# 하락 개장 회복 가설의 고정 관측

자료: Ahmed Elkassabgi, HF Data Library (2026),
[DOI](https://doi.org/10.5281/zenodo.19501605),
[CC BY4.0](https://hfdatalibrary.com/pages/license),
[출처 표시](https://hfdatalibrary.com/pages/cite).

2014-03-03~2017-12-29 개발 기간과 첫날의 전일 마감 관측만 전달한다.
PiTrading 기반·source 조정 가격이며2022년 이후IEX 자료는 없다.
원저자의 보증이나 이 가설의 승인을 뜻하지 않는다.

변경: 194의30개 정규장1분 CSV 전체 지문을 확인한 뒤DD/UTX를 사전 제외하고,
28종목의09:30/09:45/09:47/15:56 및 다음 거래일에 필요한 정확한 직전 세션
마지막1분봉 **원문 행**만 골라 mtime0 gzip으로 포장했다. 가격을 수정·생성하거나
빈 관측을 채우지 않았다. 반일장에 없는15:56도 만들지 않았다. 마지막 개발일의
다음날 신호는 평가하지 않으므로 불필요한 마감 관측은 없다.

source-manifest.json은 기존 원본과 같은 바이트다. index.json은 원본·압축·해제
지문, 행 수·바이트 수를 연결하고204 contracts/input-lock.json으로 성과 전에
봉인된다. 원본 무결성·자료 전달 단계이며 가격 수익은 계산하지 않았다.
계좌·로그인·사용자 이메일·실주문 자료는 없다. 2018년 이후 가격 행도 없다.

참조 가격 진단 입력이며 실제 체결·계좌 수익·KIS 동등성·기업 계보·과거 공개 시각의
증거가 아니다. 새 거래 허용 목록이나 실자본 승인은 없다.
