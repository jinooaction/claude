# 가격 외 입력의 무료 확보 가능성 점검

2026-09-21. 194 출시 이후 후속 조사다. 새 전략의 성과를 계산하지 않았으며
기존 최소31회 시도 수를 바꾸지 않는다. 실주문·자본·허용 종목·비용 관문도 그대로다.

## 가설을 바로 추가하지 않은 이유

[End-of-Day Reversal 저자 원문](https://academicweb.nd.edu/~zda/EOD.pdf)의 인쇄1~4쪽은
장 마감 직전의 종목 간 반전 효과와 매수·공매도 포트폴리오를 다룬다.
보고된 평균 효과만으로 현재의 매수 전용·편도31/40bp 조건을 감당한다고 판단할 수 없다.
이는 모든 변형의 불가능성 증명이 아니다. 논문 수익을 현재 프로그램에 이식하지 않고,
가격 조건만 반복하는 대신 실적 공시라는 별도 정보의 확보 가능성을 먼저 확인했다.

## 확인한 무료 경로

- [Microsoft의 사전 일정](https://news.microsoft.com/source/2014/01/03/microsoft-announces-quarterly-earnings-release-date-and-upcoming-event-for-the-financial-community-11/)은
  2014-01-03에 2014-01-23 장 마감 후 발표 계획을 알렸다.
- [실제 발표문](https://www.microsoft.com/en-us/Investor/earnings/FY-2014-Q2/press-release-webcast)은
  2014-01-23자로 2013-12-31 종료 분기의 실적을 담고 있다.
- [SEC 8-K](https://www.sec.gov/Archives/edgar/data/789019/000119312514018629/d661449d8k.htm)의
  Item 2.02도 같은 날짜의 실적 발표를 확인한다.

회사 공식 웹사이트 두 문서를 실제 내려받아 본문 날짜·분기·장 마감 후 계획을 검사했다.
원본은 공개 저장소 밖 event-source-pilot-v1에 보존했다. 이는 공개 가격 연구 기간 이전의
입력 형식 점검 사례이며 거래일 선정이나 수익률 조회에 사용하지 않았다.

| 원본 | 바이트 | SHA256 |

직접 SEC submissions JSON 요청은403, 웹 도구의 같은 API 조회도 실패했다.
기존 공식 분기 목록에서 공시 식별자를 확인했고, 개별 공시 본문은 웹 도구로 읽었다.
API 접근 실패를 회피하기 위해 신원을 위장하거나 유료 서비스를 등록하지 않았다.

## 아직 입증하지 못한 것

[SEC 공식 시각 안내](https://www.sec.gov/about/webmaster-frequently-asked-questions)는
접수 시각과 웹 공개 시각을 구분하며 공개 지연을 보장하지 않는다고 설명한다.
따라서 접수 시각이나 문서에 적힌 날짜를 즉시 관측 가능한 시각으로 바꿀 수 없다.
사전 계획 역시 실제 발표 시각의 증거와 구분해야 한다.

내려받은 일정 페이지는 과거 게시 시각과2025년 수정 시각을 함께 갖고 있었고,
실제 발표문에는 확인한 범위에서 정밀 게시 시각 메타데이터가 없었다.
현재 파일 지문은 오늘 확보한 사본을 식별할 뿐 과거 웹페이지 버전을 증명하지 않는다.
이 사례의 검사 결과에서 exact_release_time_verified와 point_in_time_eligible은 모두false다.

## 후속 작업 범위

새 전략보다 먼저 회사 식별자·보고 기간·예정/실제 발표·공개 시각의 근거·수정 이력을
분리하는 입력 계약이 필요하다. 시각 증거가 부족하면 매매 가능 시각은 미확정으로 남겨야 한다.
30종목 전체의 과거 사건 범위와 누락도 아직 검사하지 않았다. 누락을 사건 없음으로 처리하지 않는다.
이 계약과 자료 범위가 확정되기 전에는 실적 발표 기반 수익성이나 실사용 가능성을 주장하지 않는다.
새 입력기 구현은 별도 명세로 진행해야 하며, 이번 기록은 자료 가능성 조사에 한정한다.
