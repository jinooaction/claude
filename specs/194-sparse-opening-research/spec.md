# Feature Specification: 누락을 보존하는 시초 거래량 돌파 연구

**Feature Branch**: `codex/194-sparse-opening-research`
**Created**: 2026-09-21
**Status**: 구현 완료·실제 후보 탈락 — 최종 기록 재생과 전체 검사 진행 중
**Input**: 기존 한국투자 단타 프로그램 완성을 위해 확보한30개 후보 원본과193 관측 입력을 실제 전략 연구에 연결한다.

## User Scenarios & Testing

### User Story 1 — 당시 자료로만 단일 후보 검사 (Priority: P1)
운영자는 시초 거래량 증가와 가격 돌파가 비용을 감당할 가능성이 있는지 확인한다.
독립 검사: 신호 이후의 관측을 변경해도 이미 생성된 신호·주문 의도가 동일해야 한다.
1. 시초5분이 양봉이고 거래량이 정확한 직전14거래일 시초5분 평균의2배 이상일 때만 후보가 된다.
2. 09:40~10:30에 끝난5분 창 종가가 시초고가를 넘으면 하루 최초1회 매수 시도를 기록한다.
3. 직전14일 중 필요한 창 하나라도 누락되거나 평균거래량0이면 부족 사유를 남긴다.
4. 오후 누락이나 종가 존재 여부는 오전 신호를 소급 변경하지 않는다.

### User Story 2 — 현금과 미청산 보유 지속 (Priority: P1)
운영자는 현금보다 많이 사거나 누락된 청산을 없던 거래로 처리하지 않는 결과를 받는다.
독립 검사: 이틀 연속 청산 관측이 없고 셋째 날 관측되는 사례에서 잔량·현금·비용을 직접 대조한다.
1. 매수·비용에 쓴 현금은 차감하며 동일 시각 다른 종목이 재사용하지 못한다.
2. 완결5분 종가가 시초저가 이하이거나 거래소 폐장5분 전이면 청산 대기로 바뀐다.
3. 청산 대기는 날짜가 바뀌어도 유지하고 새 관측에서 재시도한다. 잔량이0이 되기 전 새 매수는 금지한다.
4. 기간 끝의 잔량은 미해결로 남기며 임의 종가 청산이나 마지막 날 삭제를 하지 않는다.

### User Story 3 — 재현 가능한 제한부 결과 (Priority: P2)
운영자는 후보 규칙·비용·자료 지문·모든 시도와 실패를 같은 자료에서 재현한다.
독립 검사: 별도 산술 대조가 현금 변동과 장부 합계에 일치한다.
1. 기준/가혹 비용 결과와 미청산·미관측·용량 미인증을 함께 보고한다.
2. 자료 회사 연결이 미인증이면 결과가 양수여도 실사용 합격을 선언하지 않는다.
3. 최종확인495일을 열지 않고 이전 최소30회 시도에 신규1회를 더해 기록한다.

### Edge Cases
- 시초 평균0, 전체 날짜/종목 누락, 조기폐장, 일광절약시간 전환.
- 같은 시각 여러 신호, 현금 부족, 가격 갭,0거래량, 일부 수량만 관측 가능.
- 청산 신호 직후 누락, 익일 보유, 기간 끝까지 관측 없음, 결제 전 현금 재사용.
- 회사 연결 미인증, 자료 변경, 중복 실행/기존 결과 덮어쓰기.

## Requirements

### Functional Requirements
- **FR-001**: 성과 조회 전에 단일 후보·30파일 목록·기간·비용·현금·수량·결제·동시 신호 우선순위를 고정하고 지문을 남긴다.
- **FR-002**: 개발 기간2014-03-01~2020-03-06의 XNYS 달력을 보존한다. 시초14일은 준비 기간이다.
- **FR-003**: 매수 결정과 사후 관측을 구분한다. 다음1분봉 시가는 연구 참조 가격이며 실제 체결로 표시하지 않는다.
- **FR-004**: 매수 수량과 가격 한도는 당시 정보로 정한다. 누락 진입은 미체결로 남기고 이후 가격을 소급 선택하지 않는다.
- **FR-005**: 청산 미관측·부분 수량은 상태로 보존하며 청산 대기를 일자 경계에서 초기화하지 않는다.
- **FR-006**: 현금·보유·결제대기를 하나의 시간순 장부로 유지한다. 자본 소진 후 가상의 신규 자금을 보충하지 않는다.
- **FR-007**: 한 거래·한 종목·전체 노출 한도를 명시하고 검사한다. 실제 계좌 자본은0이며 실거래 설정·허용목록은 변경하지 않는다.
- **FR-008**: 신호·미체결·미청산·비용을 모두 기록한다. 미래 자료 수정은 이미 발생한 결정에 영향을 주지 않는다.
- **FR-009**: DD/RTX 가격 차이와 미인증 회사 연결을 결과에 보존한다. 이 기능에는 실사용 승격 경로가 없다.
- **FR-010**: 기준/가혹 비용 양쪽 순손익이 양수이고 기준 청산200회 이상·미청산0인 경우에만 추가 독립검증 대상으로 표시한다. 이것은177/181 합격을 대체하지 않는다.
- **FR-011**: 원본·계약·코드 지문과 현금 산술 대조를 보존하고 기존 출력 덮어쓰기를 거부한다.

### Key Entities
- 고정 연구 계약: 후보·자료·비용·자본·평가 범위.
- 관측 창: 시각·완전성·가격·거래량.
- 주문 의도: 결정 시각·고정 수량/한도·매수/청산 이유.
- 연구 장부: 현금·보유·결제대기·미체결·미청산·비용.
- 결과: 비용별 성과·자료 한계·지문·독립검증 필요 여부.

## Success Criteria

### Measurable Outcomes
- **SC-001**: 고정된30개 파일의 전체 달력과 모든 결정이 재현된다. 사후 날짜/종목 제외0건.
- **SC-002**: 미래정보·누락 청산·현금 중복사용 반례에서 위반0건.
- **SC-003**: 실제 자료의 두 비용 장부가 별도 산술 계산과 일치한다.
- **SC-004**: 결과마다 주문0·실제자금0·승격불가·불확실성을 명시한다.
- **SC-005**: 실패 후보도 보존하고 검사·출시·인계까지 완료한다. 수익성 자체는 보장하지 않는다.

## Assumptions
- 새 연구 동작과 활성 포인터 변경이므로 위험등급2, 전체 명세 절차를 적용한다.
- 기존193 입력을 재사용하되 현금 없는 일별 초기화 실행기는 재사용하지 않는다.
- 자료는 조정 가격이며 실제 수량·용량 동등성이 미인증이다. 연구 참조 거래와 실제 체결을 구분한다.
- 회사 연결 조사는 계속 필요하다. 이번 구현이 끝나도181 T013~T016은 증거 전 미완료다.
- 실패 시 새 연구 경로 사용을 중단하고 활성 포인터를193으로 복원한다. 기존 기능 제거는 없다.
