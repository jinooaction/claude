# Feature Specification: 후보 고정 환경의 읽기 전용 사전 확인

**Feature Branch**: `codex/213-frozen-context`  
**Created**: 2026-10-13  
**Status**: 명세 검토 완료  
**Input**: 불변 후보 코드·의존성과 main을 분리하는 가능조건을 검증한다.

## User Scenarios & Testing

### User Story 1 - 선언한 후보 환경 확인 (Priority: P1)
운영자는 현재 해시가 계속 바뀌는 배포 디렉터리와 후보의 고정 경로를 구분하고,
선언한 커밋·파일 트리·의존성 목록·실제로 찾아지는 모듈 위치가 맞는지 확인한다.
**Independent Test**: 서로 독립적인 작은 합성 Git 저장소 두 개에서 한쪽 변경이 다른 쪽 선언 비교에 영향을 주지 않음을 확인한다.
**Acceptance Scenarios**:
1. 주어진 후보가 선언과 같고 main과 다른 경로이면 제한된 지역 비교 성공을 반환한다.
2. 동일 파일의 다른 커밋, 수정 파일, 다른 의존성 정보이면 불일치를 반환한다.

### User Story 2 - 혼합·불완전 환경 차단 (Priority: P2)
운영자는 main 소스나 공유 의존성이 후보 환경에 섞였을 때 이를 알아야 한다.
**Independent Test**: 경로 별칭·중첩·main 모듈·외부 가상환경·동시 변경·누락 입력을 반례로 확인한다.
**Acceptance Scenarios**:
1. 같은 경로를 다른 이름으로 지정하거나 후보 안에 main을 넣으면 비교를 거절한다.
2. 점검 동안 후보가 바뀌거나 필요한 원본이 없으면 사유를 남기며 성공을 표시하지 않는다.

### Edge Cases
잘못된 선언/중복 필드/과대 파일/심볼릭 링크/브랜치 추종/키 이름 등 비허용 필드/모듈 검색 실패/의존성 이름 중복/Git 시간 초과.

## Requirements

### Functional Requirements
- **FR-001**: 사전에 제공한 제한된 선언과 현재 후보의 정확 커밋·파일 트리·lock 지문을 비교한다. 선언을 자동 작성하거나 승인하지 않는다.
- **FR-002**: 후보와 갱신 경로의 별칭·중첩, 후보의 브랜치 추종·변경·추적되지 않은 파일을 거절한다. 읽기 확인 전후 상태를 비교한다.
- **FR-003**: 현재 실행기의 후보 전용 환경 위치·Python 버전과 지정한 최상위 프로젝트 모듈의 실제 검색 위치를 비교한다. 모듈을 실행하지 않는다.
- **FR-004**: 선언한 의존성의 설치 버전과 설치 위치를 비교한다. lock이나 버전 정보만으로 전체 설치 파일을 인증했다고 표시하지 않는다.
- **FR-005**: 입력32KiB/최대32의존성/최대16모듈/lock2MiB/Git 호출당3초·출력64KiB/결과16KiB를 제한하고 오류 전문·경로·환경·계좌·가격·키를 출력하지 않는다.
- **FR-006**: 출력은 지역 비교뿐이며 선언 인증/파일 전체 무결성/지속 불변/독립 전략/실행 승인/프로그램 준비를 미평가로 표시한다. 주문0/자격·승격거짓을 유지한다.
- **FR-007**: 설치·가상환경 생성·수집·등록·재서명·전진·권한·서버·돈 경로·실주문·장부 쓰기를 호출하지 않는다. 기존6파일·등록/수집 검증·90초·60세션·헌법/Kernel/배포/의존성을 변경하지 않는다.
- **FR-008**: 모든 실패는 성공 없이 제한된 사유로 반환한다. 기존 검증을 대체하거나 이 출력으로 등록을 이어받지 않는다.

### Key Entities
기대 환경 선언: 미서명 비교 기준. 관측 환경: 현재 실행기가 보는 Git/lock/모듈·의존성 위치. 비교 결과: 제한된 일치/불일치/조회 불가와 미평가 범위.

## Success Criteria
- **SC-001**: 합성 독립 저장소에서 main 변경 후 후보 비교 성공, 후보 변경 후 거절이 재현된다.
- **SC-002**: 경로·커밋·의존성·동시 변경·잘못된 입력 반례가 생략 없이 통과한다.
- **SC-003**: 검사 전후 원본·저장소·장부 불변과 비밀/네트워크/주문 호출0을 확인한다.
- **SC-004**: 정확 검토 코드의 전체 GitHub 검사·린트·하네스·인계·본문·병합을 확인한다. 이것은 실제 후보 환경 설치나 전체181 완료가 아니다.

## Assumptions and Safety Boundary
등급2 운영 도구의 새 기능으로 풀 SDD를 적용한다. 실제 후보/서버/키는 이번 작업에서 사용하지 않는다.
불변 환경 설치와 그 설치 파일의 인증·수집·전략 등록은 별도 후속이며 통과 전략이 없는 상태에서 시작하지 않는다.
기존1645/탈락·최소36/495미개봉·31/40bp/200거래·현금/정산/부분체결/한도/감사·90초/60세션을 보존한다.
제거하는 기능은 없다. 도구 삭제로 되돌릴 수 있고 기존 실행 경로는 이 도구를 참조하지 않는다.
