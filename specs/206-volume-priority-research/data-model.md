# 자료 모형

- 봉인 후보: family_id·기존 계약·원본 manifest 지문·정렬 규칙·비용·시도 하한.
- 신호 묶음: 같은 decision_at, 원래 symbol, 양의 유한 relative_volume, signal_close,
  opening_low. 미래 시각을 섞지 않으며 중복 symbol을 거부한다.
- 전달 항목: symbol·평문 지문/크기·암호문 지문/크기·고유 nonce·계약/파일 정체성 AAD.
  키·가격·거래량·계좌·이메일은 지문 목록에 없다.
- 연구 장부: 기존194 사건·현금·예약·원래 수량·부분 참조 체결·정산·잔량.
- 결과: 계약·입력·코드·장부 지문, 최소35선행/새1/최소36, 두 비용 시나리오와 실패 이유.

상태: 계약 봉인→자료 준비→입력 검증→개발 재생→독립 재계산→검증 기록.
어느 상태도 운영 승인·실주문 가능·자본 배분으로 전환하지 않는다.
준비 실패는 완료 영수증 없는 실패이며 기존 출력은 덮어쓰지 않는다.
