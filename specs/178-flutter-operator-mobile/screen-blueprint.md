# 화면 설계도

첫 버전은 하단 탐색의 `홈`, `자동화`, `설명` 세 영역으로 구성한다. 주문이나 설정 탭은 없다.

## 홈

위에서 아래로 다음 순서를 유지한다.

1. 앱 이름과 수동 새로고침 버튼
2. 온라인·오프라인·지연 여부와 자료 생성 시각을 보여주는 신선도 배너
3. 전체 운영 판정, 한글 제목, 이유와 다음 행동을 담은 큰 카드
4. `실제 돈 경로`, `다음 자율 작업`, `돈 경로 정렬`, `개입 필요` 2×2 요약 블록
5. 기준 커밋, 출처와 원본 실행 기록
6. “이 앱은 상태만 읽으며 주문·자본 변경을 하지 않습니다” 안내

화면 폭이 좁거나 글자가 커지면 2×2 블록은 한 열로 바뀐다. 전체 판정 카드보다 자산 숫자가
앞에 오지 않으며, 자료에 없는 잔고·보유종목·손익은 빈칸으로도 만들지 않는다.

## 자동화

목록은 다음 순서로 묶는다.

1. 핵심 자동화 중 위험·지연·누락·알 수 없음
2. 나머지 핵심 자동화
3. 보조 보고 중 비정상
4. 나머지 보조 보고

각 항목은 이름, 중요도, 상태 문구와 아이콘, 설명, 마지막 실행 시각, 경과 시간, 허용
신선도를 표시한다. 원본 실행 주소가 있을 때만 `기록 보기`를 제공한다. 링크 실패가 목록을
닫거나 상태를 바꾸지는 않는다.

## 설명

- 앱이 보여주는 것: 정제된 공개 운영 상태, 다음 행동, 자동화 신선도
- 앱이 하지 않는 것: 주문, 실거래 활성화, 중단 해제, 자본·전략·종목·한도 변경
- 자료 출처: GitHub Pages의 버전이 붙은 읽기 전용 JSON과 기준 커밋
- 안전 안내: 화면이 오래됐거나 확인 불가이면 서버·텔레그램·원본 실행 기록으로 재확인
- 디자인 및 앱 버전

## 상태별 첫 화면

| 입력 상태 | 최상단 표시 | 정상 오인 방지 |
|---|---|---|
| 신선한 정상 | 정상 아이콘과 생성 시각 | 실제 주문 경로 무장 시 별도 주의 문구 |
| 신선한 주의 | 주의 이유와 다음 행동 | 정상 요약보다 먼저 표시 |
| 위험/행동 필요 | 위험 아이콘과 원인 | 초록색 전체 판정 금지 |
| 30시간 초과 | “오래된 상태” 배너 | 마지막 판정을 현재 정상으로 표현하지 않음 |
| 오프라인+캐시 | “오프라인, 마지막 자료” 배너 | 저장 시각과 생성 시각을 함께 표시 |
| 캐시 없는 실패 | “상태를 확인할 수 없음” | 빈 값을 정상으로 추측하지 않음 |
| 예제 자료 | 모든 탭에 “예제 데이터” | 예제 숫자를 실제값처럼 표현하지 않음 |

## 접근성 확인

- 상태는 아이콘·문구·색상 세 가지로 표현한다.
- 화면 읽기 순서는 시각적 순서와 같다.
- 200% 글자 크기에서 고정 높이를 사용하지 않고 카드가 아래로 늘어난다.
- 새로고침, 탭, 기록 링크는 최소 44×44이며 의미 있는 접근성 이름을 가진다.
- 작은 화면에서도 좌우 스크롤 없이 핵심 정보가 보인다.
