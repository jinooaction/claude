# 스펙 039 — 라이브 캐너리 포트폴리오 (고도화를 실거래에 올리기)

## 문제 (운영자 핵심 지적)

운영자: **"앞으로 항상 실거래 기반으로 고도화하고 싶다. 돈을 못 벌면 이 고도화 아무 의미 없다."**

현 격차:
- **고도화(스펙 032~038)** — 포트폴리오 재조정·다요인 알파·추세 필터·forward 판정·A/B·칼마 —
  는 전부 **페이퍼 전용**.
- **실거래(라이브 캐너리)** — `canary-live-rules.toml` = 단순 3룰 qty=1(SPY 눌림목·MSFT
  골든크로스 등), $12k, `AUTO_INVEST_MODE=live`(2026-05-30 무장). 즉 정교한 고도화가 **실제
  돈을 안 만진다.**

## 목표

고도화(추세 필터로 방어되는 포트폴리오 전략)를 **소액 실거래** 라이브 캐너리로 올린다 —
헌법 VI 2단계(소액 실거래 검증) + 헌법 X.4(운영자 지시 하 가드형 라이브 캐너리).

## 이번 슬라이스 (안전 산출물 — 돈 0 이동)

- **`deploy/canary-live-portfolio.toml`** — 보수적 라이브 포트폴리오 설정:
  - 유니버스·화이트리스트 = 기존 실거래 종목 **SPY·MSFT·AAPL 그대로**(라이브 거래 집합
    무확대, 헌법 II).
  - 단순 3룰 대신 **추세 필터로 방어되는 top-2 모멘텀 포트폴리오**(추세 아래면 현금, hold_replace
    저회전).
  - `global_exposure 60%`·`invested_fraction 0.6` 으로 현금 버퍼 크게(미검증 전략 전액 투입 금지).
  - 자본은 이 파일이 안 정함 — go-live 채널이 운영자 지정 소액 적용.
- 회귀 테스트 — 위 안전 불변식(유니버스 무확대·추세 필터 ON·보수적 노출·저회전)을 못박음.

## 무장(arming)은 운영자 결정 — 이 슬라이스에 포함 안 함

라이브 포트폴리오 실행(`rebalance-once --mode live --confirm-live`)을 주기적으로 돌리는 가드
워크플로 + 자본 무장은 **돈이 움직이는 되돌릴 수 없는 행동**이라 운영자가 다음을 확정해야 한다:
- **자본 금액**(소액 — 예: $500~$2,000).
- **접근**: (A) 새 라이브 포트폴리오 캐너리 추가 vs (B) 기존 3룰 캐너리에 추세 오버레이만 vs
  (C) 더 기다려 forward 검증 후.
- **킬스위치**: 스펙 014 손실 서킷 브레이커(일손실·총낙폭 한도).

헌법 X.4: 라이브 전환은 운영자 *결정*. 자율 무장은 운영자 지시 하 소액 캐너리·전체 캡·가드
채널 한정이며, **풀라이브 아님**.

## 미검증 경고 (정직)

이 전략은 아직 forward 페이퍼로 충분히 검증되지 않았다(verdict=INSUFFICIENT_DATA, ≈20 거래일
필요). 그래서 *소액* 캐너리로만 운용한다 — 캐너리 자체가 소액 실거래 검증 단계다. forward-verdict
+ 칼마(스펙 035/038)가 `--mode live` 로 이 실거래 트랙을 같은 잣대로 판정한다.
