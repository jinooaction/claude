# 자료 구조

- 소스 목록: 정렬된 중복 없는 저장소 상대 경로 tuple. 기존38개 및 검토된 실행 의존 파일과 목록 구현 자체. 외부 입력 아님.
- 소스 항목: `{path, sha256}`. 절대 체크아웃 위치는 제외하고 원본 바이트를 해시한다.
- 지문 입력: `{schema: 2, candidate, provider, sources}`. 반환은 기존64자리 SHA-256 문자열이며 값은 바뀐다.
- 실패: 부재·비정규 파일·링크·읽기 실패·상태 변화·중복은 ValueError. 성공 지문이나 이전 캐시로 대체하지 않는다.
- 기존 등록/자격: 필드 변경·자동 마이그레이션 없음. 옛execution_identity는 기존 비교에서 거부된다.
