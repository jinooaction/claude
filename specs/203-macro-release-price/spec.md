# Feature Specification: 공식 거시 발표일의 장중 가격 반응 진단

**Feature Branch**: `codex/203-macro-release-price`  
**Created**: 2026-10-02  
**Status**: 개발 구간 비용 후 탈락 — 연구 전용
**Input**: 한국투자 계좌용 단타 프로그램의 통과 전략을 찾되 실제 주문 전 비용과 시간 분리로 검증한다.

## User Scenarios & Testing

### User Story 1 — 발표일 원본을 재현한다 (P1)

운영자는 가입비 없는 발표 달력의 날짜가 실제 공식 발표 날짜인지 확인한다.
물가지수와 고용 발표만 사용하며, 2차 달력의 상태값이나 과거에 알 수 있었음을
주장하는 생성 시각을 사실로 받아들이지 않는다.

1. 고정한 달력·연준 보관 날짜·분봉 목록의 지문이 다르면 연구를 중단한다.
2. 발표 날짜·동부 시각 08:30·미국 증시 거래일·중복을 검사해 포함/제외 이유를 남긴다.
3. 2차 달력에 `cancelled`라고 잘못 적힌 과거 발표도 공식 날짜와 원문이 있으면
   무조건 버리지 않고, 반대로 공식 날짜가 없는 항목은 제외한다.

### User Story 2 — 개발 구간의 한 가설만 가격으로 진단한다 (P1)

2013-08-23~2017-12-29의 발표 거래일에서만, 직전 거래일 마지막 5분봉 종가보다
09:45 시작 봉 종가가 높은 종목의 09:55 시작 봉 시가와 15:55 시작 봉 시가를
관측한다. 기준 편도 31bp와 가혹 편도 40bp 비용을 차감한다. 관측 누락과 거래량
0은 보간하지 않는다. 2018년 차단 구간과 2019년 이후 최종 구간의 수익은 열지 않는다.

### User Story 3 — 연구와 실거래의 경계를 지킨다 (P2)

운영자는 결과가 비용 후 음수인지, 또는 표본·체결 근거가 부족한지 구분한다.
이 결과는 가격 참조쌍 진단이며 현금·동시 노출·실제 호가·부분 체결·계좌 수수료를
검증한 전략 합격이 아니다. 주문과 실제 자본은 항상 0이다.

### Edge Cases

- 미국 증시 휴장일 발표, 일광절약시간, 같은 날짜의 중복·다른 발표 가족.
- 2차 달력의 잘못된 취소 상태·빈 기준 월·비표준 시각·공식 날짜 불일치.
- 분봉 누락·중복·거래량 0·불완전 전일·조기 폐장·원본 지문 변경.
- 관측 뒤 사전등록 규칙이나 차단 기간을 유리하게 바꾸려는 시도.

## Requirements

### Functional Requirements

- **FR-001**: 개발 가격을 열기 전에 원본 지문, 한 후보, 제외 규칙, 관측 시각,
  시간 분할, 비용, 누적 선행 시도 수를 고정한다.
- **FR-002**: 발표는 물가지수 또는 고용, 공식 보관 날짜와 일치, 동부 시각
  08:30, 해당 날짜 정규 거래 세션이라는 조건을 모두 만족해야 한다.
- **FR-003**: 2차 달력의 `status`와 2026년 생성된 `first_announced_at`는
  과거 발표/공개 시각의 증거로 사용하지 않는다.
- **FR-004**: 정확한 직전 세션 종가와 09:45 신호·09:55 진입·15:55 청산
  5분봉을 요구하며, 결측·중복·거래량 0을 조용히 대체하지 않는다.
- **FR-005**: 개발 기간만 비용 전·기준·가혹 비용 후 결과를 계산한다.
  후속 기간은 독립 후보 자격과 별도 결정 전까지 읽지 않는다.
- **FR-006**: 출력은 모든 제외/관측 상태와 지문을 남기고 주문 0, 자본 0,
  실거래 승격 불가를 명시한다.
- **FR-007**: 최소 거래 수와 비용 관문을 못 넘으면 후보를 탈락 또는 자료
  부족으로 기록하고, 실제 주문·자본·기존 전략 설정을 바꾸지 않는다.

### Key Entities

- 발표 원본: 가족, 날짜·시각, 2차 달력 식별자, 독립 공식 날짜 확인.
- 가격 관측쌍: 발표 날짜·종목·직전 종가·신호·진입·청산·거래량.
- 진단 결과: 제외·누락 이유, 비용별 개발 수익, 원본 지문, 승격 불가 표식.

## Success Criteria

- **SC-001**: 같은 원본은 같은 날짜 목록·제외 이유·결과를 만든다.
- **SC-002**: 누락·휴장·잘못된 취소 상태·지문 변조 반례를 거부한다.
- **SC-003**: 개발 기간의 실제 5종목 가격에 대해 비용 전후 결과와 표본 수를 낸다.
- **SC-004**: 모든 결과가 주문 0·자본 0·실거래 불가를 표시한다.

## Assumptions

새 연구 명령과 활성 명세 포인터를 더하는 등급 2 변경이다. 기존 연구와
주문·위험 경계는 제거하지 않는다. 실패하면 이 연구 경로와 포인터만 되돌린다.
양수 결과도 Spec 177의 완전한 전략 관문이나 Spec 181 T013~T016의 완료가 아니다.
