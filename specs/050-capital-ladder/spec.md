# 스펙 050 — 자본 사다리 (evidence-gated capital ladder)

**날짜**: 2026-06-11 · **운영자 위임**: "1·2·3 모두 세계 최고 수준이 목표. 3번(자본·수단)도
자동과 자율에 맡길 것. 기준은 계좌 잔고와 포트폴리오." · **헌법**: X.4 v5.0.0 개정 동반

## 왜 (문제)

자본 배치 규모가 운영자 단건 승인($500 고정 + $1,000 하드캡)에 묶여 있어, 시스템이 아무리
검증돼도 "많은 돈"의 지배 변수(자본)가 움직이지 않는다. 운영자는 위험 예산 하나만 정하고
배치 규모 결정 자체를 위임하기를 명시했다(2026-06-11). 세계 최고 운용사의 구조(LP 는 위험
예산, GP 는 그 안에서 전권, 독립 리스크 한도가 GP 위에)를 코드로 구현한다.

## 무엇 (요구)

- **FR-1 (사다리)**: 자본 = 실계좌 NAV × 단 비율. 단0=0%(무장 해제) → 단1=25% → 단2=50%
  → 단3=100%. 실계좌 NAV 는 KIS 잔고 멀티 거래소 스윕(`account-nav` CLI)으로 측정.
- **FR-2 (첫 진입)**: 단 0→1 은 유효 forward 엣지 `EDGE_CONFIRMED` + 전략 지문 정합
  (스펙 049 조건 승계)일 때만. 유효 forward 엣지는 표준 20관측 `forward-verdict` 또는
  깊은 OOS + 짧은 forward 지속성 `forward-verdict-anchored` 중 하나가 `EDGE_CONFIRMED` 를
  낸 경우다. 앵커드 산출이 실패하거나 미확정이면 기존 표준 판정만 남아 보수적으로 대기한다.
- **FR-3 (승격 — 올라가는 건 증거 전부)**: 단 n→n+1 은 현재 단에서 라이브 NAV 관측 ≥ 20
  + ≥ 27 캘린더일 경과 + 단 진입 후 낙폭 < 예산/2 — 셋 전부. 증거가 None(측정 불가)이면
  절대 승격 아님.
- **FR-4 (강등·정지 — 내려가는 건 즉시)**: 단 진입 후 라이브 낙폭 ≥ 예산/2(10%) → 한 단
  강등(단 1이면 무장 해제). ≥ 예산(20%) → 단 0 + 무장 해제. 재진입은 forward 재검증부터.
- **FR-5 (재사이징)**: 단 유지 중 실계좌 NAV ±10% 드리프트(입금/성장/하락) → 자본만
  재계산(시계 리셋 없음). 운영자 입금이 다음 게이트 실행에서 자동 반영된다.
- **FR-6 (낙폭 예산 = 운영자 소유)**: 기본 20%(2026-06-11 위임 계약). 변경은 운영자 결정
  — CI 회귀가 센티넬·코드 기본값의 일치를 강제한다.
- **FR-7 (실행 채널)**: 결정은 순수 모듈 `portfolio/capital_ladder.py`(테스트됨), 집행은
  게이트 워크플로(`forward-edge-autoarm.yml`)의 센티넬 PR + 자동 머지, 실주문은
  `rebalance-live-canary.yml` 시장시간 스케줄에서만. 빠른 장중 방어선은 스펙 014 서킷
  브레이커(사다리는 일 1회의 느린 거버너).
- **FR-8 (자본 권위 가드)**: 실주문 워크플로는 자본이 사다리 기록 실계좌 NAV 이하인지
  검증. 사다리 필드 없는 수동 센티넬은 종전 소액 가드($1,000) 유지 — 손 편집으로 큰
  자본을 무장할 수 없다. CI 회귀(`test_live_arming_sentinel`)가 자본 = 단 공식까지 검증.

## 비위임 불변 (세계 최고 펀드도 운용역에게 안 주는 것)

킬스위치(`automation/AUTOARM_DISABLED`) · 스펙 014 서킷 브레이커 · K1 캡 체계 ·
화이트리스트(헌법 II) · 추가 전용 감사(헌법 IV) · 시크릿(헌법 V) · 장중 배포 금지(VIII.A)
· 낙폭 예산 소유권. 입금(은행 이체)·증권사 약정·컨테이너 네트워크 정책은 물리적으로
운영자만 가능하다.

## 합격 기준

- **SC-1**: 순수 결정 로직 단위 테스트 — 차단 계열(킬스위치/지문 불일치/NAV 불능),
  단 0(WAIT_EDGE/PROMOTE), 강등·정지(즉시), 승격(증거 전부 필요·None 승격 금지·천장),
  재사이징(시계 보존), 하위 호환(옛 무장 센티넬 = 단 1) 전부 커버.
- **SC-2**: 같은 입력 → 같은 결정(순수·결정론). 주문 0건·돈 0 이동(결정·기록만).
- **SC-3**: 센티넬 일관성 CI 회귀 — 커밋된 센티넬의 자본은 사다리 공식 또는 소액 가드
  중 하나의 권위를 가져야 한다.
