# Research

## 결정: 월별 실적 효과와 개별 사건 입력을 구분

175의 EarningsSurprise/AnnouncementReturn은 월별 집계 포트폴리오다.
발표 전후 수익을 포함한 신호를 발표 순간의 정보로 바꿀 수 없다.
193의 같은 바이트 해시/검증·시간대 필수 방식을 참고하되 분봉 종료 시각 규칙은 복사하지 않는다.

## 결정: 현재 확보와 과거 공개를 구분

[194 조사](../194-sparse-opening-research/event-input-feasibility.md)의 두 실제 원문을 재사용한다.
현재 다운로드 기록에는 정밀 완료 시각이 없으므로 소급한 관측 영수증을 만들지 않는다.
새 import가 로컬 파일을 읽고 내용 확인을 끝낸 시각만 기록한다. 원격 진위나 공개 시각 증명은 아니다.
SEC 접수, HTML 게시/수정 메타데이터는 source_claims로만 남긴다.

## 검토한 대안

- 접수 시각 + 고정 지연: 공개 지연 상한 증거가 없어 기각.
- 현재 파일 mtime을 과거 관측으로 사용: 복사/수정 가능한 값이므로 기각.
- 현재 문서로 옛 발표일에 거래: 과거 버전 부재로 기각.
- 정확한 최초 공개 초가 없으면 모든 활용 거부: 불필요하다. 실제 확인 완료 이후의 입력은 재현 가능하다.
- 새 네트워크 수집기부터 구현: 확보 원문 재사용과 내용/시각 구분부터 완성한다.
  향후 수집기는 요청 시작/응답 완료/파싱 완료를 기록하고 실패를 미공개 증거로 쓰지 않아야 한다.

## 독립 검토

event_time_contract_review의 읽기 전용 검토로 사건/종목 연결 분리, 예정/실제 분리,
현재 사본의 역사 소급 금지, 관측 상한 사용, 실패는 UNKNOWN, 정정 버전 보존,
미래 문서 추가 후 과거 조회 불변 검사를 반영했다. 수익률은 열람하지 않았다.
