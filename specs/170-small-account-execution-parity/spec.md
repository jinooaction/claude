# Feature Specification: Small-Account Execution Parity

**Feature Branch**: `codex/170-small-account-execution-parity`  
**Created**: 2026-08-27  
**Status**: Preregistered  
**Input**: User description: "다음 우선순위를 진행하고, 전략과 합격 기준의 오류를 뿌리부터 확인한다."

## Problem Definition

### Request

역사적으로 가장 유망한 전략도 현재 소액 계좌에서 실제 주문을 만들 수 없고 하드닝 카나리는
종목별 최신 거래일 차이를 데이터 결손으로 오판한다. 기준을 낮추지 않고 이 두 실행 결함을
수정하고, 첫 자본 진입 전에 대체 ETF의 경제적 동등성과 정수 주 구현 가능성을 자동 검증한다.

### Root Cause

1. `canary-portfolio`는 유니버스 거래일의 합집합 끝날짜를 사용한다. 한 종목의 최신 바가 다른
   종목보다 하루 늦으면 아직 오지 않은 바를 결손으로 세어 거짓 `audit_integrity_failures`를 낸다.
2. 현재 실행 ETF `SPYM`, `IEF`, `GLDM`은 약 90달러 전후다. 계좌 NAV 약 1,456달러의 연구 단
   10%와 종목당 주문 상한 50%에서는 1주 가격이 주문 상한 약 72달러보다 커 주문할 수 없다.
3. 자본 사다리의 직접 forward 진입은 정확 자금 구현성 검사를 모든 경로에 공통으로 요구하지
   않는다. 대체 ETF가 원래 신호 자산을 충분히 추적하는지도 첫 주문 직전에 재검증하지 않는다.

### Non-goals

- `globalfixed`의 현재 `NO_EDGE` 판정을 기준 완화로 합격시키지 않는다.
- 자본 사다리 비율, 계좌 낙폭 예산, 종목/주문/전체 노출 상한, 킬스위치, 정규장 제한을 바꾸지 않는다.
- 소수점 주문을 검증된 KIS 경로처럼 가정하지 않는다.
- 이 기능 구현·검증 중 실제 주문이나 자본 이동을 발생시키지 않는다.

## User Scenarios & Testing

### User Story 1 - Use the Latest Complete Canary Window (Priority: P1)

운영자는 모든 신호 자산에 바가 존재하는 최신 공통 거래일을 끝점으로 하드닝 카나리를 실행한다.

**Independent Test**: 한 종목만 최신 2거래일이 늦은 자료에서 최근 45개 공통 세션을 선택하면
거짓 결손 없이 통과하고, 같은 창 안의 실제 중간 결손은 계속 실패한다.

### User Story 2 - Preregister Economically Similar Low-Price Proxies (Priority: P1)

운영자는 결과를 보기 전에 고정한 `SPY->SCHX`, `IEF->SPTI`, `GLD->IAUM`만 실행 후보로 사용한다.

**Independent Test**: KIS 조정 일봉의 최신 252개 공통 세션에서 각 쌍이 수익률 상관 0.95 이상,
연환산 추적 오차 6% 이하, 연환산 수익률 차이 3%p 이하, 대체 ETF 중간 일거래대금 100만 달러
이상, 데이터 나이 7일 이하를 모두 충족하고 KIS 시세·주문 거래소 코드가 해석되는지 확인한다.

### User Story 3 - Require Execution Readiness on Every First-Capital Path (Priority: P1)

운영자는 연구 공장, 역사+forward 탐색, 직접 forward 확정 중 어느 경로도 최신 대체 ETF 동등성과
정확한 정수 주 미리보기 없이는 첫 자본을 열지 않는다는 보장을 받는다.

**Independent Test**: 엣지 증거가 완전해도 동등성 또는 자금 구현성 중 하나가 없거나 실패하면
단 0을 유지하고, 둘 다 통과한 경우에만 기존 단으로 진입한다. 이미 체결된 전략의 위험 축소
경로는 새 진입 검사 때문에 막히지 않는다.

## Requirements

> **돈 경로·안전 경계 변경**: 등급 4다. 라이브 화이트리스트와 실행 대체 ETF를 바꾸며 첫 자본
> 진입 관문을 강화한다. 기존 위험 상한은 완화하지 않는다.

### Functional Requirements

- **FR-001**: 카나리 창은 모든 신호 자산 세션의 교집합에서 최신 `window_days`개를 선택해야 한다.
- **FR-002**: 선택 창 내부 실제 XNYS 거래일 결손은 계속 감사 무결성 실패로 처리해야 한다.
- **FR-003**: 카나리 JSON은 결손 종목·날짜와 공통 세션 수를 표시해야 한다.
- **FR-004**: 실행 대체 쌍은 `SPY->SCHX`, `IEF->SPTI`, `GLD->IAUM`으로 사전 고정한다.
- **FR-005**: 대체 ETF 동등성은 최신 252개 공통 조정 일봉 수익률로 계산해야 한다.
- **FR-006**: 모든 쌍은 상관 0.95 이상, 연환산 추적 오차 0.06 이하, 연환산 수익률 차이 0.03 이하를 충족해야 한다.
- **FR-007**: 각 대체 ETF의 최신 252세션 중간 일거래대금은 100만 달러 이상이어야 한다.
- **FR-008**: 최신 공통 바는 감사 시점 기준 7일 이내여야 하고 신호·대체의 최신 날짜가 같아야 한다.
- **FR-009**: 동등성 증거는 스키마, 사전등록 임계값, 실행 매핑, 지표, 전체 판정의 내부 일관성을 소비자가 재검증해야 한다.
- **FR-010**: KIS 읽기 전용 smoke는 세 대체 ETF의 현재가와 시세 거래소를 해석하고 주문 거래소 코드로 변환 가능해야 한다.
- **FR-011**: 라이브·검증 설정의 최소 주문금액은 20달러로 같아야 하며 전략 지문은 기존과 동일해야 한다.
- **FR-012**: 정확한 10% NAV 미리보기는 현재 양수 목표, 정수 주, 1주 가격, 주문/종목/전체 상한, 현금 버퍼를 그대로 적용해야 한다.
- **FR-013**: 연구 공장, 역사 탐색, 직접 forward 확정의 단 0 진입은 동등성·자금 구현성이 모두 참이어야 한다.
- **FR-014**: 첫 체결 직전 재검증도 동등성·자금 구현성을 모두 요구해야 한다.
- **FR-015**: 이미 체결된 전략은 기존 손실·청산 게이트를 따르며 새 진입 검사 실패로 위험 축소 주문을 막지 않아야 한다.
- **FR-016**: 모든 검증 명령은 읽기 전용 시세·일봉·계좌 조회만 사용하고 주문 API를 호출하지 않아야 한다.
- **FR-017**: 현재 `globalfixed`의 통계 엣지 판정과 합격 임계값은 변경하지 않아야 한다.

## Success Criteria

- **SC-001**: 최신 종목 지연만 있는 자료는 카나리 무결성 0, 창 내부 결손은 1 이상이다.
- **SC-002**: 사전등록한 세 대체 쌍이 고정 임계값을 모두 통과하거나, 하나라도 실패하면 라이브 매핑 변경이 배포되지 않는다.
- **SC-003**: 현재 활성 2자산 목표에서 약 145달러 연구 자본의 무주문 미리보기가 구현 가능하다.
- **SC-004**: 세 자산이 모두 활성인데 현재 자본으로 오차 한도를 못 맞추면 억지 주문 대신 계속 대기한다.
- **SC-005**: 동등성·자금 구현성 변조, 누락, 오래된 증거가 각각 독립 실패한다.
- **SC-006**: KIS branch smoke, 전체 pytest, Ruff, YAML, 엄격 하네스, HANDOFF 사실, PR 품질 관문이 통과한다.

## Assumptions

- 신호 계산은 계속 `SPY`, `IEF`, `GLD`를 사용하고 주문 심볼만 대체한다.
- SCHX는 미국 대형주, SPTI는 미국 중기 국채, IAUM은 실물 금 노출을 제공하지만 지수 만기가
  완전히 같지는 않으므로 수익률 동등성 관문이 반드시 필요하다.
- KIS 공식 주문 샘플에서 검증된 수량 경로는 정수 `ORD_QTY`이며 소수점 수량은 본 범위 밖이다.
