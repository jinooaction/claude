# 생산 결과: 미국 주식 월말·월초 전략

## 한눈 결론

16개 월말·월초 후보 중 개발 구간 승자는 `월말 2거래일 + 월초 4거래일`이었지만,
2007-01~2026-06 홀드아웃에서 `NO_FACTORY_EDGE`로 탈락했다. 달력 효과는 일부 남아
있었으나, 비용 후 크기·통계 신뢰도·시대 분산이 실자본 기준에 못 미쳤다.

홀드아웃 성과는 2007~2010년과 2021~2026년에 음수였고, 편도 비용을 10bp에서 25bp로
높이면 연 현금 초과수익이 -3.34%가 됐다. 따라서 기준을 낮추지 않고 탈락으로 확정했다.

## 장부와 안전 경계

- 기존 중앙 장부 752개 + 출시 레짐 16개 + 달력 16개 = 784개 후보
- 독립 전략군 19개, 프로그램 오합격 상한 0.19 ≤ 예산 0.20
- `promotion_allowed=false`, `research_canary_eligible=false`
- 선택 배포 설정 없음, 주문 0건, 자본 변경 0건, 라이브 전략 변경 0건
- 다음 독립 우선순위: 회계 기반 횡단면 다요인 전략
