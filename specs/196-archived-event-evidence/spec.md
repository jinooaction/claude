# Feature Specification: 과거 보관 사건의 근거 검사

**Feature Branch**: `codex/196-archived-event-evidence`  
**Created**: 2026-09-25  
**Status**: Released — 전체 단타 목표의 입력 검증 단계이며 전체 실사용 완료는 아님
**Input**: 기존 한국투자 계좌용 단타 프로그램 완성. 실제 과거 자료와 관측 구간을 검증해 재현 가능한 연구 입력을 마련한다.

## User Scenarios & Testing

### User Story 1 - 같은 원문에 속한 보관 근거인지 확인한다 (Priority: P1)

운영자는 보관 원문, 검색 목록, 수집 기록이 같은 응답을 가리키는지 확인할 수 있어야 한다.

**Why this priority**: 다른 문서의 시각을 붙이거나 손상된 본문을 쓰면 과거 검증이 잘못된다.
**Independent Test**: 실제 월마트 보관 자료의 연결은 통과하고, 다른 응답 식별자를 붙인 자료는 거부한다.

**Acceptance Scenarios**:
1. **Given** 서로 맞는 원문·목록·수집 정보, **When** 검사, **Then** 파일 지문과 연결 근거가 있는 보고서를 생성한다.
2. **Given** 변조·잘림·잘못된 응답 연결, **When** 검사, **Then** 오류를 반환하고 성공 보고서를 만들지 않는다.

### User Story 2 - 공급자 시각의 뜻과 확인 한계를 구분한다 (Priority: P1)

운영자는 지금 파일을 확인한 시각과 과거 공급자가 기록한 시각을 구분하고, 수집 프로그램의 방식에 맞는 조건부 관측 구간을 확인한다.

**Why this priority**: 당시 공개된 코드의 동작은 보관 형식의 일반 설명과 다를 수 있다.
**Independent Test**: 검토한 수신 후 초 단위 프로필은 다음 초를 조건부 기준점으로 계산하며, 알 수 없는 방식은 계산을 거부한다.

**Acceptance Scenarios**:
1. **Given** 알려진 시각 방식과 실제 수집 정보, **When** 계산, **Then** 시각 정밀도에서 나온 범위와 검토 가정을 함께 출력한다.
2. **Given** 잘림 표시가 있는 자료, **When** 검사, **Then** 표시를 보존하고 원문 전체가 완전하다고 인증하지 않는다.
3. **Given** 조건부 기준점, **When** 직전 및 정확한 시각을 비교, **Then** 각각 미도달·도달로 판정하되 전략 승인으로 바꾸지 않는다.

### Edge Cases

중복 필드·식별자, 틀린 길이와 지문, 압축 폭탄, 다른 회사 자료 연결, 잘못된 날짜·시간대,
본문 대신 외부 문서를 불러오는 페이지, 오류 응답, 프로필 불일치, 기존 출력 덮어쓰기,
빈 근거 문구, 종목 연결 미확인, 서버 응답 잘림과 로컬 파일 훼손의 혼동을 검사한다.

## Requirements

### Functional Requirements

- **FR-001**: 공급자 목록, 응답, 수집 메타데이터, 수집 프로그램 정보의 원본 지문·길이·주소·식별자 연결을 검사한다.
- **FR-002**: 응답 본문의 공급자 지문과 실제 바이트를 대조하고, 주장하는 사건의 인용문 존재를 검사한다. 인용 일치가 의미적 진위를 자동 증명하지는 않는다.
- **FR-003**: 지원하는 수집 방식에만 조건부 관측 구간을 계산한다. 수집 소요 시간을 수신 후 시각에 중복 가산하지 않는다.
- **FR-004**: 공급자 시계·공개 코드와 배포 코드의 관계·원문 전체 완전성·사건 처리 지연·종목 연결을 각각 구분한다. 확인하지 않은 사항은 인증하지 않는다.
- **FR-005**: 현재 로컬 검사 시각을 별도로 기록하고 기존195의 관측 기록을 과거로 바꾸지 않는다.
- **FR-006**: 잘림 표시는 보존한다. 원문에 포함된 사건 근거를 검사하는 것과 원문 전체를 복원하는 것을 구분한다.
- **FR-007**: 알려지지 않은 입력, 모순, 훼손, 크기 초과는 거부하고 기존 출력과 원본을 덮어쓰지 않는다.
- **FR-008**: 실제 원문 검사와 반례 검사를 제공한다. 결과에 전략 채택·실주문 가능 상태를 부여하지 않는다. 전체 기간·종목 범위 검증을 한 문서 검사로 대체하지 않는다.

### Key Entities

- 보관 증거 묶음: 목록·응답·연결 기록·수집 프로그램 정보·파일 지문.
- 사건 근거: 회사·보고 기간·종류·인용문·종목 연결 미확인 상태.
- 조건부 관측 구간: 공급자 시간 해석·정밀도·가정·현재 검사 시각.

## Success Criteria

- **SC-001**: 실제 보관 발표문 1건의 내용과 수집 기록 연결을 재현한다.
- **SC-002**: 잘못된 파일·목록·연결·시각·인용 반례에서 거짓 성공 보고서가 0건이다.
- **SC-003**: 동일 자료에서 동일한 증거 지문과 조건부 시각 결과를 얻으며, 로컬 검사 시각은 별도로 남는다.
- **SC-004**: 기존195의 과거 조회 결과와 주문·자본 권한 변화가 0건이다.

## Assumptions

- 위험 등급 2: 새 연구 입력 경로 및 다음 세션 명세 포인터를 추가한다. 커널·승격·배포 제한 변경 없음.
- 공급자 공개 기록과 검토한 수집 코드에 의존한 조건부 계산이다. 실제 배포 커밋의 증명이나 외부 시계 공증이라고 주장하지 않는다.
- 최초 공개 초의 복원은 필수가 아니다. 실제 관측 이후 사용할 수 있는 근거를 마련한다.
- 전체 자료 확보, 사건 처리 지연 모델, 전략 검증, 전진 관찰, 단타 주문·청산·대사는 전체 목표에 남으며 본 기능으로 대체되지 않는다.
- 제거 기능 없음. 되돌림은 새 도구 사용과 명세 포인터를 이전 버전으로 돌리고 원본·기존 관측 기록을 보존하는 것이다.
