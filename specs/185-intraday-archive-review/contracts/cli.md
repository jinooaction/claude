# 명령 계약

`uv run python -m auto_invest.analytics.intraday_archive --archives DIR --out NEW_DIR`

입력은 YYYY-MM-DD 폴더가 있는 sessions다. 1~2000개 항목을 허용하며 고정 파일당50MB
상한과 심볼릭 링크 거절을 적용한다. 날짜-partial-32자리식별자는 미완 개수로 표시한다.
정상 날짜의 불완전한 자료는 실패다. 원본 안에 출력을 만들거나 기존 경로를 덮어쓰지 않는다.
출력 연구 분석 성공은 종료0이며 자료 부족도 정직한 분석 결과다. 검증/입출력 실패는
종료2와 고정 오류 코드다. 오류 원문·원본 파일 내용·계좌 정보를 공개하지 않는다.
재시도는 새 출력 경로를 사용한다. 기존 실패 자료를 삭제하거나 덮어쓰지 않는다.
