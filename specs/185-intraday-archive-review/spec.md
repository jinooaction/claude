# 날짜별 단타 보관 자료의 연구 연결

운영자 요청: 남은 단타 프로그램 작업을 해결한다. 기존 계좌와 수집기를 유지한다.
범위: 이미 보관한 자료가 기존177 전략 검증기로 전달되지 않는 연결 공백 해소.
비목표: 전략 승격, 정식 전진 관찰, 실시간 계좌 관측, 자본 배정, 실제 주문.
위험 등급2: 읽기 전용 자료 분석 경로를 추가하며 기존 실행 권한은 변경하지 않는다.

## 사용자 이야기

운영자는 sessions 아래 날짜별 자료를 새 연구 폴더로 결합하고 기존18개 후보 검증 결과를
확인한다. 별도 시장자료 계정이나 키는 필요 없다. 거래일이 부족하면 실제 개수와 부족분을 본다.
독립 검증: 완결2일 자료가 실제 기존 검증기까지 전달되어 754일 부족을 반환한다.

## 요구사항

- FR001: 고정 명령은 archives 폴더와 새 out 폴더를 받는다. 원본·CSV·manifest 지문,
  원본 bars와 CSV 내용, 5종목의 완결 거래일, 공급자·합성 여부·수정 정책을 확인한다.
- FR002: 검증은 한 번 읽은 비공개 임시 스냅샷에서 한다. 심볼릭 링크·지문 불일치·
  잘못된 날짜·누락 파일·혼합 공급자·이미 존재하는 출력·원본 안의 출력은 거절한다.
- FR003: 기존 수집기의 날짜-partial-32자리 식별자 폴더만 별도 개수로 보존하고 완결 일수에서
  제외한다. 정상 날짜 폴더가 불완전하면 실패한다. 기간 내 빠진 거래일도 품질 실패로 남긴다.
- FR004: 기존177 후보·756일·비용·시간 분리·연구 판정을 그대로 호출한다. 합성 여부와
  부분 시장 성격을 지우지 않는다. 과거 자료를 정식60세션 실적으로 세지 않는다.
- FR005: 출력에는 원본 지문을 가진 결합 자료, 연구 JSON, 모의 체결 CSV를 기록하고
  최종 review.json을 마지막에 원자적으로 이름 변경한다. 실패한 새 폴더는 원인 조사용으로 보존한다.
- FR006: 기존 서버의 main 한정 읽기 검사에서 현재 진단 수집기 상태의 식별자를 확인하고
  그 sessions를 읽는다. 결과는 시험 임시 폴더에만 기록하고 공개 로그에는 개수·판정만 남긴다.
  실제 계좌·주문 장부·자격값·서비스 설정을 변경하지 않는다.

## 완료 기준과 경계

동일 자료·누락·변조·혼합·소스/CSV 차이·중도 실패·원본 보존·명령 무자격값 시험,
전체 회귀·린트·하네스·인계·정상 PR·실제 서버 자료 검사를 수행한다.
자료 부족은 정직한 분석 결과이며 분석 명령 실패와 구분한다. 연구 합격도 실거래 권한이 아니다.
헌법 I~VII, VIII.A, IX/X와 모든 커널 경계는 유지한다. 복구는 새 명령 사용 중지 및
정상 코드 되돌림이며 원본 수집기·자료·거래 장부는 그대로 남는다.
