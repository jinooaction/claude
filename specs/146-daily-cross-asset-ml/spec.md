# Feature Specification: Daily Cross-Asset ML Challenger

**Feature Branch**: `Codex/146-daily-cross-asset-ml`
**Created**: 2026-08-16
**Status**: In Progress
**Input**: User description: "AI 기술과 자동 매매의 장점을 살리는 다음 수익 전략 고도화를 이어서 진행해줘."

## User Scenarios & Testing

### User Story 1 - 더 많은 시장 정보로 주간 상대수익 학습 (Priority: P1)

운영자는 기존 3자산 월간 모델보다 빠르고 넓게, 11개 유동성 높은 ETF의 일봉에서 다음 주 상대수익을 학습하는 후보를 원한다.

**Independent Test**: 고정된 11자산 일봉을 입력하면 미래 누출 없는 주간 예측, 불확실성, 비중, 비용별 성과가 반복 실행에서 동일하게 생성된다.

### User Story 2 - 실제 KIS 시세로 자동 재평가 (Priority: P2)

운영자는 사람이 자료를 옮기지 않아도 서버가 KIS 읽기 전용 시세를 갱신하고 주간 후보 보고서를 발행하기를 원한다.

**Independent Test**: 제한된 SSH 명령 하나가 일봉 백필과 연구 실행만 수행하고 JSON·Markdown·후보 패키지를 사이드카에 남긴다.

### User Story 3 - 통과한 후보만 자율 루프에 연결 (Priority: P3)

운영자는 엄격한 기준을 모두 통과한 결과만 기존 자율 성장 루프의 작업 후보가 되기를 원한다.

**Independent Test**: `eligible=true`인 패키지만 작업 패킷이 되고 `NO_EDGE` 또는 `BLOCKED`는 증거로만 남는다.

## Requirements

> **안전 경계**: 연구와 후보 등록까지만 수행한다. live 전략, 주문, 자본, 허용 종목, 캡, 센티넬은 변경하지 않는다.

- **FR-001**: 고정 유니버스 `SPY, QQQ, EFA, EEM, IEF, TLT, LQD, GLD, DBC, VNQ, UUP`의 조정 일봉만 사용해야 한다.
- **FR-002**: 일봉을 거래 주의 마지막 관측값으로 주간 변환하고 1·4·13·26·52주 모멘텀, 변동성, 하방변동성, 낙폭, 추세거리, 횡단면 순위, SPY 상관·시장 폭 특징을 과거 자료만으로 만들어야 한다.
- **FR-003**: 최소 104주 학습, 26주 검증, 1주 purge, 겹치지 않는 8주 테스트의 확장형 워크포워드를 사용해야 한다.
- **FR-004**: 결정적인 Ridge와 얕은 Gradient Boosting을 학습하고 검증 오차와 모델 불일치로 예측 불확실성을 계산해야 한다.
- **FR-005**: 양의 하한 예측 상위 4개만 역변동성 배분하고 종목당 25%, 총 99%, 롱온리 상한을 지켜야 한다.
- **FR-006**: 회전율에 10·25·50bp 비용을 차감해야 한다.
- **FR-007**: 같은 날짜의 11자산 동일비중과 기존 다중속도 역변동성 추세 전략을 모두 비교해야 한다.
- **FR-008**: CAGR, 샤프, 최대낙폭, 회전율, 구간 승률, PSR, DSR, 예측 오차, 자료 범위와 지문을 보고해야 한다.
- **FR-009**: 후보 준비 판정은 최소 10개 테스트 구간, 25bp 양의 CAGR, 두 기준 대비 샤프 +0.20, PSR/DSR 각 0.95, 구간 승률 60%, 더 나은 기준보다 나쁘지 않은 최대낙폭, 50bp 양의 총수익을 모두 요구해야 한다.
- **FR-010**: 11개 종목 중 하나라도 1,200개 미만 일봉, 날짜 불일치, 비양수 가격, 누수, 모델 오류가 있으면 실패 폐쇄해야 한다.
- **FR-011**: 실제 서버 실행은 KIS 시세 조회와 로컬 연구 파일 쓰기만 허용하고 주문·취소 경로를 호출하지 않아야 한다.
- **FR-012**: 준비된 후보만 자율 작업 입력이 되며 이후에도 기존 `Backtest -> Canary -> Full`을 우회하지 않아야 한다.

## Success Criteria

- **SC-001**: 동일 입력의 판정·비중·지문이 결정적이다.
- **SC-002**: 모든 테스트 예측보다 학습 라벨이 과거임을 테스트가 증명한다.
- **SC-003**: 예측 가능한 합성 자료는 통과할 수 있고 잡음 자료는 통과하지 못한다.
- **SC-004**: 워크플로와 강제 명령에 주문 문자열 또는 live 설정 변경이 없다.
- **SC-005**: 실제 KIS 일봉 실행이 `DAILY_ML_EDGE_CANDIDATE_READY`, `NO_EDGE`, `BLOCKED` 중 하나를 자동 발행한다.
