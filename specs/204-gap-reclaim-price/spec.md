# Feature Specification: 하락 개장 후 회복의 연구용 검증

**Feature Branch**: `codex/204-gap-reclaim-price`
**Created**: 2026-10-02
**Status**: Draft
**Input**: 기존 한국투자 단타 프로그램 완성. 비용 후 탈락한 기존 후보를 승인하지 않고 다른 고정 가설을 실제 자료로 검증한다.

## User Scenarios & Testing

### User Story 1 — 결과 확인 전에 가설을 고정한다 (Priority: P1)

운영자는 개장 전 가격 급락이 개장 후 되돌려지는 경우가 거래 비용을 감당하는지 확인한다.
**Why this priority**: 기존 ETF 돌파·급락·거시 발표와 대형주 공시 지속 후보는 비용 후 탈락했다.
**Independent Test**: 고정 종목·기간·시각·규칙·비용·기존 시행 수의 지문을 실제 성과 확인 전에 커밋한다.
**Acceptance Scenarios**:
1. **Given** 고정 가설, **When** 가격 성과 확인, **Then** 모든 날짜·종목의 신호 부재와 누락도 남는다.
2. **Given** 손실 또는 표본 부족, **When** 판정, **Then** 값을 바꿔 다시 합격시키지 않는다.

### User Story 2 — 사용자 기기 사용을 방해하지 않고 검증한다 (Priority: P1)

원본 전체 지문을 확인해 필요한 시각의 관측만 원격 연구에 전달한다.
**Why this priority**: 전체 원본은 약1GiB이며 사용자 맥북에서 무거운 연구·전체 회귀를 수행하지 않는다.
**Independent Test**: 입력 변조, 순서·종목 불일치, 없는 관측, 반일장, 덮어쓰기를 거부하고 원격에서 재현한다.
**Acceptance Scenarios**:
1. **Given** 검증 원본, **When** 관측 축소, **Then** 원문 지문과 각 관측을 연결하고 없는 값을 만들지 않는다.
2. **Given** 전일 마지막 관측 누락, **When** 신호 검증, **Then** 더 이른 가격으로 대체하지 않는다.
3. **Given** 원격 실행, **When** 종료, **Then** 결과와 정확한 코드·입력 지문을 보존한다.

### User Story 3 — 가격 진단과 실사용 자격을 구분한다 (Priority: P1)

운영자는 개발 가격 진단의 탈락·표본 부족·후속 실행 모형 필요를 구분한다.
**Why this priority**: 참조 가격쌍은 실제 주문 체결이나 계좌 수익률이 아니다.
**Independent Test**: 양의 참조 수익이 있어도 실주문·승격·자본 표식이 계속 거짓/0인지 확인한다.
**Acceptance Scenarios**:
1. **Given** 기준·가혹 비용 양수와200쌍 이상, **When** 개발 진단, **Then** 실행 모형 검증 필요로만 표시한다.
2. **Given** 어느 비용이든 음수 또는 거래 수 부족, **When** 종료, **Then** 최종 확인 성과를 열지 않는다.

### Edge Cases

회사 계보 미확인 DD/UTX, source 조정 가격, 처음 거래일의 전일 누락,
휴일·DST·반일장, 중복·역순 관측, 잘못된 가격·거래량, 신호는 있으나 진입/청산 누락,
원본과 축소본 변조, 압축 폭탄, 입력 잠금 불일치, 출력 중복, 개발 이후 가격의 우발적 포함.

## Requirements

### Functional Requirements

- **FR-001**: 기존193/194 원본 지문을 고정하고 2014-03-03~2017-12-29 개발 기간을 사용한다. 이후 수익은 열지 않는다.
- **FR-002**: 공개된 역사 고정30종목에서 사전 제외 DD/UTX를 뺀28종목만 비교한다. 연구 범위는 실거래 허용 목록이 아니다.
- **FR-003**: 전일 정확한 정규장 마지막1분봉 종가 대비 개장가가2% 이상 낮고, 09:45 시작1분봉 종가가09:30 시작봉 시가보다 높을 때만 신호를 만든다. 전일·개장·신호 관측이 없으면 누락을 남긴다.
- **FR-004**: 신호봉 완료09:46 이후09:47 시가와15:56 시가를 양의 거래량에서 참조한다. 신호 부재를 미래 진입·청산 가격 존재 여부로 바꾸지 않는다.
- **FR-005**: 기준 편도31bp·가혹40bp를 각 매수/매도에 한 번 적용하고 같은 가중치 가격쌍 평균을 계산한다. 최소200쌍 및 양비용 양수를 유지한다.
- **FR-006**: 모든 날짜·종목의 상태를 보존한다. 누락을 채우거나 완전한 날만 다시 선택하지 않는다. 반일장15:56 관측 없음도 남긴다.
- **FR-007**: 축소 관측을 만들 때 원본 전체 지문·정렬·종목을 검증하고 원본 행을 그대로 사용한다. 축소본 지문을 성과 실행 전 별도로 잠근다.
- **FR-008**: 연구 결과는 실제 체결·현금·결제·용량·과거 공개 시각의 인증이 아니다. 신호·참조 가격쌍·누락·후속 모형 필요를 분리하고 실자본 표식은 계속0/거짓이다.
- **FR-009**: 기존 연구 시행 수 최소33과 이번 한 후보를 기록한다. 새 모형의 양수 결과는177·181의 합격을 대신하지 않는다.
- **FR-010**: 무거운 검증과 가격 진단은 원격에서 수행한다. 로컬은 낮은 우선순위와 명시적 쉬는 구간을 둔 자료 전달 준비·작은 반례만 수행한다.
- **FR-011**: 계좌·주문·허용 목록·자본·승격·거래 감사·외부 요청 제한·배포 제한은 변경하지 않는다. 출력은 기존 파일을 덮어쓰지 않는다.

### Key Entities

사전등록 가설, 원본 지문, 축소 관측·별도 잠금 지문, 거래일별 상태, 참조 가격쌍,
두 비용 조건, 원격 실행 증거, 후속 실행 검증 필요 상태.

## Success Criteria

- **SC-001**: 성과 확인 전 고정 가설과 입력 지문 커밋을 보존한다.
- **SC-002**: 모든 개발 종목·거래일을 신호 없음·필수 관측 없음·참조쌍으로 재현 가능하게 분류한다.
- **SC-003**: 별도 산술 재계산과 원격 반복 실행이 같은 상태·비용별 결과를 만든다.
- **SC-004**: 변조·누락·반일장·미래 정보·덮어쓰기 반례에서 허위 성공0건이다.
- **SC-005**: 실제 주문·자본 변경·비밀값 출력0건, 맥북 화면 조작·무거운 로컬 검사0건이다.

## Assumptions

위험 등급2의 새 독립 연구 도구이며 전체 SDD를 적용한다. 규칙은 회복 가능성을
검사하는 가설이지 알려진 수익 사실이 아니다. 가격 조정과 기업 연결 미인증은
그대로 기록한다. 연구 단계의 합격 경계·177 통계·실거래 권한은 수정하지 않는다.
소프트웨어 출시와 후보 개발 통과는 다른 결론이며 전체181 T013~T016은 열린다.
