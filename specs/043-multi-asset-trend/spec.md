# 스펙 043 — 멀티에셋 분산 추세추종 (검증된 엣지를 세계 최고 수준 차원으로 확장)

## 한 줄 요약

검증된 단일 자산 추세 방어(스펙 042)를 **두 비상관 자산(주식 베타 + 채권 듀레이션)에 각각
추세 오버레이를 얹어 합치는** 멀티에셋 분산 추세추종으로 확장한다. 추가 데이터 없이 Shiller
GitHub CSV의 10년 국채 수익률로 채권 총수익 프록시를 만들어 1871~현재(대공황 포함)로 검증한다.

## 동기 (우선순위 판단)

정직한 현 상태:

1. **종목 선택 알파 = 측정상 0** (스펙 041, 정보계수 IC≈0). 가격 팩터로 인덱스를 못 이긴다.
2. **유일하게 끈질긴 엣지 = 추세추종의 자본 방어** (스펙 042, Shiller 155년 9/9 견고).
3. 그러나 그 엣지가 지금은 **단일 자산군(미국 주식 베타)** 에만 적용된다. SPY·QQQ 는 사실상
   같은 자산(상관 ~0.95). 단일 지수 추세 타이밍은 소매(retail) 수준이다.

세계 최고 수준과의 진짜 격차 = **멀티에셋 분산 추세추종**. 금융에서 가장 크고 끈질긴 "공짜
점심"은 비상관 수익 흐름의 분산이다(Faber GTAA; AQR/Man-AHL managed futures). 여러 비상관
자산에 각각 추세 오버레이를 얹고 합치면, 추세 신호가 서로 다른 시점에 켜지고 자산 자체가
비상관이라 단일 자산 추세보다 위험조정 수익(샤프·칼마)이 더 높다.

## 데이터 (제약 안에서 정직하게)

이 컨테이너는 GitHub 만 닿는다(SEC·야후·FRED 차단). 그런데 스펙 042 가 쓰는 그 Shiller CSV
(`datasets/s-and-p-500`)에 **10년 국채 수익률(Long Interest Rate)이 1871년부터** 들어있다.
그 수익률 시계열로 *상수만기 10년 par 채권 총수익 프록시*를 만들면, 두 번째 비상관 자산을
추가 데이터 없이 검증할 수 있다.

## 범위

- **슬라이스 1 (연구·증명)**: `analytics/multi_asset_trend.py` — 채권 총수익 프록시 +
  일반 추세 신호(임의 레벨) + 슬리브/블렌드 + 분산 비교(`compare_diversified_trend`) +

## 비목표 (안전 경계)

- **라이브 자동 승격 0건.** 페이퍼/연구 전용 — 주문 0건, 돈 0 이동. 라이브 전환은 운영자
  게이트(헌법 X.4)이며 이 스펙의 범위가 아니다.
- Kernel(K1~K6) 터치 0건. analytics/scripts/설정만 추가.

## 합격 기준 (사전 등록)

- `DIVERSIFICATION_EDGE`: 분산 추세가 단일 주식 추세 대비 ① 샤프↑ ② 칼마↑ ③ 최대낙폭
  비악화. 셋 다여야 한다.
- 견고성: SMA 창(7/10/12) × 가중(50:50, 60:40) × 구간(전체/현대/최근) 다수에서 일관.
- 정직성: 분산이 CAGR 을 낮추면 그대로 보고(위험조정 우위 ≠ raw 수익 우위).

  비교는 공정).
