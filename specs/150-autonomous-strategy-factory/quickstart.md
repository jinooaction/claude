# Quickstart: 자동 전략 공장과 연구 캐너리

1. 고정 fixture로 64개 후보 생성과 지문 재현을 확인한다.
2. 합성 구간 수익으로 DSR과 PBO 기준 미달이 승자를 제거하는지 확인한다.
3. 공개 주식·채권·금 자료로 공장 probe를 실행해 실제 64개 결과를 발행한다.
4. 선택 후보 TOML을 로더와 exact fingerprint로 검증한다.
5. 완전 합격 fixture에서만 자본 사다리가 NAV 10% 단 1을 결정하는지 확인한다.
6. 40개 forward 관측 전에는 10% 초과가 차단되는지 확인한다.
7. 전체 시험, 린트, 헌법·커널 표시, workflow, 하네스와 HANDOFF를 검증한다.
