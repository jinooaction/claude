# 보관 자료 연구 연결

입력은 `--archives` 폴더 바로 아래 YYYY-MM-DD 보관 폴더다. 모든 폴더의 manifest,
source.json, 5종목 CSV 지문과 완결 거래일을 검증한다. 중복 날짜와 정상 날짜 폴더의
미완 자료는 거절한다. 기존 수집기의 YYYY-MM-DD-partial-32자리식별자 폴더만
incomplete_archive_count로 공개하고 거래일 수에서 제외한다. 원본을 읽어 비공개 임시
스냅샷으로 검증하며 심볼릭 링크는 거절한다. 원본의 bars와 CSV 내용도 대조한다.
동일 공급자·합성 여부·수정 정책만 결합하고 결합 자료에도 원본 지문을 남긴다.

출력 폴더는 새로 만들며 기존 경로를 덮어쓰지 않는다. manifest.json과 연구 보고서·
모의 체결 장부를 생성한다. 완료 표식 review.json은 마지막에 생성한다. 중도 실패 폴더는
완료로 표시하지 않고 원인 조사용으로 보존한다. 결과에는 실제 완결 거래일 수, 필요 거래일 수,
부족 일수, 보관 기간 내 빠진 거래일 수, 연구 판정과 원인, live_eligible=false,
orders_submitted=0을 제공한다. 중간 거래일 누락은 연구 판정의 자료 품질 실패로 남긴다.
이 명령은 과거 연구이며 실주문 가동이나 정식 전진 관측이 아니다.
