# 실제 원본 계약의 남은 증거 — 2026-09-13

이 문서는 소프트웨어 완료 선언이 아니다. 전체 과거 내역·화면 접근·문의는 필수 조건이
아니다. 현재 확인한 원본 정의에서 확정 가능한 계산과 아직 입증하지 못한 의미를 구분한다.

## 시작 순현금과 거래 이후 변동

공식 foreign-margin 상세 JSON의 응답 속성을 다시 조회했다.

- frcr_dncl_amt1: 외화예수금액. 설명은 공백.
- ustl_buy_amt / ustl_sll_amt: 미결제매수/매도금액. 설명은 공백.
- frcr_rcvb_amt / frcr_mgn_amt: 외화미수/증거금액. 설명은 공백.
- frcr_ord_psbl_amt1: 원화주문가능환산금액이라는 설명이 있어 USD 순현금으로 사용 불가.

FR057/061/062에서 조건부 계산은 구현됐다. 전후 단일 USD 사용가능금액+증거금이
반복 예수금 보고와 일치하고 증거금도 독립 대조되며 미수가0인 경우,
`예수금 + 미결제매도 - 미결제매수`를 계산한다. 미체결 증거금을 다시 차감하지
않는다. 미수 차감의 일반식, 미결제 구성의 수수료 포함 관계와 조건 밖의 보고
표시 방식은 아직 입증하지 않았다. 계산기 구현 완료와 전체 순현금 인증을 구분한다.

현재잔고의 frcr_dncl_amt_2는 공식 설명이 '외화로 표시된 외화사용가능금액'이다.
이를 모든 부채/미결제를 반영한 순현금으로 바꾸면 구매력과 순현금을 혼동한다.
frcr_etc_mgna와 tot_loan_amt에는 추가 계산 설명이 없다. FR061은 국내 원화
예수금을 현재 보고의 tot_dncl_amt와 대조하고 출처가 명시된 보고 환율로 USD 평가한다.
FR063은 국가 전체 현재 보유와 일반 미국 보유를 수량/시장/통화로 대조한다.
FR064는 국내/미국/자산표 조회를 하나의 CURRENT 전후 구간에 묶었다.
남은 것은 이 조건부 입력들의 전체 자산 범위 및 거래 후 비용 포함 관계를 입증해
정상 공급자의 전체 계좌/현금 검증 판정에 연결하는 일이다. 검증값은 아직 false다.

### 확인된 갱신 지연과 계산 모델에 미치는 영향

현재잔고 API 상세 원본의 `apiSummary`는 수수료를 포함한 최종 정산금액이 미국장
종료 후 처리되며, 처리 지연과 애프터연장 신청 여부에 따라 반영 시간이 달라진다고
명시한다. 미국 거래는 별도 시스템을 사용하므로 일반/통합증거금 계좌의 보유도
미국장 종료 후에 반영될 수 있다. 같은 숫자가 전후 조회에서 반복된다는 사실은
거래가 모두 반영됐다는 증거가 아니다. 특정 한국 시각을 넘겼다는 사실만으로
최종 정산 완료를 인증할 수도 없다.

따라서 단타 중간 상태를 CURRENT와 매번 정확히 일치시키는 방식만으로 완성할 수
없다. 검토할 다음 모델은 대조된 시작 잔고에 우리 주문의 누적 체결 변화를 한 번만
적용하고, 수수료는 확정값과 미확정값을 구분한 뒤 최종 거래명세로 정산하는 방식이다.
CURRENT는 장중 체결의 즉시 반영 증거가 아니라 후속 대조 원본으로 사용한다.
이것은 아직 구현된 계약이 아니다. 적용 전에 다음 반례를 해결해야 한다.

- 외부 주문·입출금·환전과 우리 주문의 변화를 구분하고 불명 차이를 차단한다.
- 부분 체결과 재조회·재시작에서 같은 누적 체결을 두 번 차감하지 않는다.
- 거래명세의 순정산금액으로 바꿀 때 수수료를 다시 차감하지 않는다.
- 미확정 수수료를0으로 간주하지 않는다. 비용 한계를 입증하지 못하면 신규 진입은
  거절하되 기존 주문의 관측·복구를 어떻게 유지할지 별도로 검증한다.
- 실제 체결 시각을 만들지 않고 이미 구현한 관측 구간·거래량 검증을 유지한다.

## 체결·비용 자격

CTOS4001R은 trad_dt/sttl_dt, tr_frcr_amt2, frcr_excc_amt_1,
dmst_frcr_fee1/frcr_fee1을 제공한다. 현재 확인한 응답 속성에는 주문번호가 없다.
eb22ad4에서 단일 전략의 종료 주문 집합과 종목/방향별 단일 주문의 비용 대조를 실제
인증 GET→SQLite→prepare_qualification에 연결했다. 계좌·연구/실행 지문·조회 기간·
운영 승인 참조를 계산 결과에 묶는다. 이 연결은 이제 미구현이 아니다.
FR049~055에서 인증된 원본 봉, 원문 주문일, 주문 수량, 관측 구간, 묶음 거래대금과
수수료를 같은 증거로 대조해 실행 모델 적합성을 계산하도록 연결했다. 단순한 고정
미구현 차단은 남아 있지 않다. 실제 자료가 없거나 대조가 실패하면 자격을 거절하며,
모의 검사 통과를 실제 계좌의 실행 적격 증거로 대신하지 않는다.

2026-09-11 공식 체결통보 속성 원본을 재조회했다. STCK_CNTG_HOUR 설명은 특정
거래소의 시각 미수신과 수신 타임스탬프 대안을 명시한다. 수신 시각을 실제 체결 시각으로
승격하지 않는다. CNTG_YN=2만 체결이며 CNTG_QTY도 이때 체결 수량이다. 통보 구독만
추가하면 과거의 시간·거래량 증명이 완성된다는 결론은 근거가 없다. 별도 시간 증거나
관측 구간을 사용하는 모델 계약과 원본 재생이 필요하다. FR045/046에서 구간 계산과
동일 전진 장부의 완결 봉 자동 소비를 구현했다. FR049/055는 시장 원본 인증과
관측 모델 조건을 최종 자격 검사에 연결했다. 이 소프트웨어 연결과 실제 계좌의
합격 증거 확보를 구분한다. 정확한 체결 시각이 없다는 사실만으로 불가능 판정을 하지 않는다.
