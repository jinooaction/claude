## 실제로 막힌 연결

`KISExecutionObserver._read`는 같은 주문 권한의 인증을 갱신한 뒤
`observe_account`를 호출한다. 이 실제 입력기는 현재 전체 계좌 범위와 현금 집계 검증을
참으로 반환하지 않는다. 따라서 `build_observation`에서 거절되며, 내부 정상 입력 시험이
통과하더라도 실제 제공자가 완성된 것으로 보지 않는다. T009/T010을 미완료로 유지한다.

다음 구현에 필요한 것은 원본의 저장 위치 또는 사용할 수 있는 조회 경로와 실제 자료의
범위다. 확인 후 통화, 기준 시점, 결제·미결제, 채무와 중복 포함 여부를 정규화하고 같은
시작 경로의 정상·누락·오래된 자료·재시작 시험을 수행해야 한다. 화면 접근이나 평생 거래
내역은 보편적인 필수 조건이 아니다. 검증된 시작 상태와 그 이후의 완전한 변경 내역도
대안이지만, 기존 서버의 일부 체결 이력만으로 현금 변경 전체가 증명되지는 않는다.

## 안전 경계와 되돌림

고정된 미구현 실행 모델 표시는 실제 계산 결과를 모두 확인하는 검사로 대체했다.
알 수 없는 새 조건, 원본 불일치, 미종료 주문, 누락된 승인에 대한 거절은 유지한다.
구매력을 순현금으로 바꾸거나 미평가 자산을 0으로 처리하지 않는다.
이 작업에서 실제 주문·취소·자본 배분·승인 파일 발급은 수행하지 않았다.
PR793은 초안이며 main 배포는 하지 않았다. 되돌림은 해당 기능 커밋을 별도 되돌림
커밋으로 처리하고 변경된 코드 지문으로 기존 자격을 재검사하는 방식이다.

전체 회귀 검사 수치와 제외 항목은 `validation.md`의 해당 코드 기준 기록을 따른다.
검사 통과 자체가 위 두 미완료 항목의 대체 증거는 아니다.
