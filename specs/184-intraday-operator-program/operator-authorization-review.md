기존 한국투자 계좌와 FR070 고정 예산 방식에 대해 전략 검증을 실행하고, 실제

승인으로 해석하지 않는다. 이 문서는 실행 권한 파일이 아니며 실행기는 읽지 않는다.

## 처리 기준

현재 main98c96bb는 인계 문서 변경이고 실행 코드9c818fc/main8966780과 동일하다.
서버 상태 조회34767799668에서 실제 설치8966780, 수집 타이머 active,
서비스 success, 최근 완결 보관일2026-09-11을 확인했다.

`select_research`는 보관 원본에서 후보를 다시 선정한다. 후보가 없으면
`prepare_qualification`은 연구 결과를 거절하며 운영자 동의로 바꾸지 않는다.
후보가 선정되면 서버 서명 고정 등록, 등록 후60세션, 실제 체결 구간·수량·비용
대조, 같은 계좌/예산/런타임/연구 식별자, 강화된 사전 운용 검사와 배포 근거를
확인한 뒤 보호된 서버 승인 파일에 연결한다. 근거 해시를 임의 값으로 채우지 않는다.

진단 서비스의 `qualified_forward_sessions=0`은 고정 진단값이므로 실제 승인용
장부를 전수 조회한 결과로 쓰지 않는다. 같은 서비스의 `LIVE_ADAPTER_NOT_IMPLEMENTED`
문구도 FR070 실행기의 미구현 증거가 아니다. 연구 자료 부족 여부는 별도 실제
보관 자료 검사의 개수와 판정으로 확인한다.
