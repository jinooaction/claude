# 기능 명세: 단타 사용자 실행 프로그램

- **FR068**: 부분 체결의 평균가격 나눗셈에서 발생하는 소수 오차를 원래 거래대금과
  구분한다. 신규 체결은 증권사 누적 평균가격×누적 수량에서 기존 누적 거래대금을
  뺀 정확한 추가 거래대금을 별도 저장한다. 원래 누적값·수량과 출처를 감사 가능하게
  보존하고 재조회·현금/비용 대조·단타 손익은 이 거래대금을 소비한다. 기존 행은
  수정하지 않으며 금액을 제공하지 않은 옛 기록을 원본 인증값으로 승격하지 않는다.
  임의 허용 오차로 금액 불일치를 숨기지 않는다. 전체 계좌/수수료 인증은 별도다.

- **FR067**: 누적 체결 수량이 늘지 않은 재조회에서도 기존 장부의 거래대금과
  증권사 누적 평균가격×수량을 대조한다. 금액 누락·변경·비정상 가격은 경고로
  반환하고 해당 주문의 종료 전이를 보류한다. 기존 체결을 수정하거나 차이를
  새 체결로 만들지 않는다. 단타 실행기의 기존 동기화 불확실 차단에 연결한다.
  이는 자체 현금 계산의 입력 보정이며 전체 현금/수수료 인증을 대신하지 않는다.

- **FR066**: 거래내역 CTOS4001R의 거래소 필터를 현재 공식 요청 명세의 공백으로
  고정한다. 기존 미국 거래소 제한은 없애고 다른 통화의 원본도 보존해 통화별로
  계산한다. 미지원 필터는 요청 전에 거절한다. 모든 페이지와 정상 실행/읽기 명령이
  같은 필터를 사용해야 하며 등록일 범위를 거래일 완전성이나 전체 현금 인증으로
  승격하지 않는다. 기존 비용/주문 대응 검사를 유지한다.

- **FR065**: 현재 현금/보유 대조와 같은 관측 구간의 전체 자산표를 결합한다.
  일반20행 분류표의 모든 숫자와5열 합계를 검증하고 해외주식/외화/예수금 이외의
  자산 및 별도 채무/청약/담보 항목은0이어야 한다. 예수금 분류와 요약을 현재 KRW
  현금에 대조하며 해외주식 분류의 존재는 현재 보유 수량 대조와 맞아야 한다.
  보고서 변경·누락·부분 응답·잘못된 합계·지원 외 상품은 거절한다. 결제 기준 분류
  대조 결과를 현재 전체 자산 시점 인증이나 거래 후 비용 인증으로 승격하지 않는다.

- **FR055**: 최종 자격 검사는 인증된 같은 원본의 시간/거래량/수량/가격/수수료 결과와
  날짜/장부/거래내역 대조를 함께 요구한다. 과거의 고정 미구현 표시를 단순 삭제하거나
  사용자 합격 값을 받지 않고 프로그램이 재계산한 결과와 계좌/전략/비용 지문을 확인한다.
  하나라도 누락/불일치면 거절한다. 이 판단은 주문 이후 실행 모델의 적합성이며 전체 계좌
  인증이나 전략 승격 자체가 아니다. 기존 연구/전진/별도 운영 승인/잔고·위험 검사는 유지한다.
  미체결 주문도 원문 주문일이 신호의 뉴욕 거래일과 같아야 한다. 원래 주문 수량보다
  적게 체결됐는데 증권사가 종료를 확인하지 않으면 잔량0 표시만으로 닫힌 주문으로 보지 않는다.

- **FR054**: 반복 주문의 수수료를 주문별로 임의 배분하지 않는다. 원본 주문일이
  확인된 경우 같은 거래일/종목/방향의 주문과 거래내역 수량·대금을 대조하고 묶음
  수수료를 해당 주문들의 다음 봉 기준 대금 합에 비교한다. 날짜 불명 다중 주문,
  묶음 누락/중복/다른 날짜의 상쇄는 거절한다. 기존 단일 주문 진단은 유지한다.

- **FR053**: 원본 주문 수량을 장부/의도 수량과 대조하고 미체결 주문까지 포함한
  전체 조회 주문의 실제 체결 수량을 min(주문 수량, floor(다음 봉 거래량×참여율))과
  비교한다. 누락 수량/중복 주문/원본 봉 누락/강제 정리 의도는 모델 일치로 취급하지
  않는다. 이 수량 결과도 동일 자격 준비에서 소비하며 전체 실행 승인은 별도로 유지한다.

- **FR052**: 엄격한 체결 조회는 주문 날짜 원문을 시각과 분리해 보존한다. 불확실한
  주문 시각을 UTC로 해석하지 않는다. 같은 주문의 날짜 충돌/잘못된 날짜는 거절하며
  비용 대조는 보존한 날짜와 매매일을 비교한다. 날짜 누락은 미검증이며 같은 날짜가
  나온 것만으로 등록일 조회의 전체 거래 범위나 실제 체결 시각을 인증하지 않는다.

- **FR051**: 같은 인증 조회·장부 대조의 실제 평균 체결가와 보고 수수료를 같은 원본
  다음 봉 시가에 대한 연구 기본 비용 한도와 비교한다. 매수/매도의 불리한 가격 방향과
  수수료 기준 대금을 구분하고 Decimal로 계산한다. 시간 구간이 다음 봉에 포함되지
  않거나 원본/가격/수수료가 누락되면 검증하지 않는다. 부분 비용 검증을 전체 동등성이나
  실행 승인으로 바꾸지 않으며 원본 비용과 모델 입력 지문을 함께 보존한다.

- **FR050**: 신규 실행 의도에 원래 신호의 봉 종료 시각과 주문 종류를 보존한다.
  전략 청산을 재시작/재주문할 때도 최초 청산 신호 시각을 유지한다. 전송 전부터 실제
  응답 수신까지의 모든 체결 가능 구간이 신호 직후5분 봉 안에 있을 때만 다음 봉 시점
  조건을 확인한다. 과거 기록의 누락 시각이나 강제 정리 시각을 정상 신호로 추정하지 않는다.
  시점 조건과 거래량 조건을 각각 보고하며 전체 계좌/전체 실행 동등성으로 승격하지 않는다.

- **FR049**: 선택적 서버 수집 증명은 프로그램이 직접 연 KIS 인증 GET에서 생성한다.
  고정 서버 키와 수집 코드 지문으로 정규화된5종목 봉·수집 시작/수신 시각을 서명하고
  모의 장부와 독립 재생을 거쳐 자격 검사까지 전달한다. 사용자 봉/과거 파일을 서명하는
  명령은 제공하지 않는다. 서명 없는 진단 기록은 보존하며 출처 인증으로 승격하지 않는다.
  서버 수집기와 키 관리자를 신뢰하는 증명으로, KIS가 발급한 전자서명이나 실행 승인이 아니다.

- **FR048**: 비용 증명의 지문은 명시된 검증 기간의 원본 주문·체결·상태·감사만 포함한다.
  기간 밖의 과거 기록이 추가돼도 같은 증명의 승인 참조가 바뀌지 않아야 한다. 기간 안의
  모든 계좌 주문을 대조하고 다른 전략 혼입/불일치/조회 중 장부 변화는 계속 거절한다.

- **FR047**: 실제 체결 GET 완료 직후 잡은 수신 시각을 신규 체결 감사에 별도 저장한다.
  논리적 틱 시각과 기존 체결 시각은 보존한다. 재시작 후 같은 주문의 모든 장부 체결과
  수량/가격/체결번호가 일치하는 수신 기록만 구간 상한을 좁히는 데 사용한다. 일부 누락,
  중복, 불일치, 잘못된 시각이면 현재 GET 수신 시각의 넓은 구간을 유지한다. 과거 행을
  재작성하거나 새 필드 없는 시각을 수신 완료로 해석하지 않는다.

- **FR046**: 서명된 고정 기록 검증과 독립 재생에 사용한 동일 장부 스냅샷에서 완결
  거래일의 원본 봉만 구간 모델에 전달한다. 별도 DB 재조회나 사용자 합격 보고서를
  사용하지 않는다. 실제 prepare_qualification이 구간 모델을 호출하고 결과와 입력
  지문을 보존한다. 자료 부족/구간 오류는 명시적으로 보고한다. 재생 일치는 시장 원본의
  암호학적 출처 인증과 다르며 기존 전체 실행 자격 차단을 해제하지 않는다.

- **FR044**: 원본 foreign-margin에서 USD로 분류된 단일 행에 미결제매수/매도·미수·
  증거금이 모두0이고 미분류 행이 없을 때만 보고된 USD 결제 현금을 계산한다. 범위는
  해당 보고 행이며 계좌 전체 범위나 주문가능 현금 인증을 부여하지 않는다. 금액 누락·
  비정상·음수·중복·미결제/부채가 있으면 금액 없음과 원인을 반환한다.
- **FR045**: SUBMITTING의 전송 전 장부 기록부터 실제 양수 체결 조회 응답 수신까지를
  체결 가능 구간으로 보존한다. 응답 수신 시각을 정확한 체결 시각으로 바꾸지 않는다.
  완결된5분 봉이 구간 양끝을 포함해 모두 있어야 하며 가능한 각 봉에 겹치는 동일 종목
  주문들의 전체 체결 수량 합계가 그 봉 거래량×참여율 이하여야 한다. 불명확한 체결을
  유리한 봉에 배분하지 않는다. 이 구간 모델 통과는 원본 시세 인증이나 기존 연구의
  정확한 다음 봉 체결 동등성을 대체하지 않는다.

- **FR043**: 실행 계좌의 인증된 주문체결/거래명세 GET과 동일 실행 장부를 실제 자격
  검사에 연결한다. 계좌·전략·실행 코드·조회 기간·원본 금액에 묶인 계산 지문을 운영
  승인 참조와 비교한다. 같은 기간 단일 전략의 종료 주문 전체가 대응하고 종목/방향별
  체결 주문이 하나일 때만 비용 상한을 대조하며 여러 주문에 수수료를 임의 배분하지 않는다.
  수량/금액/정산 산술/지정가 대조와 실제 체결 시각·모델 거래량 증명은 별도 조건이다.
  후자가 없으면 비용 대조가 맞더라도 실행 자격으로 승인하지 않는다. 평가 대상은 외부
  기준 보유와 공용 current_positions의 합집합이며 공용 보유를 외부 기준에 중복하지 않는다.

- **FR042**: 전략 주문용 시세5종목과 기존 보유 평가용 시세를 분리한다. 기존 보유의
  상장 거래소는 실제 조회 응답으로 탐색하되 조회 가격/수신 시각을 실행 평가에 쓰지 않는다.
  동일 실시간 연결의 원본 발생 시각 가격을 소비자별로 나눈다. 허용 주문 종목과
  전략 시세의 정확한5종목 검사는 유지한다. 조회/구독 실패·노후 가격은 차단하며 OTC
  가격을 다른 거래소나0원으로 대체하지 않는다. 연결은 실행 잠금 뒤 시작하고 함께 닫는다.
  전략5개를 포함한 전체 구독은40개 이하이며 별도 두 웹소켓의 동시 사용을 전제하지 않는다.

- **FR041**: 계좌 개설 이후 전체 내역을 시작 조건으로 요구하지 않는다. 관측 시작부터
  동일 계좌의 GET 응답 데이터·조회 조건·수신 시각을 비공개 추가 전용 장부에 보관하고
  재실행 시 이어 쓴다. 기존 주문/체결/감사 장부는 수정 없이 전후 순번을 함께 기록한다.
  실패·부분 응답은 FAILED로 남긴다. 원본 확보와 시작 순현금/전체 범위 검증은 구분한다.
  인증 헤더·서버 자유문구는 저장하지 않고 공개 출력은 건수·상태만 포함한다. 과거 체결을
  시작 잔고에 다시 반영하거나 로컬 순번을 증권사 사건의 완결성으로 사용하지 않는다.

## User Scenarios & Testing

### 사용자 이야기 1 — 한 실행 창에서 운용 (P1)

사용자는 한국투자 기반 모의 운용을 시작하고, 다른 창에서 상태를 보거나 중지한다.
기존 장부를 그대로 이어 쓰며 중복 실행은 거절한다. Alpaca 계정은 필요 없다.

**독립 검증**: 임시 작업 폴더에서 시작·중복 시작·상태·중지·재시작을 실행하고
이전 장부가 유지되며 중지 요청 후 새로운 수집 주기가 시작되지 않는지 검사한다.

### 사용자 이야기 2 — 실제 발생시각이 있는 시세 (P1)

사용자는 실제 KIS 웹소켓에서 허용 종목의 가격과 발생시각을 확인한다.
끊김·잘못된 응답·오래된 가격은 현재 정상 시세로 표시하지 않는다.

**독립 검증**: 로컬 웹소켓 서버가 복수 체결·구독 응답·연결 종료·이상 프레임을
보내며 실제 네트워크 전송, 신선도 검사, 캐시 폐기를 검증한다.

### 사용자 이야기 3 — 해당 주문의 구매가능 상한 (P2)

사용자가 종목과 지정가를 입력하면 그 요청 그대로 외화 구매가능 금액과 정수 수량을 조회한다.
종목을 고정한 샘플 조회나 통합증거금 대체값을 사용하지 않는다.

**독립 검증**: 요청 파라미터와 금액·수량 계약, 오류·누락·지연 거절을 가짜 HTTP로 검증한다.

### 경계 사례

- 장 휴일·폐장에는 다음 거래 시간을 기다리며 프로세스 생존과 가격 신선도를 구분한다.
- `stop`은 모의 운용 수집 중지이며 보유 청산이 아니다. `execution-stop`은 별도
  주문 운용기의 정리 요청이며 증권사 대조가 끝나기 전에는 정리 완료로 표시하지 않는다.
- 구독하지 않은 종목, 25필드 예제, 암호화 프레임, 틀린 건수, NaN, 시간대 불일치는 거절한다.
- 체결 발생시각과 수신시각은 별도 보존한다. 미래·30초 초과·역행 체결은 실행용 캐시에 없다.
- 비밀값·계좌번호·원본 오류 본문은 공개 상태에 남기지 않는다.

## 운영자 정정 반영 — 프로그램 완성과 실제 투자 분리

2026-09-09 운영자는 실제 투자 실행이 아니라 사용 가능한 프로그램 완성을 요청했다.

미검증 입력을 정상값으로 바꾸지 않으며 미구현 연결도 외부 조건 탓으로 숨기지 않는다.

- **FR-036**: 내부 계좌 공급자가 net_cash_and_listed_equities 평가 기준을 명시한 경우

  순현금은 미결제 매매·비용·입출금·환전·배당·채무 등 모든 비주식 잔액을 반영한 USD
  값이며 주문가능 현금(execution_cash)과 구분한다. 전체 계좌 범위와 현금 검증은
  여전히 필수다. 이 경로에서 보고 순자산이나 nav_verified를 계산 근거로 쓰지 않는다.
  누락 가격·미검증 자산·누락 순현금·유효하지 않은 합계는 거절한다. 모든 보유를 평가하며
  단타 허용 종목만 더하지 않는다. 원본 가격 시각은 유지하고 가격 주문 전 신선도 검사를
  보존한다. 공급자의 검증은 내부 계약이며 사용자 파일이나 옵션으로 발급하지 않는다.

- **FR037**: 내부 공급자의 `cash_ledger_and_listed_equities` 경로는 원본 순서 번호가
  보존된 USD 순현금 사건을 시작 잔액부터 재계산하고 매 사건 후 잔액과 최종 잔액을

- **FR060**: 국내 현재잔고도 정상 KIS 계좌 입력에서 동일 인증/계좌로 읽어 보존한다.
  국내 보유·대출·현금의 현재 보고와 결제 기준 전체 자산표를 구분한다. 새 읽기 소스는
  실행 지문에 포함하며, 국내 조회 성공만으로 전체 계좌 범위/순현금을 승인하지 않는다.
- **FR061**: 동일 인증의 USD 시작 잔고와 국내 현재잔고를 원화/달러로 분리해 보존한다.
  USD 전후 보고의 총예수금과 국내 예수금이 일치하고 국내 정산액/순자산/총평가가 같으며
  다른 확인한 구성·매매·채무가0인 경우만 해당 현금 범위를 계산한다. 두 USD 통화 행의
  최초고시환율이 동일·양수일 때만 명시적 보고 환율 정책으로 USD 평가를 산출한다.
  원화가 음수이면 그대로 채무성 현금으로 포함하고12자리 내림을 명시한다. 반복 보고는
  합산하지 않으며 조회 시각을 환율 발생 시각으로 만들지 않는다. 전체 계좌 범위,
  거래 후 미결제 순현금, 주문가능금액과는 별도이며 기존 실행 승인 조건을 유지한다.
- **FR062**: 동일 계좌의 전후 USD 사용가능금액/매수·기타 증거금과 통화별 예수금/
  증거금 보고가 일치하는 경우, 보고 미결제 매수·매도 금액을 별도 현금 구성으로
  보존하고 `예수금 + 미결제 매도 - 미결제 매수`를 계산한다. 주문 증거금을 자산에서
  다시 차감하지 않는다. USD 반복 행의 예수금/증거금은 독립 단일 통화 보고와 일치해야
  하고 모든 보고 미결제 구성도 동일해야 한다. 누락·불일치·미수·다른 통화의 현금은
  계산 불가다. 기존0조정 계산은 유지하고 새 계산을 정상 원화/달러 평가에 연결한다.
  이 조건 밖의 증권사 표시 방식, 미결제 금액의 수수료 포함 관계, 전체 자산 범위는
  이 산술만으로 인증하지 않는다. 실제 주문·자본 배분·계좌 승인 조건은 유지한다.
- **FR063**: 기존 국가 전체 CURRENT 조회의 보유를 별도 정규화하고 일반 미국 잔고와
  수량·통화·시장 범위를 대조한다. 체결 기준 수량을 사용하며 결제 기준 수량으로
  대체하지 않는다. 전후 수량/매도가능/대출/시장 변화는 거절하되 가격 움직임을 수량
  변화로 오인하지 않는다.0수량/소수 수량을 원본대로 보존하고, 양수 보유의 누락이나
  다른 통화·시장을 제외해서 일치시키지 않는다. 이것은 해외 주식 범위의 대조이며
  국내/기타 자산·현금·전체 계좌 인증을 대체하지 않는다.
# FR064 하나의 계좌 관측 구간

국가 전체 현재잔고 전후 조회 사이에 미국 잔고/미체결/주문가능/증거금,
국내 현재잔고, 전체 자산 분류표를 수집한다. 동일 계좌와 인증 연결을 요청마다
재검사하고 전체 30초 제한을 적용한다. 실제 받은 증거금 응답을 재사용하며
재사용 응답에 새 수신 시각을 붙이지 않는다. 전후 현재잔고가 감싸는 국내/미국
조회는 현금·보유 대조에 사용할 수 있다. 부분 겹침·역순·오래된 조회는 거절한다.
전체 자산 분류표의 결제 기준과 전체 계좌 실행 인증은 구분한다. 실제 주문,
자본 배분, 인증 실패 무시, 전체 범위/현금 검증 표시의 자동 승격은 하지 않는다.
