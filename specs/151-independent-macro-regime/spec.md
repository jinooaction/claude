# Feature Specification: 독립 거시 레짐 전략군

**Feature Branch**: `Codex/151-independent-macro-regime`
**Created**: 2026-08-23
**Status**: Planned - candidate grammar frozen, implementation pending
**Risk Grade**: 4 - 합격 후보가 기존 NAV 10% 연구 캐너리 진입 대상이 될 수 있음
**Input**: "소진된 가격 매개변수 공간과 경제적 원인이 다른 신규 전략군을 구체화하고, 같은 검증 기준으로 자동 탐색한다."

## User Scenarios & Testing

### User Story 1 - 경제적 원인이 다른 네 전략군을 고정한다 (Priority: P1)

운영자는 기존 추세·모멘텀 숫자를 다시 섞는 대신 금리곡선, 물가, 고용 충격,
옵션시장 공포라는 서로 다른 원인으로 자산 비중을 바꾸는 후보를 원한다.

**Why this priority**: 기존 256개 가격 후보는 탐색 공간이 소진됐고, 추가로 살펴본
192개 단순 거시 조합도 검증 기준에 미달했다.

**Independent Test**: 같은 사전 등록 문법에서 네 전략군별 16개, 총 64개 고유 후보가
생성되고 후보의 경제 논리·매개변수·설정 지문이 안정적으로 재현된다.

**Acceptance Scenarios**:

1. **Given** 고정된 후보 문법, **When** 후보를 생성하면, **Then** 금리곡선 순환,
   물가 방향, 실시간 삼 규칙 고용 충격, VIX 충격·회복 전략군이 각각 16개 생성된다.
2. **Given** 같은 자료와 코드, **When** 다시 생성하면, **Then** 후보 ID·순서·정책
   설정·전략 지문이 모두 같다.
3. **Given** 연구 규칙을 실제 주문 엔진이 표현할 수 없음, **When** 후보를 검증하면,
   **Then** live 자격을 주지 않고 표현 불일치 이유를 남긴다.

### User Story 2 - 발표 당시 알 수 있었던 자료만 쓴다 (Priority: P1)

운영자는 나중에 수정된 경제 통계를 과거에도 알았던 것처럼 쓰는 가짜 백테스트를
막고 싶다.

**Why this priority**: 가격과 달리 거시 통계는 발표 지연과 수정이 있어 단순 날짜 정렬만으로는
미래 정보 누출을 막을 수 없다.

**Independent Test**: 일간 시장 지표는 당일 장 마감 뒤 다음 기간에만 적용되고, 월간 물가와
고용 지표는 발표 지연과 실시간 계열을 적용하며, 수정 안전성이 불명확하면 후보 전체가 탈락한다.

**Acceptance Scenarios**:

1. **Given** 월 t의 CPI, **When** t월 수익을 계산하면, **Then** 그 CPI는 사용할 수 없고
   실제 발표 지연 뒤 기간부터만 신호가 바뀐다.
2. **Given** 실시간 삼 규칙 이력과 나중에 수정된 실업률 이력, **When** 고용 신호를 만들면,
   **Then** 실시간 삼 규칙 이력만 사용한다.
3. **Given** 자료 결측·오래됨·교차검증 실패, **When** 공장을 실행하면, **Then** 부분 후보를
   합격으로 취급하지 않고 `NO_FACTORY_EDGE`와 자료 실패 이유를 발행한다.

### User Story 3 - 탐색한 모든 숫자를 과적합 벌점에 포함한다 (Priority: P1)

운영자는 실패한 탐색을 지워 승자 확률을 부풀리지 않고, 이미 본 192개 조합까지 모두
다중검정 벌점에 넣기를 원한다.

**Why this priority**: 신규 신호라도 홀드아웃 결과를 본 뒤 숫자를 조정하면 같은 과적합이다.

**Independent Test**: 기존 생산 256회, 이번 사전 탐색 192회, 공식 후보 64회가 모두 완료되면
DSR·PBO의 누적 시도 수가 정확히 512이고 누락 시 승자가 없다.

**Acceptance Scenarios**:

1. **Given** 192개 사전 탐색 재생 장부가 없음, **When** 공식 후보를 평가하면, **Then** 전체
   실행을 중단하고 후보를 합격시키지 않는다.
2. **Given** 512개 누적 시도 중 일부가 중복 지문, **When** 장부를 합치면, **Then** 중복은
   별도 시도로 부풀리지 않고 원래 시도와 연결한다.
3. **Given** 잠정 최고 후보가 하나 이상의 기존 공장 관문을 실패, **When** 판정하면,
   **Then** 승자와 배포 설정을 발행하지 않는다.

### User Story 4 - 연구 신호와 실제 주문 신호를 같게 만든다 (Priority: P2)

운영자는 백테스트에서 쓴 거시 규칙과 실제 주문 직전 규칙이 정확히 같고, 자료가 없을 때
새 주문이 나가지 않기를 원한다.

**Why this priority**: 검증과 실거래가 다르면 좋은 백테스트도 돈 경로 근거가 될 수 없다.

**Independent Test**: 동일한 가격·거시 스냅숏과 후보 설정에서 연구 재생과 주문 미리보기가
같은 목표 비중을 만들고, 신선하지 않은 거시 스냅숏은 브로커 호출 전에 차단된다.

**Acceptance Scenarios**:

1. **Given** 완전 합격 후보와 신선한 거시 스냅숏, **When** 주문 미리보기를 실행하면,
   **Then** 연구 재생의 같은 날짜 목표 비중과 일치한다.
2. **Given** 거시 자료가 누락되거나 7일보다 오래됨, **When** 첫 주문을 준비하면,
   **Then** 보유를 임의 청산하지 않고 신규 주문 전체를 차단한다.
3. **Given** 후보가 합격하더라도 설정 지문·강화 캐너리·정합성 중 하나가 다름,
   **When** 자본 사다리를 평가하면, **Then** 단 0·자본 0을 유지한다.

### Edge Cases

- 서로 다른 이름의 후보가 같은 목표 비중 경로를 만들면 전략 지문으로 중복 처리한다.
- VIX가 휴장으로 비어 있으면 직전 영업일 값을 사용하되 신선도 한도를 넘으면 차단한다.
- CPI의 12개월 전 값이 없거나 0이면 물가 전략군 전체를 불완전으로 처리한다.
- 금리 2년·10년 중 하나가 없으면 금리곡선 전략군만이 아니라 같은 묶음 전체를 실패시킨다.
- 거시 신호가 바뀌어도 무거래 밴드와 최소 주문 금액 아래면 주문하지 않는다.
- 손실 halt·정합성 오류·주문 상태 불명은 거시 신호보다 항상 우선한다.

## Requirements

### Functional Requirements

- **FR-001**: 시스템은 네 전략군에서 각각 16개, 총 64개 고유 후보를 결정론적으로 생성해야 한다.
- **FR-002**: 금리곡선 순환 전략군은 10년-2년 금리차의 역전, 지속, 재가팔라짐 상태를 사용해야 한다.
- **FR-003**: 물가 방향 전략군은 비계절조정 CPI 전년비의 수준과 3·6개월 방향을 사용해야 한다.
- **FR-004**: 고용 충격 전략군은 실시간 삼 규칙 계열의 0.3·0.5%p 문턱과 방향을 사용해야 한다.
- **FR-005**: VIX 전략군은 25·35 수준, 1·5일 확인, 5·20일 냉각 기간을 사용해야 한다.
- **FR-006**: 각 전략군은 균등 3자산 기준과 기존 탈락 후보 `factory-relative_momentum-cb2e32f74390`을 사전 등록 기준 포트폴리오로 각각 사용해야 한다.
- **FR-007**: 후보는 SPY·IEF·GLD 신호와 SPYM·IEF·GLDM 실행 수단만 사용하고 레버리지·공매도를 금지해야 한다.
- **FR-008**: 일간 금리·VIX는 신호일 다음 기간부터, 월간 통계는 45일 발표 지연 뒤부터 사용해야 한다.
- **FR-009**: CPI는 비계절조정 공식 계열, 고용은 실시간 삼 규칙 계열을 사용하고 자료 출처·최초·최종 날짜·결측·신선도를 기록해야 한다.
- **FR-010**: 기존 256회와 사전 탐색 192회를 공식 64회보다 먼저 누적 장부로 재생해야 한다.
- **FR-011**: 공식 묶음 완료 시 다중검정 시도 수는 512여야 하며, 하나라도 재생 불가하면 승자가 없어야 한다.
- **FR-012**: 합격 기준은 스펙 150의 DSR 0.95, PBO 0.10, PSR 0.95, 구간 승률 60%, 샤프 우위 0.20, 칼마 우위, 낙폭 방어, 50bp 비용 후 양의 수익을 그대로 유지해야 한다.
- **FR-013**: 후보 정책의 입력·매개변수·목표 비중 규칙은 전략 지문에 포함되어야 한다.
- **FR-014**: 연구와 주문 미리보기는 같은 순수 목표 비중 함수를 사용해야 한다.
- **FR-015**: 거시 자료 누락·오래됨·오염·지문 불일치는 서명과 브로커 호출 전에 신규 주문을 차단해야 한다.
- **FR-016**: 합격 후보는 기존 강화 캐너리·정합성·halt 없음·정확한 지문을 통과할 때만 기존 NAV 10% 단 1 심사로 이동해야 한다.
- **FR-017**: 10% 초과 승격과 모든 하향·정지 규칙은 헌법 X.4 v8.0.0을 그대로 유지해야 한다.
- **FR-018**: AI나 사람이 다음 후보를 제안하더라도 홀드아웃을 읽기 전에 후보 문법을 장부에 동결해야 하며, 유료 모델 호출은 이번 범위에 포함하지 않아야 한다.

### Key Entities

- **MacroSnapshot**: 한 시점에 실제 알 수 있었던 금리차, CPI 전년비·방향, 실시간 삼 규칙, VIX 상태와 자료 신선도.
- **MacroPolicyCandidate**: 전략군, 기준 포트폴리오, 문턱, 확인·냉각 기간, 자산 기울기, 전략 지문을 가진 후보.
- **ExploratoryTrialReplay**: 이번 대화에서 이미 본 192개 조합을 다시 계산해 누적 벌점에 포함하는 장부.
- **MacroFactoryDecision**: 512회 누적 다중검정과 기존 관문으로 만드는 단일 합격 또는 승자 없음 판정.
- **LiveMacroEvidence**: 주문 직전 자료 커밋, 생성 시각, 최신 관측 시각, 정책 지문, 목표 비중을 묶은 증거.

## Success Criteria

### Measurable Outcomes

- **SC-001**: 네 전략군 64개 후보가 모두 고유하고 두 번 실행해 같은 ID·순서·지문을 만든다.
- **SC-002**: 거시 자료가 1990년부터 현재까지 이어지고 1990~2006 개발 구간과 2007년 이후 120개월 이상 홀드아웃이 완전히 분리된다.
- **SC-003**: 공식 판정의 누적 시도 수가 512이며 모든 합격 기준은 스펙 150과 숫자까지 같다.
- **SC-004**: 미래 정보 누출·자료 오래됨·192회 재생 누락·연구/실거래 비중 불일치 시험이 모두 fail-closed한다.
- **SC-005**: 같은 스냅숏의 연구 재생과 주문 미리보기가 모든 후보에서 동일한 목표 비중을 만든다.
- **SC-006**: 합격 후보가 없으면 자본·주문·live 설정 변경이 0건이고 다음 독립 전략군이 기계 판독 가능하게 발행된다.
- **SC-007**: 64개 공식 후보와 192개 재생을 포함한 전체 공장 실행이 15분 안에 끝나며 부분 실행은 승자를 발행하지 않는다.

## Assumptions

- 공개 자료 전달 경로는 FRED·Cboe·BLS 교차검증을 사용하며, 자료 제공 중단은 성공이 아니라 차단이다.
- 이번 기능은 기존 세 자산 실행 수단을 유지한다. 신규 종목·레버리지·공매도는 별도 스펙이다.
- 탐색 결과가 좋지 않으면 기준을 낮추지 않고 전략군을 폐기한다.
- 현재 권위 상태는 `armed:false`, 단 0, 자본 0이며 이 명세 자체는 주문하지 않는다.
