# 기존 한국투자5종목 과거 수집과 연구

운영자는 가입 없이 한국투자로 계속 진행하도록 지시했다. 위험 등급3: 기존 인증 읽기
진단을5종목으로 확장하고 원본을 연구기로 연결한다. 유료/무료 신규 계정 연결은 보류한다.

- 기존 허용 SPY/QQQ/IWM/TLT/GLD만 각 최대80페이지로 조회한다. 공식 거래소 매핑 유지.
- 종목별 원본·조회시각·해시·종료 이유를 보관한다. 188 단일 종목 기본 동작은 유지한다.
- 수집 시작 시점에 장이 끝난 날짜만 분석한다. 공통 기간은 각 종목 첫/마지막 날짜의 교집합 범위다.
- 범위 밖 자료를 버리지 않고 원본에 보존한다. 공통 기간의 내부 누락·봉 부족은 불합격 이유로 남긴다.
- 기존177 후보·비용·756세션 기준·독립 증거 검사를 유지한다. 짧은 기간 결과를 장기 통과로 바꾸지 않는다.
- 완전한 공통 자료에는 기존18후보를 기본/스트레스 비용으로 별도 재생한다. 결과와 모의 장부는
  short-window-diagnostic.json에 보관하며 학습/검증 기간 분리나 승격 근거로 쓰지 않는다.
  자료가 불완전하면 이 계산도 실행하지 않는다. 공식 독립 증거 판정과 별도인 짧은 구간 진단이다.
- 서버 고정 읽기 검사에 연결하고 원본/연구 결과를 비공개 새 폴더에 보존한다. 주문·자금 변경 없음.

완료: 관련 모의 반례·전체 회귀·린트·하네스 통과 후 병합된 코드로5종목 실제 수집과
독립 연구 결과 확인. 전체 장기 전략 적격과 이번 가용 자료 연구 완료는 구분한다.
