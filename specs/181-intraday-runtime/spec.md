# 기능 명세: 단타 자동매매의 수집·지속 운용 연결

**Feature Branch**: `codex/181-intraday-runtime`
**Created**: 2026-09-06
**Status**: 수집·진단 모의 소프트웨어 검증 완료, PR767 초안 — 실자료·실거래 미완료
**Input**: "단타 자동 매매도 완성하라고 했다. 다시 구현 완료해."

## 문제 정의

Spec 177은 CSV 연구 도구까지만 출시했다. 사용자의 전체 요청에는 시세 수집,
실시간 판단, 주문·청산, 복구, 증거 축적과 검증된 소액 실거래가 포함된다.
연구 도구 완료를 전체 요청 완료로 취급하지 않는다. 본 명세는 이 전체 경로를
추적하되, 미검증 전략의 자본 투입을 코드 구현의 완료 조건으로 강제하지 않는다.
위험 등급 3(별도 모의 실행·자료 신뢰 경계), 후속 실주문 연결은 등급 4다.

## User Scenarios & Testing

### US1 — 실제 분봉을 확보한다 (P1)

운영자는 파일을 손으로 준비하지 않고 허용된 공급자에서 5분봉을 수집한다.
독립 시험: 여러 페이지, 오류, 중복, 정정, 정규장 외 봉과 미완성 봉을 주입한다.
역사 수집은 원본과 공급자·시장 범위·수집 시각·조정 기준을 보존한다.
권한이 없으면 `DATA_ACCESS_REQUIRED`이며 자료 부족을 전략 탈락으로 표시하지 않는다.

### US2 — 프로그램이 계속 판단하고 모의 주문·청산한다 (P1)

닫힌 봉에서만 기존 18후보의 신호를 계산한다. 주문을 만든 봉에서는 체결할 수 없다.
고정 지정가의 다음 5분봉 도달 여부와 거래량 한도로 부분·미체결을 기록한다.
종목별·주문별 20%, 총 80%, 별도 가상자본 100,000달러, 현금 및 비용을 적용한다.
각 모의 계좌는 일손실 2%에서 신규 진입을 멈추며 다른 후보 계좌에는 영향을 주지 않는다.
장 종료 15분 전부터 신규 진입을 막고 청산 주문을 낸다. 청산 실패는 포지션을
보존하고 노출 잔존으로 표시한다. 가격을 추격하거나 체결을 만들어내지 않는다.
독립 시험: 한 세션을 한 번/분할/재시작으로 입력했을 때 장부와 잔고가 동일하다.

### US3 — 장애와 미완료를 숨기지 않는다 (P1)

같은 봉 재수신·중복 실행은 한 번만 반영한다. 이미 처리한 봉의 정정, 중간 누락,
오래된 봉, 손상된 장부는 신규 진입을 차단한다. 보유 수량을 임의로 삭제하지 않는다.
원본·주문·체결·잔고는 별도 추가 전용 기록에 저장하고 거래 DB를 재사용하지 않는다.
진행 보고서는 모의 체결과 실제 체결, 누적 관찰과 합격 관찰을 구분한다.

### US4 — 검증된 범위에서만 실거래로 이어간다 (P2)

완료 기준은 수집기 시험만이 아니다. Spec 177의 756세션 역사·비용·시간 분리 관문,
동일 전략 지문의 최소 60세션 전진 관찰, 공급자와 실제 체결 비용의 동등성,
강화 캐너리, 계좌 자금성 및 단타 주문 권한까지 각각 증거가 필요하다.
현재 헌법 X.4의 하루 한 번 주문 경로를 단타 반복 주문에 재사용하지 않는다.
이 경로는 별도 헌법/명세/위험 등급 4 검증 전에는 비활성이다.

### Edge Cases

- 키 없음, 401/403, 429, 5xx, 시간초과, 반복 페이지, 페이지 상한: 유한 재시도·명시 실패.
- 공급자·조정 방식·전략 지문 변경: 같은 모의 장부에 합치지 않음.
- 시각 없는 시세를 거래 시각으로 위장하거나 보간하여 분봉을 만들지 않음.
- 조기 폐장·휴장·서머타임: XNYS 달력을 사용함.
- 마지막 청산 미체결·재시작: 잔량을 보존하고 다음날 신규 진입을 차단함.
- 장중 늦게 시작/소급 자료: 진단 재생으로 구분하며 전진 관찰 자격을 부여하지 않음.

## Requirements

- **FR-001**: 허용 공급자 Alpaca SIP 역사와 KIS 부분시장 5분봉만 수집하고 서로 분리한다.
- **FR-002**: 외부 호출은 속도 제한, 최대 4회 시도, 지수 대기, 장애 회로·회복을 갖는다.
- **FR-003**: 입력은 5분 정렬 UTC, 양수 유한 OHLC·정수 거래량, XNYS 정규장이다.
- **FR-004**: 원본 지문과 수집 시각, 전체 페이지 여부, 공급자 범위를 남기며 수정하지 않는다.
- **FR-005**: 같은 입력은 정확히 한 번만 상태를 변경하고 한 입력의 장부·잔고는 원자적이다.
- **FR-006**: 실제 브로커 주문 함수·계좌 DB·라이브 설정·센티넬을 호출하거나 변경하지 않는다.
- **FR-007**: 신호는 Spec 177의 고정 후보를 재사용하되 체결 모형 차이는 새 실행 지문으로 남긴다.
- **FR-008**: 불확실한 체결·누락·오래된 입력은 신규 진입 차단이며 정해진 청산은 유지한다.
- **FR-009**: 보고서는 항상 `live_eligible=false`, `orders_submitted=0`을 표시한다.
- **FR-010**: 자격 증명·자료·관찰·실주문 구현 미완료를 각각 남긴다. 자동 합격이나 수익 보장은 없다.

### Key Entities

자료 배치(공급자/시장/지문/시각), 확정 봉, 후보 실행 지문, 모의 지정가 주문,
부분 체결, 가상 계좌, 추가 전용 사건, 단계별 준비 상태.

## Success Criteria

- **SC-001**: 전체 페이지 수집 후 기존 Spec 177 입력 계약으로 검증할 수 있다.
- **SC-002**: 중복·재시작·동시 실행에서 중복 모의 체결 0건이다.
- **SC-003**: 정상·조기 폐장·누락·미체결 시험에서 미래정보 체결 및 숨긴 잔량 0건이다.
- **SC-004**: 어떤 실행 옵션에서도 실제 주문 0건이며 현재 저빈도 전략은 그대로다.
- **SC-005**: 소프트웨어 검증, 실제 자료 운용, 단타 실거래 완료가 각각 별도 상태로 표시된다.

## Assumptions

유료 계약·계정 가입은 자동으로 하지 않는다. 무료 역사 API도 운영자 계정 권한이 필요하다.
15/30/60분 전략을 대상으로 하며 초고빈도 매매는 포함하지 않는다.
먼저 진단 모의 운용을 연결한다. 이는 합격 후보의 60세션 전진 관찰을 대신하지 않는다.
현재 전략·자본을 바꾸지 않고 단타 반복 실주문 경계를 우회하지 않는다.

## 되돌림

별도 단타 실행 프로세스를 중단한다. 기존 저빈도 서비스는 변경하지 않는다.
수집 원본과 모의 감사 장부는 삭제하지 않는다. 미완료 실거래 작업은 계속 명시한다.

## 후속: 기존 서버 인증을 이용한 실제 분봉 점검

로컬 키 부재를 전체 데이터 접근 부재로 취급하지 않는다. 기존 `kis-smoke`의
main 계보 확인·격리 checkout·서버 전용 토큰 캐시·비밀값 차단 경로를 그대로 사용해
가장 최근 완전히 닫힌 XNYS 세션의 고정 5종목 분봉을 수집한다. 전체 예상 시각과
종목별 봉 수가 정확히 일치해야 통과하며, 원본/manifest는 기존 pytest의 전용 임시
디렉터리에 저장하고 로그에는 공급자·세션·봉 수·지문만 남긴다. 새 SSH 명령이나
실주문 권한은 추가하지 않는다. 이 검사는 자료 계약 검증이며 역사 합격이나 지속
전진 운용을 뜻하지 않는다. T001~T011의 독립 소프트웨어 출시를 T012~T016의 실제
관찰 완료에 묶지 않되 전체 요청의 미완료 표시는 유지한다.
