# 기능 명세: KIS 단타 주문 실행과 복구

**Feature Branch**: `codex/182-intraday-kis-execution`
**Created**: 2026-09-07
**Status**: 실행·복구 코드 검증 완료, 생산 실거래 전체완료 조건 미충족
**Input**: Alpaca 계정 없이 기존 한국투자증권 중심으로 단타 자동매매를 끝까지 완성한다.

## 문제 정의

181은 수집·모의 판단을 서버에 가동했지만 실제 주문 상태 관리와 전략 검증이
남아 있다. 자료 계정 부재를 실행 소프트웨어 개발의 선행 조건으로 잘못 묶었다.
이번 단계는 반복 판단을 기존 KIS 주문·체결·감사 경로에 연결하는 실행기를
만들고, 중복·미확정 제출·부분 체결·취소 경합·청산을 네트워크 없는 실계약 시험으로
검증한다. 자료 합격과 실거래 승인 전에는 새 생산 주문 진입점을 설치하지 않는다.
위험 등급 4: 주문·취소 돈 경로 구현, 실행 검증은 가짜 계정과 격리 장부에 한정한다.

## User Scenarios & Testing

### US1 — 주문부터 청산까지 이어진다 (P1)

확정된 신호와 실제 계좌 상태를 받아 신규 주문, 체결 동기화, 목표 수량 감소,
장 종료 15분 전 청산을 이어간다. 지정가·정수주·허용 5종목을 지킨다.
독립 시험: 접수→부분 체결→취소 요청→취소 확인→잔량 청산→잔고 대사.

### US2 — 장애가 중복 주문이 되지 않는다 (P1)

한 신호는 한 번만 주문한다. 제출 직후 프로그램 종료·응답 유실·동시 실행은
새 주문을 막고 기존 증권사 기록과 대사한다. 취소 접수는 최종 취소가 아니다.
독립 시험: 같은 입력 반복과 재시작, 부분 체결이 취소와 겹치는 상황에서도
체결 수량이 사라지거나 중복되지 않는다. 불명확한 쓰기 요청을 자동 재전송하지 않는다.

### US3 — 새 자료 계정 없이 개발·점검한다 (P1)

외부 연결 없는 명령으로 KIS 실제 요청 형식과 전체 주문 수명을 재현한다.
결과는 시험 증거임을 표시하고 실제 주문 수와 합격 전진 관찰을 0으로 표시한다.
Alpaca는 선택 자료원이며 기존 KIS 수집은 계속 사용한다. 756세션 자료가 없으면
자료 부족이라고 표시한다. CFD 호가·합성 봉을 실제 ETF 체결 자료로 바꾸지 않는다.

### Edge Cases

- 오래된/미래 시세, 거래소 불일치, 음수/비유한 가격, 매도 초과, 잔고 불일치.
- 취소 HTTP200/업무거절/원문 오류/응답 유실/접수 후 추가 체결.
- 장 종료·조기 폐장·휴장·손실 정지·증권사 미체결·타 전략 보유.

## Requirements

- **FR-001**: 매수는 지정가, 정수주, 주문/종목20%·전체80% 이하이며 기존 router의
  whitelist·halt·execution-state·exposure·maintenance 관문도 모두 통과한다.
- **FR-002**: 신호 지문·세션·시각·종목별로 영속적인 단일 실행 claim을 주문 전 기록한다.
  claim 이후 결과가 없으면 원주문 기록을 찾고, 증거가 없어도 claim을 지우거나 재전송하지 않는다.
- **FR-003**: 외부 관측 실패·누락·대사 불일치·미확정 제출은 신규 주문 차단이다.
  매도는 이 실행기에 귀속된 확정 보유량 이하이며 다른 전략의 보유를 팔지 않는다.
- **FR-004**: 종료 15분 전 신규 진입을 막고 미체결 매수부터 취소한다. 최종 체결·취소를
  확인한 뒤 실제 잔량만 청산한다. 미체결 잔량과 실패는 다음 실행에 보존한다.
- **FR-005**: KIS 취소는 원주문 종목·거래소·미체결 수량을 보내고 업무 성공을 확인한다.
  취소를 요청했다고 로컬 주문을 CANCELLED로 확정하거나 즉시 재호가하지 않는다.
- **FR-006**: 증권사 쓰기는 기존 ExecutionAuthority만 사용한다. 추가 전용 취소 요청과
  실행 claim은 삭제·수정하지 않는다. 명백한 거절도 같은 요청의 자동 반복을 만들지 않는다.
- **FR-007**: 네트워크 없는 검증 명령은 임시 계정/DB와 MockTransport로만 동작하며
  환경 비밀값을 읽지 않는다. 생산 URL이나 --live 옵션을 받지 않는다.
- **FR-008**: 운용 승인은 기본 차단이다. X.4의 하루 1회 권한, 기존 사다리·자본·전략을
  단타 권한으로 재사용하지 않는다. 단타 실거래 전에는 별도 반복 주문 경계·실제 177/181
  검증 증거·소액 자본 한도·소스 지문·배포 감사·강화 캐너리가 필요하다.
- **FR-009**: 소프트웨어 시험 완료와 전체 실거래 완료를 나눈다. 181 T012~T016의
  실제 증거가 없으면 체크하지 않는다. 자료 계정 가입과 유료 비용을 자동 발생시키지 않는다.

## Success Criteria

- **SC-001**: 같은 신호 반복·재시작·동시 실행에서 중복 증권사 요청 0건.
- **SC-002**: 부분 체결과 취소 경합에서 숨긴 보유·초과 매도 0건.
- **SC-003**: 외부 연결 없는 전체 주문 수명 시험과 기존 전체 회귀 검사 통과.
- **SC-004**: 실거래 미승인/증거 누락이면 주문 0건, 구체적인 미완료 사유 표시.

## Assumptions / 되돌림

사용자의 지시는 개발·검증·병합·정상 배포를 계속하라는 승인이다. 아직 특정 단타
전략이나 자본을 승인했다는 뜻은 아니다. 본 구현은 증거 없는 실거래를 활성화하지 않는다.
변경을 되돌릴 때 새 단타 실행 호출을 중단하고 기존 감사·주문·체결·claim을 보존한다.
취소 접수만으로 취소 확정하던 기존 동작은 제거하고 증권사 최종 상태 동기화로 대체한다.

## 후속 US4 — 배정 전에 금액과 주문 가능 수량을 검토한다 (P1)

운영자는 자금 배정안을 제시하고 절차대로 진행하라고 요청했다. 금액 확정 전에도
검토용 설정을 만들 수 있지만 설정 저장을 계좌 배정이나 실거래 승인으로 취급하지 않는다.
이 후속 범위는 등급 2다. 주문 코드·권한·손실 제한을 수정하지 않는 읽기 전용 계산이다.

- FR-010: USD 검토 예산과 날짜가 있는 5종목 참고 시세로 정수주 수량을 계산한다.
  기존 신호의 16% 목표, 지정가 반올림, 현금 여유분을 반영한다. 100달러라도
  1주를 못 사면 그 사실을 표시하며, 가능 수량은 수익성이나 매수 신호가 아니다.
- FR-011: 출력은 검토 전용, 자금 변경 0, 주문 0, 실거래 가능 false다.
  승인·실행 인수를 받지 않고 환경 비밀값·계좌 장부·외부 네트워크를 사용하지 않는다.
- FR-012: 참고 가격과 가정한 현금은 실시간 계좌 관측과 구분한다. 검증된 NAV가
  없다는 사실과 실제 전략 증거·생산 연결이 남았다는 사실을 감추지 않는다.
- FR-013: 2% 손실 정지 기준은 기존 동작 설명이다. 손실을 그 금액으로 보장하는
  장치로 표현하지 않으며 설정에서 실제 실행기의 값을 바꾸지 않는다.
- SC-005: 100달러/600달러 예시, 1주 경계값, 현금 부족, 잘못된 금액/종목/날짜,
  실제 신호 계산과의 일치, 네트워크·장부 무접근을 시험한다.

완료 기준은 재현 가능한 검토 설정·보고서·검증이다. T010~T012 전체 실거래 조건은
그대로 남는다. 이 기능을 되돌리면 검토 명령과 예시만 제거하며 기존 실행기는 불변이다.

## 후속 US5/US6 — 확정 한도로 준비하고 실제 계좌를 점검한다 (P1)

2026-09-07 운영자가 "응 확정하고 완성해줘"라고 답해 준비 기준
600달러·하루 손실 정지12달러를 확정했다. 금액을 다시 질문하지 않는다.
금액 확정은 이 문맥에서 다음 준비 단계의 기준 확정이며 실제 배정·주문 가동은 아니다.
등급3에 준해 전체 명세·계획·연구·계약·시험을 남긴다. 기존 돈 경로는 불변이다.

- FR-014: 확정값(자본600, 주문/종목120, 전체노출480, 하루정지12 USD)을
  버전 있는 준비 설정으로 저장한다. 설정의 승인 범위는 준비 기준이며 주문 허용은 false다.
- FR-015: 사전점검은 확정된 한도를 읽고 모의 브로커를 통한 주문 수명 검증을
  그 금액으로 재현한다. 임시 장부 밖으로 쓰거나 실제 증권사 주문을 전송하지 않는다.
- FR-016: KIS 읽기 전용 계좌 수집기는 USD 구매가능금액·미국 정수주 보유·미체결을
  명시적으로 조회한다. 모든 페이지를 검사하고 거절·형식 오류·반복/불명확 커서·
  누락·수량 오류·30초 초과는 불완전 관측으로 거절한다.
- FR-017: 통합 구매가능금액을 USD 현금으로 대체하지 않는다. NAV·분수주·
  다른 국가 보유 등 전체 계좌 범위를 확정하지 못하면 계좌 전체 검증 false를 유지한다.
  이 결과를 기존 실행기의 Observation으로 자동 변환하지 않는다.
- FR-018: 계좌 수집 성공도 live_eligible=false이며 비밀값·계좌번호·원문 오류는
  공개 결과에 포함하지 않는다. 기존 서버 읽기 검사로 실제 응답 계약을 확인한다.
- SC-006: 확정 한도 이탈·실행 스위치·임의 승인 필드를 거절하고, 모의 주문과
  실제 네트워크 조회의 증거를 구분한다. 생산 주문 요청은0이다.

완료 기준은 확정 설정, 한도 적용 모의 검증, 실제 읽기 계좌 계약이다.
T010~T012의 과거자료·전진 관찰·생산 주문 증거는 단축하거나 모조하지 않는다.
