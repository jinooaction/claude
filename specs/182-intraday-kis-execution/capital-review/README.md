주문 1건의 상한 $120도 주문 목표 $96과 다르다.

## 왜 100달러로 시작할 수 없는가

현재 5종목과 정수주 규칙을 유지하면 참고 가격에서 최소 1주 예산은 다음과 같다.
가격이 바뀌면 다시 계산해야 한다. 실제 계좌 제한이나 현금 상태에 따라 더 막힐 수 있다.

| 종목 | 참고 가격 | 1주 계산에 필요한 최소 배정 한도 |
|---|---:|---:|
| SPY | $770.19 | $4,816.57 |

| IWM | $296.01 | $1,851.13 |
| TLT | $82.21 | $514.07 |

600달러는 5종목 전략 전체를 분산 운용하기에 충분하지 않다.
TLT 매수 추천이나 수익성 합격을 뜻하지 않으며, 전 종목을 사기 위해 자금을
추가 입금하거나 한도를 자동 상향하지 않는다. 더 작은 실운용 금액을 원한다면
현재 종목·전략 설계로는 주문이 안 된다는 결론을 유지한다.

## 확인한 계좌 연결과 미확인 부분

[읽기 전용 KIS 검사 34064890546](https://github.com/jinooaction/claude/actions/runs/34064890546)은
2026-09-07 07:45 KST에 7개 검사를 통과했다(16.50초). 실제 주문은 없었다.
이는 연결·시세·조회 계약 확인이며 자본 승인이나 전략 수익성 증거가 아니다.
기존 조회가 반환하는 구매가능금액과 합산 잔고를 새 단타의 검증된 현금·NAV
(계좌 전체 순자산)로 인정하지 않았다. 통합증거금·미체결 예약·보유 평가 범위를
확정할 별도 계좌 관측 연결이 필요하다.

## 진행 순서

1. 완료: 100/600달러 설정을 재현 가능한 검토 명령으로 계산하고 정수주 가능성을 표시.
2. 완료: 운영자가 준비 기준 $600와 하루 정지 기준 $12를 확정했다.
   금액을 정해도 즉시 실행되거나 기존 저빈도 전략 자본이 재사용되지 않는다.
3. 확정 설정과600달러 모의 검증은 반영됐다. 조회의 USD 단일 행 가정은 FR-022로
   보정하고 재검증 중이다. 이전34077759009의 7개 통과/1개 실패는 이 가정 때문이었다.
   모든 USD 행을 각각 보존하므로 조회 완료에 합산 계약 답변이 필요하지 않다.
   [KIS 확인 요청 초안](kis-cash-contract-inquiry.md)은 집계/NAV 후속 확인용이며 미발송이다.
   검증된 계좌 순자산, 실제 역사 자료/전략 합격, 동일 후보 전진 관찰,
   실행 동등성, 단타 전용 생산 권한·연결은 여전히 미완료다.
4. 운영자가 실제 실행을 시작한 뒤 접수·체결·청산·잔고 일치를 확인한다.
   이 검토 명령에는 실거래 시작 기능이 없으며 가짜 시작 명령을 안내하지 않는다.

## 재현

확정값 검사와 가상 계좌의 주문→부분체결→취소→추가체결→청산:

```bash
uv run python scripts/intraday_execution.py preflight
```

실제 실행기의600달러 한도를 사용하되20달러는 부분체결을 재현하기 위한 **가짜 시험 가격**이다.
참고 시장가격이나 매수 신호가 아니다. 보고서는 budget_parameters_confirmed=true,
capital_change_usd=0, live_eligible=false를 함께 표시한다.
기존2% 손실 기준은 추정 수수료도 포함하며12달러를 보장하는 손실 상한은 아니다.

저장소 최상위에서 실행한다. 모든 결과는 검토 전용 JSON이며 정상 종료는 거래 승인이 아니다.

```bash
uv run python scripts/intraday_capital_review.py --prices specs/182-intraday-kis-execution/capital-review/reference-prices.json --capital-usd 100.00
uv run python scripts/intraday_capital_review.py --prices specs/182-intraday-kis-execution/capital-review/reference-prices.json --capital-usd 600.00
```

[참고 가격](reference-prices.json), [100달러 계산](review-100.json),
[600달러 계산](review-600.json)에 입력과 결과, 계산기·실행기 지문이 있다.
quote_age_seconds는 실행할 때마다 달라지고 다른 산술 결과는 같은 입력에 동일하다.
100/600달러 비교 JSON은 확정 이전의 검토 기록이므로 approval_recorded=false가 보존돼 있다.
현재 확정 상태는 confirmed-budget.json과preflight 결과로 확인한다.
가격은 9월4일 미국 거래 종료 부근의 공개 참고 스냅샷이며 실제 주문 시세가 아니다.
