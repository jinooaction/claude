# 스펙 054 — 비상관 수익원 탐색 (1차: 밸류·캐리, 정직한 부정 결과)

운영자 방향(2026-06-16): "비상관 수익원 다변화를 세계 최고 수준으로 마이크로까지 완벽하게."
현재 forward 토너먼트 6트랙이 **전부 추세추종(모멘텀) 계열**이라 단일 차원으로 취약하다. 세계
최고 수준 퀀트(AQR "Value and Momentum Everywhere")의 정석 = 추세와 *음의 상관*인 수익원을
결합해 같은 수익을 더 낮은 변동성(샤프↑)으로.

## 질문

밸류(CAPE)·캐리(E/P vs 금리)로 만든 수익원이 추세추종과 비상관이라 결합 시 분산 이득(샤프↑)
이 나는가? — **측정한 것만 배선** 원칙대로, 트랙을 추가하기 *전에* 답한다.

## 방법

같은 베타(S&P)에 후보 신호를 얹어 사과 대 사과로 비교(`value_carry.py`). 데이터: Shiller 월간
(1871~2026, GitHub). 미래 누출 0. 재현: `uv run python scripts/value_carry_probe.py`.

## 결과 — 세 가지 결합 형태 전부 부정

**(A) 50/50 결합** (`measure_{value,carry}_diversification`):

| 구간 | 후보 | 판정 | 추세↔후보 상관 | 추세 샤프 | 후보 샤프 | 결합 샤프 |
|------|------|------|:---:|:---:|:---:|:---:|
| 1881~ | 밸류 | 이득 없음 | 0.46 | 1.17 | 0.78 | 1.14 (↓) |
| 1881~ | 캐리 | 이득 없음 | 0.63 | 1.17 | 0.72 | 1.00 (↓) |
| 1950~ | 밸류 | 약한 이득 | 0.56 | 1.43 | 1.14 | 1.46 (+0.03) |
| 1971~ | 밸류 | 약한 이득 | 0.48 | 1.37 | 1.00 | 1.39 (+0.02) |
| 1990~ | 밸류 | 이득 없음 | 0.58 | 1.29 | 0.89 | 1.21 (↓) |
| (캐리 1950/1971/1990 전부 이득 없음, 상관 0.57~0.62) | | | | | | |

- 상관 0.46~0.63 — 어느 것도 진짜 비상관(≈0)이 아니다. 결합 이득은 밸류 2구간 +0.02뿐(노이즈).

**(B) 조건부 결합** (추세 OFF=현금 구간만 밸류로 운용 — 추세의 빈 구간을 메우는 시도):

| 구간 | 추세 샤프 | 조건결합 샤프 | 추세 낙폭 | 조건결합 낙폭 |
|------|:---:|:---:|:---:|:---:|
| 1881~ | 1.17 | **0.88 (↓)** | 41.0% | **70.1% (악화)** |
| 1950~ | 1.43 | 1.15 (↓) | 18.9% | 38.7% (악화) |
| 1971~ | 1.37 | 1.09 (↓) | 18.9% | 39.2% (악화) |
| 1990~ | 1.29 | 0.95 (↓) | 18.9% | 47.2% (악화) |

→ 조건부는 *더 나쁘다*. 추세가 현금으로 빠지는 구간은 **약세장**인데, 그때 밸류는 "싸니 사라"며
주식을 늘려 **떨어지는 칼을 잡는다** → 추세추종의 핵심 방어를 정확히 무력화. 재현(인라인):
`cond=[market[t] if in_mkt[t] else e*market[t]+(1-e)*cash[t]]`, e=`value_exposure`.

## 핵심 발견 — 왜 비상관이 불가능한가 (구조적)

1. **long-only 베타 공유**: 밸류·캐리·추세 셋 다 결국 long-only 로 주식/채권 베타에 노출 →
   같은 베타라 구조적으로 양의 상관(0.5~0.6). AQR 의 비상관 밸류/모멘텀은 *롱숏*(싼 것 매수 +
   비싼 것 *공매도*)이고, 그 시장 베타 중립이 직교를 만든다. 우리는 long-only ETF(KIS) 제약.
2. **밸류는 추세와 상충(역추세)**: 밸류는 약세장에 주식을 *늘리려* 하고 추세는 *줄이려* 한다 —
   비상관이 아니라 정반대. 결합하면 추세의 방어가 무력화된다.

→ **현 데이터·제약(long-only, 주식·채권·금)에서 추세추종은 이미 거의 최적의 long-only 전략**
이다. 비상관 수익원으로 개선하려면 롱숏(공매도) 또는 다른 자산군(통화·원자재 선물·변동성)이
필요한데 둘 다 현 시스템 제약 밖. 152년 데이터가 추측 배선을 막았다(이게 측정의 가치).
