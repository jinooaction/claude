# Requirements Checklist: Autonomous Production Approval

- [x] 사람 의존점과 자동화 완료 기준이 구체적이다.
- [x] 실제 주문과 주문 없는 수동 검증이 분리돼 있다.
- [x] 제거되는 기능, 남는 안전장치, 되돌림 방법이 명시돼 있다.
- [x] 자본·전략·허용 종목·손실 예산이 바뀌지 않음을 명시했다.
- [x] 비밀값 경계와 main-only 정책을 명시했다.
- [x] 실서버 검증은 주문 0건으로 설계됐다.
- [x] 외부 설정과 저장소 코드의 검증 방법이 재현 가능하다.
