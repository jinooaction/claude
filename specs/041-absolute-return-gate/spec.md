# 스펙 041 — 절대 기대수익 게이트(듀얼 모멘텀) + 유니버스 대폭 확대

## 문제 (운영자의 날카로운 지적 — 정확함)

운영자: **"점수 중 1위에 투자하는 게 무슨 허접한 전략이야? 1위가 수익이 기대가 안 되는
상황에도 투자를 한다는 거잖아. 기대 수익율이나 예측 성공률 기준으로 판단해야 하는 거 아니야?
이게 지금 세계 최고 수준이 맞아?"** + "유니버스 종목을 최대한 확대하는 것부터 우선순위 즉시
높여서 수행해." + "AAPL 1주 실거래 검증은 의미없어 중단해."

정확한 지적이다. 기존 방식의 두 결함:

1. **상대 순위만 봤다(절대 바닥 없음)**. 합성 점수는 횡단면 z-점수 = *상대* 순위다. 후보가
   전부 나빠도 "그나마 1위"를 산다 — 수익이 기대 안 되는데도 투자. 세계 최고 수준 아님.
2. **유니버스가 좁았다(3~28종목)**. 상관 높은 메가캡 몇 개를 줄 세운 건 진짜 횡단면 신호가
   아니다(`REAL-DATA-FINDINGS` 교훈).

## 목표

① **절대 기대수익 게이트**(듀얼 모멘텀, Antonacci): 상대 순위로 후보를 고르되, 종목의 *자기*
후행수익률이 절대 바닥을 못 넘으면 **1위라도 사지 않고 현금**. "기대 안 되면 투자 안 함."
② **유니버스 대폭 확대**: 현재(2026) 유효한 고유동성 대형주 ~89종목(섹터 분산).

## 한 일

- **절대 게이트** — `strategy/trend.py` 의 `absolute_momentum` 방식에 `min_return` 임계치 추가:
  `(마지막종가 / lookback전종가 − 1) > min_return` 라야 보유. `TrendFilterConfig.min_return_pct`
  (config) → `TrendSpec.min_return`(전략) 배선(rebalancer·portfolio_replay). 상대 순위(합성
  점수)로 top-N 고른 뒤, 절대 바닥 미달은 현금으로 — 듀얼 모멘텀.
- **유니버스 확대** — `deploy/canary-portfolio.toml`(게이트 ON) + `canary-portfolio-notrend.toml`
  (대조군) 의 유니버스·화이트리스트를 ~89 현재 대형주로(28→89). 스펙 034 의 옛 데이터(2018)
  목록은 상장폐지·합병 종목(AET·AGN·ANTM·CELG…)이 섞여 부적합 → 2026 유효 종목으로 큐레이션.
- **A/B = 게이트의 가치 측정** — canary-portfolio.toml(absolute_momentum 게이트) vs
  canary-portfolio-notrend.toml(게이트 없이 top-N 항상 매수)을 전용 DB 로 병렬 forward 페이퍼.
  forward-verdict 가 둘을 판정 → **"절대 게이트가 정말 1위-항상-매수보다 나은가"의 격리된 답.**
- 워크플로 `--construct-universe-top-n` 15→30(넓은 후보), 타임아웃 20→30분(89종목 백필).
- **AAPL 라이브 캐너리 무장 해제**(`rebalance-live.request` armed:false) — 운영자 "중단".
