# 스펙 048 — 다중 추세 속도 앙상블 실측

데이터: Shiller 1871~ + 런던 금 1833~(둘 다 GitHub). 3자산(주식·채권·금) 역변동성 결합.
재현: `uv run python scripts/trend_ensemble_probe.py [--single 10] [--ensemble 3,6,9,12] [--json]`.

## 핵심 결과 — 앙상블 3/6/9/12 vs 단일 10개월 (3자산 역변동성)

| 구간 | 단일 10개월 샤프/낙폭/칼마 | 앙상블 3/6/9/12 |
|------|------:|------:|
| 전체 1871~ | 1.60 / 5.3% / 1.10 | **1.90 / 3.7% / 1.60** ✓ |
| 현대 1950~ | 1.73 / 5.3% / 1.49 | **2.02 / 3.7% / 2.22** ✓ |
| **자유변동 1971~** | 1.81 / 5.3% / 1.77 | **2.13 / 3.7% / 2.67** ✓ |
| 최근 1990~ | 1.72 / 4.5% / 1.70 | **2.02 / 3.2% / 2.51** ✓ |

**4/4 구간에서 앙상블 엣지** — 샤프 ~1.8 → ~2.0+, 낙폭 ~5% → 3.7%, 칼마 대폭↑(1971~ 1.77→2.67).

## 빠른 속도의 역할 (정직)

| 앙상블 | 엣지 구간 | 비고 |
|------|------:|------|
| 6/10/12 (빠른 3개월 없음) | 3/4 | 전체 1871~만 낙폭 5.3→5.7 미세 악화 |
| 3/6/9/12 (빠른 3개월 포함) | **4/4** | 가장 깊은 1871~ 포함 전 구간 개선 |

→ **빠른 속도(3개월)가 핵심**. 빠른 신호가 급반전을 일찍 잡아 휩쏘·낙폭을 줄인다. 단일 속도의
이진 절벽을 분수 노출(여러 속도 합의 비율)로 부드럽게 한 효과가 위험조정 수익을 끌어올린다.

## 결론

- 다중 속도 앙상블은 *신호 속도 자체를 분산*해 단일 SMA의 휩쏘를 줄인다(세계 최고 수준 managed
  futures 표준). 자산 분산(스펙 043·047)·위험 사이징(044·047)에 더한 **세 번째 분산 축**.
- 결과: 우리 제약(GitHub 데이터)에서 도달 가능한 가장 높은 위험조정 수익 — **샤프 2+ / 낙폭
  3.7%**(기관급), 1871년 실폭락 데이터까지 4/4 견고.
