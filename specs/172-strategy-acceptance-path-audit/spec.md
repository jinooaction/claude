# 기능 명세: 전략 합격 경로 감사와 연구 교착 해소

**기능 브랜치**: `codex/172-next-priority-strategy-audit`
**작성일**: 2026-08-30
**상태**: 확정
**입력**: "매매 자동화 다음 우선순위를 진행하고, 많은 전략이 합격하지 못한 원인이 전략 부재인지 평가 오류인지 확인한다."

## 문제 정의

현재 `globalfixed`는 장기 홀드아웃에서 기준을 이겼지만 전진 관측은 4/20이라 자본은 0이다.
별도의 레짐 후보 `regime-corr24-thr0p2-weak6-cash`는 사전등록 8개 관문 중 7개를 통과했으나
최근 3구간 중 1구간만 이겨 연구 합격이 아니다. 따라서 "유망 신호가 하나도 없다"는 결론은
틀리지만, "현재 전체 합격 경로를 통과한 후보가 없다"는 결론은 맞다.

감사에서 두 가지 구현 오류를 확인했다.

1. 전진 관문 교정은 심은 신호의 절대 검출력 하한을 검사하지 않아, 연 샤프 1.50 신호를
   48개 관측에서 약 15%만 검출해도 `CALIBRATED`를 낼 수 있다.
2. 병렬 연구 후보 ID가 전략 내용이 아니라 `전진 관측 수 // 5`로 바뀐다. 그래서 현재 4개
   관측에서는 이미 완료된 연구 ID와 겹쳐 멈추고, 5개가 되면 새 근거 없이 새 연구처럼 보인다.

## 목표와 비목표

### 목표

- 전진 관문에 무효 오탐률뿐 아니라 심은 신호의 절대 검출력 80% 하한을 적용한다.
- 현재 표본이 하한을 못 채우면 실패가 아니라 `UNDERPOWERED`(검출력 부족)로 명확히 보고하고,
  전진 관찰 자체는 계속한다.
- 8개 실제 레짐 관문과 기존 교정이 다루는 통계 핵심 관문을 구분한 기계 판독 감사를 만든다.
- 7/8 후보를 2026-07 이후 공개 월별 자료로 추적하는 주문 없는 전진 관찰 계약을 등록한다.
- 병렬 연구 후보 ID를 관찰 횟수와 분리해 같은 연구가 멈추거나 중복 발행되지 않게 한다.

### 비목표

- 관문을 낮추거나 기존 후보를 소급 합격시키지 않는다.
- 실주문, 모의 주문 제출, 자본 배분, 라이브 설정, 허용 종목, 한도, 비밀값을 바꾸지 않는다.
- 7/8 후보를 매매 엔진에 구현하거나 `Backtest -> Canary -> Full` 단계를 건너뛰지 않는다.
- 이번 감사가 끝나기 전에 새로운 전략 격자를 대량 탐색하지 않는다.

## 사용자 시나리오와 인수 조건

### US1 — 교정 상태를 정직하게 판정한다 (P1)

1. 48개 관측, 연 능동 샤프 1.50 대조군의 live 검출력이 80% 미만이면 `CALIBRATED`가 아니다.
2. 무효 오탐률 검사는 통과하지만 검출력이 부족하면 `UNDERPOWERED`이며 프로브는 증거를 발행한다.
3. 보고서는 paper/live 검출률, 80% 하한, 통과 여부를 각각 기록한다.

### US2 — 전체 합격 경로의 교정 범위를 드러낸다 (P1)

1. 감사 보고서는 레짐 후보의 8개 관문, 7개 통과, 실패한 `recent_segment_wins`를 재현한다.
2. 기존 가족 교정이 8개 전체가 아니라 PBO와 홀드아웃 PSR 중심의 통계 핵심만 다룬다는 점을
   `PARTIAL_COVERAGE`로 표시한다.
3. 전체 8관문 검출력이 측정되지 않았으면 "84% 전체 합격 검출력"이라고 표시할 수 없다.

### US3 — 유망 후보를 주문 없이 전진 관찰한다 (P1)

1. 사전등록 계약은 후보 지문, 기준 전략, 동결일 `2026-07`, 최소 관측 20, 승격 금지를 담는다.
2. 동결일 뒤 관측이 없으면 `OBSERVATION_WAIT`, 관측 수와 PSR은 0/`null`이다.
3. 월별 자동 실행은 공개 자료만 읽고 별도 사이드카에 결과를 발행하며 브로커·주문·자본 경로를
   참조하지 않는다.

### US4 — 연구 후보 식별자를 관찰 시계와 분리한다 (P1)

1. 전략·연구 목적이 같고 관측 수만 4에서 5로 바뀌면 후보 ID가 동일하다.
2. 출시 장부에 그 ID가 있으면 관측 수가 바뀌어도 같은 후보를 다시 발행하지 않는다.
3. 출시되지 않았다면 기존 전진 관찰 `OBSERVATION_WAIT`와 별개로 감사 작업이
   `EXECUTION_READY` 상태로 존재한다.

## 기능 요구사항

- **FR-001**: 전진 교정 `CALIBRATED`는 무효 오탐률과 심은 신호 paper/live 절대 검출력
  80% 하한을 모두 통과할 때만 허용한다.
- **FR-002**: 오탐 통제는 되지만 검출력이 부족하면 `UNDERPOWERED`로 발행하고 관찰 워크플로를
  중단시키지 않는다.
- **FR-003**: 교정 결과는 절대 검출력 요구치와 각 검사를 기계 판독 가능하게 기록한다.
- **FR-004**: 합격 경로 감사는 실제 8개 관문과 기존 교정이 직접 덮는 관문을 분리한다.
- **FR-005**: 감사 입력의 스키마·후보·관문 집합·안전 불변식이 다르면 안전하게 실패한다.
- **FR-006**: 레짐 후보 계약은 `regime-corr24-thr0p2-weak6-cash`, 기준
  `globalfixed-ensemble-3-6-9-12`, 동결일 `2026-07`을 고정한다.
- **FR-007**: 전진 관찰은 동결일 뒤 후보와 기준의 같은 날짜 월별 수익 차이만 사용한다.
- **FR-008**: 20개 미만은 `OBSERVATION_WAIT`; 충분한 표본도 이번 기능에서 승격을 허용하지 않는다.
- **FR-009**: 월별 자동화는 공개 자료, 고정 계약, 결정론적 프로브만 사용하고 별도 사이드카를 쓴다.
- **FR-010**: 자동화와 결과 모두 `promotion_allowed=false`, `orders_submitted=0`,
  `capital_changed=false`, `live_strategy_changed=false`를 보존한다.
- **FR-011**: 병렬 연구 후보 ID는 안정된 연구 목적과 계약 버전으로 만들고 `n_obs`를 포함하지 않는다.
- **FR-012**: `n_obs`만 바뀌어도 후보 ID와 작업 범위는 같아야 한다.
- **FR-013**: 완료된 후보는 관측 구간 변경으로 다시 발행하지 않는다.

## 성공 기준

- **SC-001**: 고정 시드 2,000회 교정에서 현재 48관측 검출력이 80% 미만이면 결과가
  `UNDERPOWERED`이고 `CALIBRATED`가 아니다.
- **SC-002**: 감사 보고서가 현재 결과를 7/8 통과, 전체 경로 `PARTIAL_COVERAGE`로 판정한다.
- **SC-003**: 현재 공개 자료에서 레짐 전진 관찰은 0개 관측의 `OBSERVATION_WAIT`로 시작한다.
- **SC-004**: 4→5 관측 변경 회귀 테스트에서 후보 ID가 100% 동일하고 중복 발행이 0건이다.
- **SC-005**: 전체 테스트·린트·엄격 하네스·HANDOFF 사실 검증이 통과한다.
- **SC-006**: 모든 테스트와 실제 자동화 정적 검사에서 주문·자본·라이브 설정 변경이 0건이다.

## 위험 등급과 되돌림

**위험 등급 3(안전 경계 판정 표시 변경)**. 돈 경로를 열지 않고 오히려 과장된 교정 표시를
닫는다. 실패 시 이 커밋을 되돌리면 기존 표시와 후보 선택 방식으로 복귀하지만, 이미 발행된
감사 사이드카는 삭제하지 않고 과거 증거로 남긴다. 헌법·커널·실거래 설정은 변경하지 않는다.
