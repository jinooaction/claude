# 조사 기록

## 결정 1: 새 전략보다 합격 경로 교정을 먼저 한다

`globalfixed`는 장기 홀드아웃에서 양의 성과를 보였고, 레짐 후보는 8관문 중 7개를 통과했다.
따라서 문제를 "전략 0개"로 단정할 수 없다. 반면 전진 교정이 실제로는 낮은 검출력인데
`CALIBRATED`라고 표시되고, 유망 레짐 후보는 공식 동결 후 관찰을 쌓지 못한다. 새 격자 추가 전에
평가기의 진실성을 고치는 편이 재작업이 적다.

## 결정 2: 낮은 검출력은 별도 상태로 표현한다

오탐 통제와 검출력은 다른 질문이다. `UNDERPOWERED`는 계산 오류가 아니라 아직 표본이 적어
결론을 낼 힘이 부족함을 뜻한다. 이 상태에서도 전진 관찰을 계속해야 표본이 늘 수 있으므로
프로브는 정상 종료한다.

## 결정 3: 전체 8관문 검출력을 지어내지 않는다

기존 교정은 가족 PBO와 홀드아웃 PSR 중심이다. 경제성, 낙폭, 최근 3구간, 최신 60개월,
회전율까지 동시에 통과할 확률을 측정하지 않는다. 이번 기능은 범위를 `PARTIAL_COVERAGE`로
정확히 표시한다. 전체 경로 교정은 충분한 생성 모형과 양성 대조군을 별도 사전등록한 뒤 수행한다.

## 결정 4: 레짐 후보는 주문 없는 월별 재평가로 관찰한다

현재 페이퍼 엔진에는 레짐 오버레이 실행 설정이 없다. 동일한 공개 월별 데이터, 동일한 고정 후보,
동일한 비용 모델로 동결일 뒤 능동수익을 계산해 별도 사이드카에 보존한다. 이는 매매 체결 검증이
아니라 독립 시계열 증거 수집이다.

## 결정 5: 후보 ID는 의미 기반으로 안정화한다

관찰 횟수는 연구 범위가 아니라 시간 경과다. ID 입력에서 제거하고 기준 후보, 트랙, 역사 판정,
연구 계약 버전만 지문화한다. 출시 장부는 같은 연구를 계속 막는다.
