# 설계 판단과 근거

결정: 완전일만 사후 선별하는 대신 달력/누락을 보존한 별도 입력 계층을 추가한다.
근거: 실제1515거래일에서 DD288분/RTX761분이 빠졌다. 공통 완전일1007개지만
연속 최대48일이다. 기존756일 조건을 조용히 완화하지 않는다.
대안: 이전 가격으로 채우면 없는 거래가 생성되고, 날짜를 삭제하면 다음날/과거14일
의미가 바뀐다. 기존 로더 변경은 기존 연구 재현성을 손상하므로 선택하지 않았다.

시가 관측은 OHLC 분봉 기반 연구 프록시다. 양의 분봉 거래량은 분 종료 뒤에야
알 수 있으므로 시가 주문 유동성을 증명하지 못한다. 입력 API는 이 가용시각을
노출하고 체결 생성은 하지 않는다. 무관측 청산으로 기존 거래를 삭제할 권한도 없다.

독립 원자료 검사는 로컬 `identity-calendar-audit-v1.json`과
`identity-observation-window-audit-v1.json`에 보존돼 있다.

읽기 전용 독립 설계 검토 완료: 기존 resample_dataset은 마지막 관측 버킷으로
entry_eligible을 계산하므로 오후 자료 제거가 오전 판정을 바꿀 수 있다. 따라서
새 경로에서는 해당 함수를 쓰지 않는다. 완전일 필터와5분 정렬 전용 시각 매퍼도
재사용하지 않고 달력 API만 재사용한다. 과거14일 입력은 시초 창/전체 일간 창을
호출자가 명시한다. 미래 행 변경으로 원본 지문이 달라지는 것은 정상이며
인과성 시험은 지문 대신 당시 판정과 실제 사용 관측을 비교한다.
