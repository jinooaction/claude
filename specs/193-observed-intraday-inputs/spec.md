# Feature Specification: 누락을 보존하는 단타 연구 입력

**Feature Branch**: `codex/193-observed-intraday-inputs`
**Created**: 2026-09-21
**Status**: 구현 완료, 전체 회귀 진행 중 — 출시 전
**Input**: 기존 한국투자 계좌용 단타 프로그램 완성을 위해 실제 종목 자료의 누락을 사후 날짜 선택이나 가격 생성 없이 처리한다.

## User Scenarios & Testing

### User Story 1 — 누락을 포함한 전체 달력 확인 (Priority: P1)
운영자는 연구 기간과 종목을 고정하고 어떤 관측이 빠졌는지 확인한다.
독립 시험: 정상/조기폐장/서머타임 전환일과 전체 결측일을 포함한 입력의 예상 시각을 대조한다.
1. 전체 거래일이 누락돼도 그 날짜가 결과 달력에서 사라지지 않는다.
2. 5분 창에 실제1분봉이4개뿐이면 완성봉으로 인정하거나 가격을 채우지 않는다.

### User Story 2 — 당시 알 수 있는 정보로만 신호 허용 (Priority: P1)
운영자는 시초30분과 정확한 직전14거래일 창이 완성된 경우에만 입력 사용 가능 판정을 받는다.
독립 시험: 판단 시각 이후의 자료를 삭제/추가/변경해도 그 시각의 판정이 같아야 한다.
1. 오전 창이 완전하면 오후 누락 때문에 오전 판정을 소급 변경하지 않는다.
2. 직전14거래일 중 자료가 빠지면15일 전 자료로 대체하지 않고 부족 사유를 표시한다.

### User Story 3 — 매수 후 누락을 숨기지 않는 체결 관측 (Priority: P1)
운영자는 체결 예정 시각에 실제 관측이 있는지 확인하고 미관측 주문과 잔량을 보존한다.
독립 시험: 신규 진입 가격 미관측과 청산 가격 미관측을 구분한 시간 순서 사례를 재생한다.
1. 진입 예정 시각 시가가 없으면 체결을 생성하지 않는다.
2. 청산 시각이 없으면 이미 발생한 매수/잔량을 제거하지 않고 미관측 청산으로 남긴다.
3. 다음 관측을 조회할 때 실제 시각과 경과시간을 표시한다. 이를 당초 예정 시각 체결로 되돌리지 않는다.

### Edge Cases
주말·휴일, 조기폐장, 서머타임, 중복·역순·비정상 가격, 음수/0거래량,
분 단위 격자 밖 시각, 다른 공급자 혼합, 완전히 비어 있는 종목/날짜,
마감 후 다음날에만 가격 존재, 자료 끝까지 청산 가격 없음, 지문 변경을 다룬다.

## Requirements
### Functional Requirements
- FR001: 사전에 고정한 종목/기간과 실제 거래소 달력을 유지한다. 누락 날짜/종목을 조용히 제외하지 않는다.
- FR002: 각 관측에 원본 지문, 종목, 시작/종료 시각, 공급자, 조정 정책을 연결한다. 자료 오류와 실제 관측 부재를 구분한다.
- FR003: 1분 원본을 집계하는 창은 예상 시각이 모두 실제 존재해야 완성이다. 불완전 창의 OHLCV를 완성봉으로 내보내지 않는다. 보간·이전 가격 채우기는 없다.
- FR004: 판단 시각 이후 관측은 신호 입력 적격성에 사용하지 않는다. 창 종료 전에는 그 창의 최종 거래량/종가를 사용할 수 없다.
- FR005: 과거 창은 실제 직전 거래일 기준이며 누락을 과거 다른 날로 대체하지 않는다. 부족 날짜와 시각을 보고한다.
- FR006: 체결 시가 조회는 정확한 시각과 실제 관측을 요구한다. 0거래량은 체결 가능 증거가 아니다. 미래 봉 전체 거래량으로 해당 시가 체결 용량을 확정하지 않는다.
- FR007: 정확한 시각의 관측 부재와 이후 최초 관측 조회를 분리한다. 이후 관측은 본래 주문 체결 증거가 아니며, 명시된 연구 정책 없이 자동 체결하지 않는다.
- FR008: 자료 끝까지 청산 관측이 없으면 미해결 상태를 보존한다. 미해결 사례를0손익 또는 제외 거래로 바꾸지 않는다.
- FR009: 기존177/190/191/192 계약·로더·판정은 보존한다. 이 기능은 별도 연구 입력 경로이며 기존 완전봉 계약을 우회하지 않는다.
- FR010: 보고서에는 전체 예상/관측/완성/누락 수, 입력 지문, 종목 식별 미확인 사항이 포함된다. 가격 연결 근거가 부족한 자료를 전략 적격으로 승격하지 않는다.
- FR011: 실제 전략 신호·수익률·합격 판정을 새로 만들지 않는다. 이후 전략은 비용/시도 수(현재 최소30가설)/관측 정책을 별도 고정한다.
- FR012: 생산 주문/자본/허용종목/비밀값/배포 경로를 변경하지 않는다. 연구 입력 도구의 완료는181 전체 실사용 완료가 아니다.

### Key Entities
고정 연구 범위, 원본 식별 정보, 거래일별 예상 시각, 실제 관측, 완성 창,
시점별 입력 가능/부족 사유, 정확 시각 체결 관측, 이후 관측과 미해결 상태, 검증 보고서.

## Success Criteria
- SC001: 고정 달력의 예상 시각100%에 실제 관측/누락 판정이 있고 생성 가격은0개다.
- SC002: 미래 자료를 바꾼 반례에서도 이전 신호 입력 판정100%가 동일하다.
- SC003: 체결 미관측 사례100%에서 허위 체결0건이며 기존 보유를 삭제하지 않는다.
- SC004: 실제 RTX/DD 자료에서1515예상 거래일, 완전일1125/1323, 누락분761/288을 독립 달력 검사와 재현한다. 두 자료의 회사 연결 미확인은 유지한다.
- SC005: 기존 연구 회귀, 전체 시험/린트, 하네스/인계 검증이 통과하고 실주문/자본 변경은0이다.

## Assumptions
위험 등급2: 새로운 연구 흐름과 활성 명세 포인터를 추가한다. 기존 안전 관문을
바꾸지 않는다. 제거 기능은 없고, 되돌림은 신규 입력 경로 사용 중단과 포인터 복원이다.
전체30종목 중28개 추가 취득, 공식 공시 공개일, 기업행동별 가격 연결은 별도 미완료다.
해당 외부 자료를 기다리지 않고 누락 처리의 인과성은 합성 반례와 확보한2종목으로 검사할 수 있다.
