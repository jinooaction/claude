# 연구 지문 계약

1. 같은 검증된 원본·코드·preregistration·판정은 재검증 생성시각만 달라져도 같은 내용 지문이다.
2. 원본 source/manifest 또는 원래 수집시각·파일·날짜·출처·조정·합성/내용 변경은 다른 자료 지문이다.
3. report 생성시각은 원래값으로 보존하지만 지문 입력에서 그 필드만 제외한다. 평가/비용/후보/거래/원본·코드·판정·알 수 없는 필드는 제외하지 않는다.
4. 전체 판정은 실제 재계산에서만 얻는다. 기존 PASS/등록 파일을 입력으로 합격시키지 않는다.
5. 기존 등록·60전진·90초·체결/현금/서명/권한 검증을 바꾸지 않는다. 지문 방식 변경으로 안 맞는 이전 등록은 자동 변환하지 않는다.
6. 검증 script/시험 fixture의 합성 합격이나 메모리 키를 실제서버/실전략/주문권한 근거로 쓰지 않는다.
