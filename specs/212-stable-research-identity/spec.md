# Feature Specification: 재검증 시각과 연구 내용 지문 분리

**Feature Branch**: `codex/212-stable-research-identity`
**Created**: 2026-10-11
**Status**: 코드·작은 합성 검증 완료, 전체 원격검증·병합·실제반영은 후속 확인
**Input**: 기존 한국투자 프로그램을 완성하기 위해 같은 자료·같은 코드의 연구 재검증이 시각 때문에 다른 연구로 판정되는 문제를 해결한다.

## User Scenarios & Testing

### User Story 1 - 같은 연구의 재현 (Priority: P1)

운영자는 원본·계산·후보·비용·코드가 같으면 다시 검증한 시각이 달라도 같은 연구로 확인할 수 있다.
**Why this priority**: 등록 뒤 매번 재검증이 필수인데 시각이 달라지면 등록과 일치하지 못한다.
**Independent Test**: 작은 합성 원본을 시각을 달리해 두 번 검증하고 같은 자료/연구 지문 및 원본 불변을 확인한다.
**Acceptance Scenarios**:
1. 같은 원본과 같은 계산을 다른 시각에 다시 확인하면 내용 지문은 같고 원래 보고서 생성 시각은 별도로 남는다.
2. 실제 전략 미달은 두 번 모두 미달이며 지문 안정성이 전략 합격을 만들지 않는다.

### User Story 2 - 변경과 위조의 거절 (Priority: P2)

운영자는 원본·출처·조정·후보·판정·비용·코드가 달라지면 기존 등록을 사용할 수 없다.
**Independent Test**: 등록 후 내용 변경과 이전 지문 방식·서명 변경을 거절하고 주문/권한이 생기지 않음을 확인한다.
**Acceptance Scenarios**:
1. 시각 이외 내용이나 원본 수집 시각이 달라지면 지문이 달라진다.
2. 검증된 현재 지문과 다른 등록은 거절되며 이전 등록을 자동 변환하거나 다시 서명하지 않는다.

### Edge Cases

- 파생 보고서 시각과 원본 수집 시각의 혼동; 자료 순서·추가·누락·정정·출처/조정 변경.
- 후보/가혹비용/거래내역 지문/코드/사전등록의 변경과 알 수 없는 보고서 필드.
- 같은 내용의 다른 JSON 표현, 비정상 수치, 원본/보고서 동시 수정, 이전 등록 지문.

## Requirements

### Functional Requirements

- **FR-001**: 원본의 전체 지문·날짜·출처·합성 여부·조정 규칙으로 자료 내용을 고정한다. 원본 검증·완전성·원본 보존은 유지한다.
- **FR-002**: 연구 내용은 원본·후보·평가·판정·비용·거래 지문·사전등록·정확한 코드에 묶는다. 파생 보고서 생성 시각만 내용 비교에서 제외한다.
- **FR-003**: 원본 수집 시각을 제외하거나 시각을 만들어 넣지 않는다. 파생 자료와 보고서 생성 시각은 실제 생성 시각으로 보존한다.
- **FR-004**: 새 지문 방식을 구별하며 이전 등록을 현재 방식으로 자동 변환·서명하지 않는다. 모든 기존 등록·60세션·90초·서명·제공자/체결·권한 관문을 유지한다.
- **FR-005**: 정확한 전체 코드 변경은 계속 등록 변경으로 판정한다. 문서 변경을 코드 동일성으로 승인하는 별도 규칙은 이번 범위가 아니다.
- **FR-006**: 실제 전략/미개봉 자료/원본 가격/서버 키/계좌/자금/주문/모드 변경은 없다. 합성 검증과 실제 합격을 구분한다.
- **FR-007**: 반례·전체 원격검사·린트·하네스·인계·본문·병합·실제 배포 관측 범위를 각각 기록한다.

### Key Entities

- 원본 자료 지문: 원래 날짜·원본/명세 지문·출처/조정/합성 범위에 묶인 고정 내용.
- 연구 내용 지문: 생성 시각만 제외한 전체 연구 결과와 버전 경계.
- 기존 등록: 같은 연구·코드·자료·사전등록과 서명을 확인하는 원래 경계.

## Success Criteria

- **SC-001**: 같은 합성 원본·같은 코드의 재검증 시각만 바뀔 때 내용 지문 불일치0.
- **SC-002**: 원본·판정·후보·비용·코드·알 수 없는 내용 변경의 탐지 누락0.
- **SC-003**: 원본 변경·이전 등록 자동 승격·실주문·자본 변경·없는 시각 생성0.
- **SC-004**: 전체 검사 실패0, 필수 반례 무생략, 원래 검사/병합 근거 재현 가능.
