# 자료 계약

- 서버저장소:고정서버디렉터리의`blobs`·`observations`·`runs`추가전용사슬.
  GitHub의기존`automation/issuer-observations`와달리처음부터독립실행한다.
- 일정시도:달력예정과실제시작/종료는별개다.완료기록이없으면성공이아니며
  상태조회가예정간격초과를누락으로계산한다.
- 목록관측:매정상시도마다RSS원본·요청/수신/검증구간을남긴다.
- 본문생략:`selection.unchanged`는같은RSS원본과24시간안의선택본문전체성공,
  직전실패0건을입증할때만양수다.기존`unselected`와`limit_skipped`는별도다.
  과거두필드완료기록도새검증기에서계속읽는다.
- 본문관측:실제새GET와검증완료가있을때만추가한다.이전원본을새관측으로복사하지않는다.
- 원격복구사본:기준/목표파일목록지문·추가파일·원본완료지문을묶는다.
  정정이아닌새복구관측은새이용가능시각을받으며서버시각을소급하지않는다.
- 상태:마지막실제시도/성공/실패,마지막원격백업,사슬지문,다음예정,
  누락범위,주문0건을읽기전용으로나타낸다.
