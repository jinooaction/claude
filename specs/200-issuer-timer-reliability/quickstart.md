# 검증 순서

1. 고정목록의동일/변경,본문실패,24시간경계,시계역행,512MiB한도반례를모의검사한다.
2. Linux에서신규service/timer를분석하고서비스에계좌환경파일과주문명령이없는지검사한다.
3. 정확한PR커밋의원격전체pytest/ruff와엄격하네스·인계·품질검사를통과한다.
4. 일반병합·장외배포와유닛설치증거를분리해확인한다.
5. 실제서버시도두번,변경없는목록의본문생략,서버/원격사본지문대조를확인한다.
6. 정상서버24시간의예정96개시도와누락을계산한다.이결과전에는15분가동완료라하지않는다.

실행은고정Microsoft만대상이다.기존GitHub수집·SEC기록·계좌/주문은별도다.
