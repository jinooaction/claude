# Feature Specification: 공개 보고서의 구조화된 증거 보존

**Feature Branch**: `codex/217-sidecar-json-redaction`
**Created**: 2026-10-16
**Status**: Approved for implementation
**Input**: 운영자 요청 “매매프로그램 완성해”의 현재 운영 차단 원인 조사에서 발견한 공개 보고서 손상 보정.

## User Scenarios & Testing

### User Story 1 - 보호된 보고서를 자동으로 읽기 (Priority: P1)

운영자는 개인정보가 가려진 뒤에도 자동 점검이 판단 수치와 상태를 읽을 수 있어야 한다.
**Why this priority**: 가림 처리가 증거를 손상하면 정상 운영도 점검 불능으로 표시된다.
**Independent Test**: 긴 소수와 비밀값을 함께 넣은 보고서를 처리하고, 수치 보존과 비밀 제거를 동시에 대조한다.
**Acceptance Scenarios**:
1. **Given** 유효한 구조화 블록과 긴 소수, **When** 공개용 가림, **Then** 동일 수치와 상태를 읽을 수 있다.
2. **Given** 계좌·토큰·주문·자본·호스트 값, **When** 공개용 가림, **Then** 기존 비밀 필드와 문자열 보호가 유지된다.
3. **Given** 여러 구조화 블록과 일반 문장, **When** 파일 또는 표준 입력 처리, **Then** 모든 블록과 문장에 해당 보호가 적용된다.

### User Story 2 - 손상된 증거를 정상으로 오인하지 않기 (Priority: P1)

운영자는 이미 손상된 기록이 가공되어 정상 증거로 승격되지 않기를 원한다.
**Why this priority**: 보고서 복구가 거래 허가의 대체물이 되어서는 안 된다.
**Independent Test**: 이미 가려진 숫자와 닫히지 않은 블록은 기존 보수적 가림 경로로 처리되고 원래 수치가 생성되지 않는다.
**Acceptance Scenarios**:
1. **Given** 잘못된 형식의 구조화 블록, **When** 처리, **Then** 기존 텍스트 보호를 유지하며 정상 증거를 합성하지 않는다.
2. **Given** 공개 연구 후보 식별자, **When** 유효한 구조화 블록 처리, **Then** 기존 구조화 파일과 동일하게 식별자를 보존한다.
3. **Given** 거래 관문, **When** 보고서 생성 보정, **Then** 전략·승격·자본·주문·대사 판정은 바뀌지 않는다.

### Edge Cases
여러 블록, 배열·중첩 객체, 소수·지수 표기·정수·참거짓·null, 대소문자 언어 표시,
긴 구분선, CRLF, 끝 줄바꿈 부재, 비JSON 코드 안의 가짜 JSON 구분선,
손상된 기존 기록, 닫히지 않은 구분선, 반복 실행, 지나친 중첩·정수 변환 제한을 시험한다.

## Requirements

### Functional Requirements
- **FR-001**: 유효한 JSON 코드 블록에 기존 구조화 파일의 재귀적 비밀 필드 보호를 적용한다. 일반 수치·타입·상태를 보존한다.
- **FR-002**: 블록 바깥과 일반 코드에는 기존 텍스트 가림을 유지한다. 비밀 필드의 문자열·숫자·객체·배열 값을 모두 가린다.
- **FR-003**: 기존 구조화 보호의 공개 후보 식별자 예외만 재사용한다. 새로운 임의 필드 예외를 만들지 않는다. 계좌 NAV 필드는 명시적으로 민감값으로 보호한다.
- **FR-004**: 유효하지 않거나 닫히지 않은 블록, 지나친 중첩·정수 변환 제한 실패는 기존 텍스트 가림을 유지한다. 삭제된 수치 복원, 관문 우회, 정상 상태 합성은 금지한다.
- **FR-005**: 파일·디렉터리·표준 입력에서 동일한 보고서 처리를 적용하고 기존 JSON/JSONL 동작을 유지한다.
- **FR-006**: 비밀 회귀·소비자 파싱·명령 실행을 자동 시험한다. 정확 커밋 전체 테스트·린트·하네스·인계 검사 후 병합한다.
- **FR-007**: 기존 기록과 감사 로그는 수정하지 않는다. 새 예약 실행의 자연 발행으로 적용하며 자본 사다리 재실행을 임의 요청하지 않는다.

### Key Entities
- 공개 보고서: 일반 문장과 여러 구조화 증거 블록.
- 보호 대상: 기존 비밀 필드 및 계좌 NAV, 문자열 내 비밀 패턴.
- 공개 증거: 수치·상태·후보 식별자. 의미와 원본 시각이 유지되어야 한다.

## Success Criteria

### Measurable Outcomes
- **SC-001**: 모든 정상 시험 보고서에서 보호 전후 비민감 수치·상태가 동일하며 자동 판독에 성공한다.
- **SC-002**: 모든 비밀 반례에서 지정된 민감값 노출이 0건이다.
- **SC-003**: 손상된 과거 증거의 추측 복원·주문·자본 변경이 0건이다.
- **SC-004**: 관련 및 전체 검증 실패 0건이며 남은 운영 조건을 인계에서 구분한다.

## Assumptions
신뢰된 생산자가 JSON 코드 블록에 증거를 기록한다. 일반 문자열에서 의미 없는 숫자와 계좌 번호를 임의 구분하지 않는다.
기존 숫자형 JSON 보호 계약을 보고서에 확대한다. 잘못된 형식의 일반 텍스트 보호는 기존 한계를 유지한다.
