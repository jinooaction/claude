## 정규 발행 적용 조건
forward-edge-autoarm.yml은 최신 main의 공통 스크립트를 호출한다.
해당 workflow는 자본 경로를 포함하므로 보고서 새로고침만을 위해 수동 실행하지 않는다.
이미 손상된 과거 LAST_RUN.md는 정상 원본으로 재생성되는 다음 기존 실행까지 경고가 남을 수 있다.
후속 확인은 automation/edge-autoarm-last-run의 run URL·시각·결정 JSON 파싱과
money-gate-alignment의 edge-autoarm 파싱 상태를 함께 대조한다.
파싱 성공도 전략 통과·자본 승격·신규 체결 증거는 아니다.
