# Feature Specification: 가입 없는 공개 분봉 원본 검증

**Feature Branch**: `codex/207-public-minute-pilot`
**Created**: 2026-10-04
**Status**: 실제 전체 원본/구조/암호화 보관·전체5318검사 완료, PR879 최종 기록/병합 확인 중
**Input**: 무료 과거 자료의 다른 경로를 찾아 단타 프로그램 완성을 계속한다.

## User Scenarios & Testing

### User Story 1 - 추가 가입 없이 원본을 확인한다 (Priority: P1)

운영자는 연락처, 로그인, 인증 키를 새 자료 공급자에게 주지 않고 과거 두 달의
분봉 원본을 확보한 사실과 실패한 사실을 구분해 볼 수 있다.

**Why this priority**: 인증 입력 대기를 다른 실제 자료 경로로 해결한다.
**Independent Test**: 고정 두 원본의 전체 바이트 크기와 지문을 실제 대조한다.
**Acceptance Scenarios**:

1. **Given** 공개 고정 원본, **When** 전체 취득, **Then** 두 파일 모두 검증된 경우에만 확보로 기록한다.
2. **Given** 주소 이동·중단·지문 불일치, **When** 취득, **Then** 실패 원인만 남기고 확보로 표시하지 않는다.

### User Story 2 - 거래소 시간을 기준으로 품질을 확인한다 (Priority: P2)

운영자는 가격 성과를 조회하지 않고 종목별 시간 범위·결측·중복·가격/거래량 오류를 확인한다.

**Why this priority**: 파일 존재를 전략에 쓸 수 있는 자료로 오인하지 않는다.
**Independent Test**: 다음 UTC 달에 속하는 정상 뉴욕 야간 봉과 잘못된 월의 봉을 구분한다.
**Acceptance Scenarios**:

1. **Given** 뉴욕 월별 봉, **When** 검사, **Then** 뉴욕 월과 정규장 달력을 기준으로 판단한다.
2. **Given** 중복·비정상 가격·분 경계 이탈, **When** 검사, **Then** 오류 개수를 보존하고 자격을 부여하지 않는다.

### User Story 3 - 결과를 잃거나 반복 요청하지 않는다 (Priority: P3)

운영자는 원본과 안전한 보고서를 다시 검증할 수 있고 실패한 시도를 계속 재시작하지 않는다.

**Why this priority**: 일시 보관 만료와 무한 재시도로 같은 일을 반복하지 않는다.
**Independent Test**: 동일 검토 코드의 첫 시도를 영구 기록하고 두 번째 시도는 네트워크 전에 거절한다.
**Acceptance Scenarios**:

1. **Given** 최초 성공, **When** 보관, **Then** 평문 가격 없이 암호화 원본과 지문·보고서만 남긴다.
2. **Given** 과거 성공 또는 실패 기록, **When** 같은 코드 재실행, **Then** 이전 기록을 덮어쓰거나 새 취득하지 않는다.

### Edge Cases

- 전체 파일 대신 일부 응답, 잘못된 길이, 403/429/5xx, 응답 중단, 무한 주소 이동.
- 시간대 없는 자료·UTC 다음 달의 정상 야간 자료·휴장/조기폐장·중복 종목/시각.
- 실수 거래량·음수/무한/결측 가격·저가/고가 모순·손상된 원본.
- 원본 취득 성공 뒤 암호화/보관 실패, 첫 시도 선점 뒤 작업 중단.

## Requirements

### Functional Requirements

- **FR-001**: 추가 가입·인증·비용·맥북 화면 조작 없이 고정 개발 자료 두 파일만 원격에서 취득한다.
- **FR-002**: 고정 원본 버전·경로·크기·전체 지문을 대조하고 일부만 받은 자료를 인정하지 않는다.
- **FR-003**: 요청 간격·최대 세 번 재시도·전체 시간/바이트 예산과 안전한 주소 이동을 적용한다.
- **FR-004**: 동일 검토 코드의 최초 시도를 취득 전에 영구 선점한다. 실패해도 자동 해제하지 않는다.
- **FR-005**: 뉴욕 월·정규장 달력·봉 시작 및 다음 분 가용 시각을 명시하고 품질/종목별 누락을 보고한다.
- **FR-006**: 성공 원본은 암호화해 추가 전용으로 보관하며 가격·연락처·키·임시 서명 주소를 공개하지 않는다.
- **FR-007**: 취득, 품질, 보관을 각각 기록한다. 출처/가격 조정/당시 종목 구성/실행 동등성은 미검증이다.
- **FR-008**: 전략 수익률·기존 최종 확인495세션을 조회하지 않는다. 주문/승격 자격은 항상 거짓이다.
- **FR-009**: 기존 자료1645세션·최소36개 선행 시도·비용31/40bp·한도·정산·감사·배포 관문을 유지한다.

### Key Entities

- 고정 원본: 공급자 위치, 파일 버전, 개발 월, 전체 크기·지문.
- 취득 영수증: 실제 받은 크기·지문, 성공/실패, 인증/가격 성과 조회 없음.
- 품질 보고서: 시간·종목·봉 오류/결측 개수, 미확인 출처와 거래 자격 없음.
- 영구 시도 기록: 검토 코드와 선점 결과, 암호화 원본·안전한 보고서 지문.

## Success Criteria

### Measurable Outcomes

- **SC-001**: 두 고정 원본 전체 검증과 보관의 성공/실패를 재현할 수 있다.
- **SC-002**: 전체 취득은 15분 안에 종료하고 반복 시도는 원본 요청 전에 거절한다.
- **SC-003**: 날짜·가격·중복·거래량·종목별 정규장 결측의 검사 결과가 두 달 모두 남는다.
- **SC-004**: 원본 확보나 검사 통과를 전략 합격으로 표시하지 않으며 신규 주문은 0건이다.

## Assumptions

설계 시 공개 메타데이터와 37674바이트 구조 정보 접근을 확인했고 전체 취득은 미확인이었다.
현재 실제 두 전체 원본/품질/암호화 보관 완료 증거는 [results.md](results.md)를 따른다.
업로더의 Finnhub 출처 주장은 공급자 확인이 아니며 명시 라이선스가 없으므로 평문 재배포하지 않는다.
개발 월은 2014-01/2019-12이며 기존 미개봉 구간을 사용하지 않는다. 새 전략 가설은 이 작업에 포함하지 않는다.
위험 등급3: 외부 요청·비밀 격리·영구 보관을 새로 연결하므로 전체 명세 절차를 적용한다.
자동 실행을 중단하고 기존 기록을 보존하면 되돌릴 수 있다. 주문·운용 설정은 변경하지 않는다.
