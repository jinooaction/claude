# 연구 결정 — 2026-10-02

공식 [API](https://hfdatalibrary.com/pages/api)는 `/symbols`를 공개하고 인증된 `/bars`는 전체
종목 Parquet를 반환한다. 기간 필터가 없고 기본 정리본을 피하려면 `version=raw`를 명시한다.
무료 키는 30일 만료한다. 기존 무료 계정을 사용하며 새 가입·비용·대량 묶음을 요청하지 않는다.

[원천 한계](https://hfdatalibrary.com/pages/issues): 2022년 3월 전후 통합 시장 자료에서
IEX 단일 거래소 자료로 바뀐다. 자료 정리로 제거할 수 없는 거래량·가격 범위 차이다.
이번 원본 수집에서 가격 값이나 최종 성과를 평가하지 않는다. 189/192/194/202–204의 실패를
다시 통과로 해석하지 않고 비용 31/40bp와 181의 검증 관문을 그대로 둔다.

기존 broker/client.py는 메모리 차단기이고 filing_collector.py는 보존 저장소 복원을 전제로 한다.
임시 Actions 실행기에서 그대로 재사용하면 실패 이력이 초기화된다. 계획 스킬의 읽기 전용
검토자도 이 문제와 첫 요청 간격·실제 20초 제한·Retry-After 누락을 확인했다.

전용 작업의 가장 최근 실행을 성공 여부와 무관하게 조회하고 작은 상태 산출물을 복원한다.
조회 오류는 중단한다. 같은 실행의 재시도도 이전 시도의 종료 시각을 증명할 수 없어 중단한다.
이전 종료 실행의 산출물 누락/손상/만료는 새 이력으로 간주하지 않는다. GitHub가 제공한
종료 시각 이후 900초가 지난 경우에만 실패 3회 상태의 반개방 요청을 허용한다.
미완료 이전 실행은 요청하지 않는다. 이 보수 복원이 항상 업로드의 취소 취약점을 보완한다.
임의 날짜 입력으로 원격 차단을 우회할 수 없도록 원격 증명은 GitHub 조회 단계만 만든다.

목록 성공은 원본 실패 누적을 지우지 않는다. 자료 수집은 별도 전체 성공 상태이며 실패 후
존재하는 확정 파일은 부분 성공으로 남긴다. 상태 산출물 90일 보존은 영구 자료 보존과 다르다.
원본은 별도 artifact로 보존하고 장기 연구 입력의 영구 보관은 이후 확인한다.

Parquet 검사에는 기존 고정 개발 의존성 DuckDB를 사용한다. footer와 열 구조만 읽고 가격
행을 쿼리하지 않는다. 원격 연구 전용이며 운영 서버의 의존성·서비스·주문 경로를 바꾸지 않는다.
