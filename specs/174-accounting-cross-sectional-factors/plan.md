# 구현 계획: 회계 기반 횡단면 다요인 전략

**브랜치**: `codex/174-accounting-cross-sectional-factors` | **날짜**: 2026-08-31 | **명세**: [spec.md](./spec.md)

## 요약

공식 Fama–French 월별 5팩터 자료의 2015년 보관본과 최신본을 분리해 사용한다. 가치(HML),
영업수익성(RMW), 보수투자(CMA)의 사전등록 8개 조합과 2개 슬리브 배율을 교차한 16개
회계 팩터 후보를 개발/차단/홀드아웃으로 평가한다. 기존 784개·19가족 감사 장부 뒤에
16개·1가족을 추가해 800개·20가족으로 재구성한다. 연구 대리값은 정확한 종목·공매도·체결
계약이 아니므로 결과와 관계없이 자본·주문·라이브 설정을 바꾸지 않는다.

## 기술 맥락

**언어/버전**: Python 3.11, Bash/YAML, JSON Schema 2020-12  
**주요 의존성**: NumPy, 표준 ZIP/CSV 파서, 기존 PSR·DSR·PBO 모듈, GitHub Actions  
**저장소**: 사전등록 JSON과 orphan sidecar 브랜치의 JSON/Markdown/JSONL 증거  
**테스트**: pytest 단위·통합 시험, Ruff, JSON Schema, 생산 프로브 재생  
**대상**: GitHub Actions Linux 러너와 로컬 분석 명령  
**성능 목표**: 16개 후보의 1963년~현재 월자료 재생 30초 이내, 전체 공장 25분 이내  
**제약**: 결과 전 계약 동결, 개발·홀드아웃 자료 분리, 결정론, 브로커·주문·자본 접근 0  
**범위**: 분석 모듈·프로브 1쌍, 중앙 공장 연결, 20가족·800행 감사, 결과·인계 증거

## 헌법 점검

- 원칙 I~VII, VIII.A, IX, X의 주문 한도·허용 종목·감사·비밀값·장중 배포 제한은 바꾸지 않는다.
- X.4 연구 단1은 point-in-time, 라이브 동등성, 10% 주문 구현성까지 요구한다. 이번 공식 팩터
  수익은 종목·수량이 없는 롱숏 대리값이므로 `research_live_parity=false`, 승격 금지다.
- 20번째 가족은 `20 × 0.01 = 0.20`으로 현재 교정 예산의 마지막 허용 가족이다. 공시 후
  드리프트를 21번째로 추가하려면 결과 전에 새 최대 가족 수와 검출력을 다시 교정해야 한다.
- PBO 0.25·홀드아웃 PSR 0.95·가족 단위 고정시드 교정을 유지하고 DSR·전체 후보 보정은
  진단값으로 보존한다. 기준을 낮추거나 결과 뒤 후보를 추가하지 않는다.
- `Backtest -> Canary -> Full` 순서를 건너뛰지 않는다. 이 작업은 첫 단계의 연구 증거만 만든다.
- 센티넬, 자본 비율, 손실 예산, 포지션 한도, 화이트리스트, 브로커 호출은 수정하지 않는다.
- 헌법·커널 목록은 변경하지 않는다. 위험 등급 4지만 돈 경로를 여는 변경은 아니다.

## 구현 단계

1. 16개 정책·자료 URL·분할·비용·관문을 JSON 계약으로 고정한다.
2. 보관본/최신본 ZIP의 월별 표·연별 표를 구분해 필수 6열만 엄격 파싱한다.
3. 두 자료의 개발 월 정합성·변경량·지문을 기록하고 홀드아웃 값은 개발 선택에서 격리한다.
4. 16개 후보의 비용 후 월수익, 10개 개발 조각, PBO·DSR을 계산한다.
5. 개발 승자 하나에 대해 홀드아웃 PSR·경제성·시대·최근·집중도·낙폭·비용·위약 관문을 계산한다.
6. 기존 784행을 독립 검증하고 회계 16행을 더해 800행·20가족을 재구성한다.
7. 결과 JSON/Markdown과 중앙 공장 sidecar를 게시하되 배포 설정은 항상 `null`로 둔다.
8. 코드와 기준을 먼저 커밋한 뒤 공식 자료를 한 번 내려받아 실제 판정을 고정한다.

## 복잡성 추적

| 추가 구조 | 이유 | 더 단순한 대안을 쓰지 않은 이유 |
| --- | --- | --- |
| 보관본+최신본 이중 자료 | 공식 사이트가 과거 수익을 재구성하므로 개발 선택과 최신 홀드아웃을 구분 | 최신 파일 하나만 쓰면 과거 수정 한계를 숨긴다 |
| 연구 전용 롱숏 대리값 | 회계 프리미엄 자체의 존재를 가격 전략과 독립적으로 먼저 판정 | SEC 현재 종목만으로 즉시 백테스트하면 생존편향·공시시점 누출이 생긴다 |
| 별도 회계 팩터 공장 | 월별 팩터 조합·부호 위약·고정 비용이 달력 공장과 다름 | 기존 모듈에 섞으면 후보 지문과 자료 계약이 모호해진다 |

## 설계 후 헌법 재점검

설계 산출물은 20가족 예산을 초과하지 않고, 실행 동등성 실패를 의도적으로 보존한다. 역사
합격이 나와도 선택 배포 설정·실자본·주문은 만들지 않는다. 누락 자료, 중앙 장부 불일치,
교정 불일치는 모두 결과 게시 전에 실패 폐쇄한다. 따라서 현재 최대 손실 표면은 넓어지지 않는다.
