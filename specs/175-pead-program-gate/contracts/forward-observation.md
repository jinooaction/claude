# PEAD 전진 관찰 계약

이번 역사 연구는 실제 주문으로 이어지지 않는다. 다음 검토를 시작하려면 2026-09-01 이후
새로 발생한 실적 발표만 사용해 아래 조건을 모두 충족해야 한다.

1. SEC 공시 접수 시각을 기준으로 당시 이용 가능했던 정보만 사용한다.
2. 최소 200개 실적 발표와 12개월을 모두 관찰한다.
3. 종목 편입·제외를 당시 상태로 보존하고 상장폐지 수익을 포함한다.
4. 공매도 가능 여부와 차입 비용을 기록한다.
5. 현재 KIS 계좌의 정수주, 최소 주문 금액, 수수료와 환전 비용으로 재현한다.
6. 연구 정책 ID와 지문을 변경하지 않는다. 변경하면 새 후보 가족으로 다시 사전등록한다.
7. 누락 이벤트, 정정 공시, 거래정지, 가격 결측은 실패 폐쇄한다.

초기 상태는 관찰 이벤트 0, 관찰 월 0, 시점보존 false, 상장폐지 보정 false, 실행 동등성 false,
다음 검토 적격 false다. 이 문서는 라이브 전환 승인이 아니라 다음 증거 수집 조건이다.
