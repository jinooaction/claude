# 스펙 032 — 검증 교리: 옛 데이터 백테스트는 필터, 현재 데이터 forward 페이퍼가 판정

## 문제 (운영자 지적, 2026-06-01)

> "지금은 2026년인데 너무 지나치게 과거 데이터만 활용하고 있는 거 아니야? 폭락장(2008·2000)도
> 결국 지나치게 과거 데이터인데?"

정확한 지적이다. **모든 백테스트는 과거다.** 그리고 과거의 시장은 2026년과 *구조가 다르다*:
참여자(고빈도·패시브 자금·리테일 비중), 통화 regime(제로금리 vs 고금리), 미시구조(체결·
스프레드), 지수 구성이 모두 변했다. 2013-2018 강세장은 물론, 2008·2000 폭락장조차 2026년
시장에 대한 약한 대용물이다. **"과거에 잘 맞았다"는 "지금 통한다"를 보장하지 않는다.** 옛
데이터에 설정을 맞출수록, 우리는 *존재하지 않는 과거 regime* 에 과적합한다.

## 이 컨테이너의 제약이 교리를 강제한다

이 실행 환경의 네트워크 정책은 git/PyPI 의존성 호스트는 허용하지만 라이브 시세 API(KIS·
Yahoo·Stooq)는 막는다. github raw 의 공개 데이터셋은 전부 옛것(예: datahub S&P500 은
2018년까지 월봉). 즉 **이 컨테이너에서는 최신 데이터 백테스트 자체가 물리적으로 불가능**
하다. 이 사실이 결론을 분명히 한다 — 현재 데이터 검증의 유일한 장소는 라이브 인스턴스다.

## 교리 (3계층 검증)

전략 후보는 세 관문을 *이 순서로* 통과해야 한다. 각 관문은 앞 관문이 통과해도 뒷 관문을
면제하지 않는다.

### 1계층 — 옛 데이터 백테스트 = 값싼 과적합 필터 (필요조건, 충분조건 아님)

`backtest-portfolio` + `portfolio-walk-forward`. 목적은 *떨어뜨리는 것*이다: 옛 데이터에서
표본 외(워크포워드) + 디플레이티드 샤프(시도 횟수 보정)조차 통과 못 하는 후보는 더 볼 필요
없이 버린다. **여기서 통과해도 "좋은 전략"이 아니다** — 그저 "명백히 과적합/엉터리는 아님"
일 뿐. 옛 regime 의 통계적 정상성에 기댄 약한 신호다. *절대 이 단계 숫자로 라이브를
정당화하지 마라.*

### 2계층 — 현재 데이터 forward 페이퍼 트랙 = 진짜 판정 (핵심)

`rebalance-once --mode paper` 를 인스턴스에서 *주기적으로* 돌려(워크플로
`rebalance-paper-forward.yml`, 매월 1일), 라이브 KIS 시세로 가상 체결(ORDER_PAPER_FILLED)을
누적한다. 돈은 움직이지 않는다. 이게 *진짜 표본 외* 다 — 백테스트의 "과거 표본 외"가 아니라
**시간상 미래(forward) 표본 외**, 즉 후보를 만들 때 존재하지도 않았던 데이터.

충분한 forward 관측이 쌓이면(헌법 VI 의 정신: 최소 ~30 거래일, 그러나 통계적으로는 더 필요)
성과 엔진(스펙 011) + 디플레이티드 샤프(스펙 027)로 "현재 데이터에서 우연이 아닌 엣지"인지
판정한다. **단순 보유 대비 위험조정(샤프·최대낙폭) 우위가 forward 트랙에서 유의해야** 한다.

### 3계층 — 라이브 캐너리 (운영자 게이트, 실제 돈)

2계층 forward 페이퍼가 유의한 엣지를 보이고 *나서야* 라이브 캐너리를 고려한다. 이건 헌법
X.4 + go-live-canary 채널 + 운영자 명시 게이트다. 자율 승격 0건(스펙 026 게이트 + IX.B-2).

## 무엇이 바뀌나

- **전략 탐색의 1차 산출물이 "옛 백테스트에서 단순 보유를 이기는 설정"이 아니다.** 그건
  과적합 함정(운영자 우려 그대로). 1차 산출물은 *후보를 forward 페이퍼 트랙에 올리는 것* 이고,
  몇 주~몇 달의 현재 데이터 트랙이 옛 백테스트 어떤 숫자보다 무겁다.
- **재현 가능한 forward 트랙 인프라가 이제 존재**한다: `deploy/canary-portfolio.toml`(시드 설정)
  + `rebalance-paper-forward.yml`(월간 페이퍼 검증, 사이드카 브랜치 발행). 운영자 인스턴스에서
  돈 없이 돈다.
- **경제적 사전확률 우선**: 데이터 마이닝한 상관보다 경제적 근거(위험 프리미엄·행동 편향)가
  있는 신호가 regime 변화에 더 강건하다. 이걸 후보 설계 원칙으로 삼는다.

   2계층 forward 트랙이 한다.

   (관측이 충분히 쌓인 뒤 의미 있음).
