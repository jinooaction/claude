# 스펙 034 — 체계적 유니버스 구성 (유동성 기반 횡단면)

## 문제 (왜 이게 수익률의 다음 병목인가)

이 시스템의 알파 스택 전체 — 횡단면 모멘텀 순위(스펙 021), 다요인 합성 점수(스펙 025),
포트폴리오 재조정(스펙 032), 최소분산·최대샤프·ERC 최적화기 — 는 **넓은 횡단면**을 전제로
설계됐다. 횡단면 팩터 엣지(모멘텀·저변동성·퀄리티)는 본질적으로 *폭(breadth) 현상*이다:
수백 종목을 가로질러 순위를 매겨야 신호가 표현된다.

그런데 모든 백테스트·검증은 지금까지 **상관 높은 15개 대형주**로만 돌았다(`sp500-portfolio.toml`,
`canary-portfolio.toml`). 15종목에서 "횡단면 모멘텀"은 사실상 기술주 베타 동전던지기다 — 진짜
팩터가 표현될 폭 자체가 없다. 반복된 정직한 결론("디플레이티드 샤프로 보정하면 단순 보유를
이기는 엣지 없음")의 숨은 교란변수가 바로 이 좁은 유니버스다.

게다가 유니버스가 **손으로 고른 하드코딩 리스트**다. 세계 최고 수준 시스템은 종목을 손으로
고르지 않는다 — 투자 가능 횡단면에서 **유동성과 충분한 가격 이력**으로 체계적으로 *구성*한다.
유동성은 들고 날 수 있는 한도이고, 가격 이력은 순위를 매길 수 있는 한도다.

## 목표

투자 가능 횡단면(예: S&P500 약 500종목 실데이터)에서 **유동성(중앙값 달러 거래대금)** 으로
순위를 매겨 거래 가능 유니버스를 결정론적으로 *구성*하는 재사용 모듈을 만들고, 그 넓은
유니버스 위에서 기존 알파 스택을 워크포워드 + 디플레이티드 샤프(표본 외 + 과적합 보정)로
정직하게 검증한다.

## 기능 요구 (FR)

- **FR-U01** 종목별 일봉에서 **중앙값 달러 거래대금**(close × volume, 최근 N봉)을 결정론적
  Decimal 로 계산한다. 데이터 부족 종목은 None.
- **FR-U02** 유니버스를 유동성 내림차순으로 **순위**화한다(동점은 심볼명 사전순). 데이터 부족
  종목은 sentinel 로 맨 끝.
- **FR-U03** `select_universe(top_n, min_dollar_volume, min_history_bars, lookback_bars)` —
  최소 이력·최소 유동성 필터를 통과한 종목을 유동성 상위 top_n 으로 **구성**해 정렬된 심볼
  리스트를 반환한다.
- **FR-U04** 데이터 수집 스크립트(`fetch_sp500_subset.py`)가 CSV 의 **전체 횡단면**(약 500종목)을
  추출할 수 있어야 한다(`--all`).
- **FR-U05** 구성된 넓은 유니버스로 `portfolio-walk-forward` 를 돌려 표본 외 + DSR 결과를
  `FINDINGS.md` 에 정직하게 기록한다. **⚠ 단, 가용 데이터(2013-2018)는 최근성 가드가 stale 로
  표시한다 — 그 결과는 전략 판정이 아니라 한계 시연이며, "지금 통하는가"의 판정은 현재
  데이터 forward 페이퍼(스펙 032/033)만 한다(교리: `FORWARD-VALIDATION.md`).**

## 성공 기준 (SC)

- **SC-U01** 동일 일봉 → 동일 유니버스(결정론, live == backtest, 헌법 X.2).
- **SC-U02** 유동성 순위가 알려진 입력에서 올바른 순서(높은 달러 거래대금 우선).
- **SC-U03** 최소 이력 미달·최소 유동성 미달 종목은 구성에서 제외.
- **SC-U04** 넓은 횡단면 워크포워드가 실행되고 결과가 디플레이티드 샤프로 기록된다 — **단
  데이터가 stale 이면 전략 판정으로 쓰지 않는다**(stale 백테스트로 폭 가설을 닫는 것은 금지).

## 안전 경계 (비협상)

- **비커널(NON-KERNEL).** 선택 전용 — 어떤 종목을 *고려*할지만 정한다. K1 캡(`risk/gates.py`)·
  사이징·주문 라우터 무변경. 구성된 유니버스는 실주문 전에 반드시 운영자 화이트리스트와
  교집합되므로(헌법 II 거부-우선), 유니버스 구성이 라이브 거래 집합을 화이트리스트 너머로
  넓힐 수 없다.
- **돈 안 움직임.** 백테스트·CLI·스크립트 전용. 라이브 워커 룰 루프 무변경.
- **결정론·LLM 미사용.** Decimal 산술, 판단 지점 호출 0건.
