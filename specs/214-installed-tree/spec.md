# Feature Specification: 설치 폴더 전체의 읽기 전용 파일 비교

**Feature Branch**: `codex/214-installed-tree`  
**Created**: 2026-10-14  
**Status**: 구현·합성 완료, 정확 원격 전체 회귀 대기  
**Input**: 후보 환경 설치·설치 파일 무결성의 경계를 별도 기능으로 구체화한다.

## User Scenarios & Testing

### User Story 1 - 버전이 같은 파일 변경 발견 (Priority: P1)
운영자는 버전 표시가 같아도 설치 폴더의 실제 파일이 바뀌었는지 확인한다.
독립 시험: 작은 합성 폴더의 버전 표시는 유지하고 파일 한 바이트를 바꾸면 불일치한다.
수락: 원래 목록·내용·실행 비트·빈 디렉터리까지 같으면 지역 비교 일치, 하나라도 다르면 불일치한다.

### User Story 2 - 불완전한 검사와 권한 구분 (Priority: P1)
운영자는 읽을 수 없는 파일·별칭·동시 변경·검사 한도를 통과로 오인하지 않는다.
독립 시험: 추가/삭제 파일, 링크, 특수 파일, 읽기 도중 변경, 잘못된 선언을 각각 거절한다.
지역 일치도 원본 선언의 진위·후보 실행 환경 전체·등록·실주문 허가를 확인하지 않는다.

### Edge Cases
빈 파일/빈 폴더, 중복·상위 경로·대소문자 별칭, 부모 경로의 링크, 다른 장치의 마운트,
파일 교체/모드 변경, 검사 중 폴더 변경, 선언 내부 누락, 시작시 실행되는 파일, 외부 기본 Python.

## Requirements
- **FR-001**: 지정된 독립 설치 폴더의 모든 항목을 기대 목록과 비교한다. 숨김 파일·캐시·메타데이터를 임의 제외하지 않는다.
- **FR-002**: 파일의 크기·전체 내용·권한과 디렉터리 목록을 비교한다. 버전/설치 목록만으로 일치라고 하지 않는다.
- **FR-003**: 선언의 중복·알 수 없는 필드·경로 탈출·한도 초과를 거절한다. 링크·공유 파일·특수 파일·다른 장치·별칭을 거절한다.
- **FR-004**: 두 번의 전체 관측과 각 읽기 전후 상태가 다르면 결과를 사용할 수 없다고 표시한다. 지속 불변이나 공격자에 대한 인증은 주장하지 않는다.
- **FR-005**: 파일 내용, 전체 경로, 환경변수, 예외 전문을 출력하지 않는다. 출력은 작은 한 결과로 제한한다.
- **FR-006**: 후보 코드를 불러오거나 다른 실행기를 실행하지 않는다. 설치·서버·키·수집·등록·장부·매매·배포를 호출하지 않는다.
- **FR-007**: 설치 파일 비교는 선언된 폴더에 한정한다. 외부 기본 Python·표준 라이브러리·실제 실행의 검색 경로·기동 코드·전이 의존성 충족은 별도 미평가다.
- **FR-008**: 기존213 비교/등록·수집·전진 검증기에 연결하지 않는다. 준비·자격·승격은 항상 미평가/거짓이고 주문은0이다.

### Key Entities
기대 목록(미서명 상대 항목·파일 크기/권한/지문), 지역 관측(두 번의 전체 항목/상태), 비교 결과(일치·불일치·조회 불가와 미평가 범위).

## Success Criteria
- **SC-001**: 같은 버전의 합성 파일 변조·추가·삭제·권한 변경을 모두 발견한다.
- **SC-002**: 링크/누락/동시 변경/한도 반례에서 통과 결과를0건 생성한다.
- **SC-003**: 모든 결과는16KiB 이내이며 실제 설치·수집·등록·매매·권한 변경을0건 수행한다.
- **SC-004**: 원격 전체 회귀·기존 필수 반례·린트와 정확 검토 코드의 종료 근거를 재현할 수 있다.

## Assumptions
비밀 없는 전용 설치 이미지와 별도로 확보한 기대 목록만 입력한다. 기대 목록의 신뢰성은 이 비교로 생기지 않는다.
일반 링크형 가상환경은 지원하지 않으며 파일 복사형 독립 이미지의 가능조건을 점검한다.
실제 운영 환경의 설치/활성화는 이번 범위 밖이다. 전체181·1645세션·최소36시도·495미개봉·90초/60세션 관문을 유지한다.

## 위험·되돌림
등급2: 독립 점검 도구/원격 검사/인계 포인터를 추가한다. 기존 기능 제거0.
새 도구와 검사만 제거하면 기존 등록·수집·진단·주문 경로는 그대로다. 실행 자격에 연결하려면 별도 등급3 SDD가 필요하다.
