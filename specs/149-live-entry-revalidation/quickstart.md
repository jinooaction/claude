# Quickstart: 최신 엣지 재검증과 병렬 탐색

1. 최신 수익 증거와 강화 캐너리, 체결 0건을 입력해 주문 차단을 재현한다.
2. PSR 0.80 이상과 모든 게이트 PASS 입력에서 주문 전 판정만 통과하는지 확인한다.
3. 자본 사다리 단 1에 체결 0건·자격 실패를 입력해 단 0 강등을 확인한다.
4. liveness 수집의 첫 조회 실패 뒤 개별 ref 재시도 계약을 확인한다.
5. forward 미달 수익 증거에서 병렬 challenger가 선택되는지 확인한다.
6. live workflow가 주문 뒤 체결·손익·정합성 결과를 모두 발행하는지 정적으로 확인한다.
