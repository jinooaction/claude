# 장기 실제 분봉 확보와 독립 연구 재검증

요청: 실제 과거 자료 확보와 전략 재검증을 완료한다. 기존 한국투자 계좌는 유지한다.
위험 등급3: 별도 데이터 공급자의 인증된 읽기 경로 추가. 주문·계좌·자금·기존 위험 관문은
변경하지 않는다. 데이터 구독 결제와 키 연결은 별도 외부 조건이며 이번 구현으로 대신하지 않는다.

- FR001: SPY/QQQ/IWM/TLT/GLD의 지정 기간 정규장5분 OHLCV를 Massive에서 GET으로 읽는다.
  공급자는 massive-sip-unadjusted로 표시한다. KIS 부분시장 자료로 위장하거나 합치지 않는다.
- FR002: 고정 HTTPS 호스트·경로·5종목, Bearer 환경 키, 리디렉션 거절, 제한 재시도를 사용한다.
 14일 단위와 limit50000으로 요청하며 예상 밖 다음 페이지는 거절한다. 키·오류 본문은 출력하지 않는다.
- FR003: 출력은 새 비공개 폴더다. 원 응답과 요청 범위·시각·해시를 보존하고, 완료한 청크를
 재실행 때 대조해 재사용한다. 손상된 자료를 덮지 않는다. 자료 부족·권한 부족은 성공으로 바꾸지 않는다.
- FR004: 가격/거래량/날짜/중복/전체 거래일 격자를 검증한다. 부족한 봉을 가공해 채우지 않는다.
- FR005: 기존177 고정18개 후보·756세션·비용·검증용 기간 분리 기준과 독립 증거 검사를 그대로 실행한다.
 실제 공급자와 연구 판정을 별도로 보고하며 live_eligible=false, orders_submitted=0을 유지한다.
- FR006: 연구 완료와 실거래 적격을 구분한다. Massive 연구 결과는 KIS 실행 제공자 검증을 대체하지 않는다.

완료 기준: 모의 응답의 수집→재실행→원본 대조→기존 연구기 통합 검사, 전체 회귀·린트·하네스·인계,
승인된 유효 키로 실제756거래일 자료 확보 및 실제 연구 판정. 실제 자료 단계 미완료는 따로 기록한다.
