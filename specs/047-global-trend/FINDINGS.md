# 스펙 047 — 글로벌 분산 추세추종 실측 (주식+채권+금)

데이터: Shiller 월간 S&P 총수익 + 10년 국채(1871~) + 런던 금 월간(1833~). 둘 다 GitHub
(`datasets/s-and-p-500`, `datasets/gold-prices`) — 이 컨테이너에서 닿는 유일한 장기 소스.
재현: `uv run python scripts/global_trend_probe.py [--window 10] [--corr] [--json]`.

## 핵심 결과 (10개월 SMA 추세 게이트, 매월 재조정)

각 자산을 자기 10개월 SMA 위일 때만 보유(아래면 현금). 2자산=주식추세+채권추세 50/50(스펙
043). 3자산=+금. **고정가중**=주1:채1:금0.33(금≈14%). **역변동성**=매월 트레일링 역변동성 가중.

| 구간 | 2자산 샤프/낙폭/칼마 | 3자산 고정가중 | 3자산 역변동성 |
|------|------:|------:|------:|
| 전체 1871~ | 1.58 / 18% / 0.45 | 1.71 / 16% / 0.52 ✓ | 1.60 / **5%** / **1.10** ✓ |
| 현대 1950~ | 1.81 / 6.6% / 1.43 | 1.98 / 6% / 1.71 ✓ | 1.73 / **5%** / 1.49 |
| **자유변동 1971~** | 1.78 / 6.6% / 1.49 | 1.99 / 6% / 1.84 ✓ | 1.81 / **5%** / **1.77** ✓ |
| 최근 1990~ | 1.78 / 6.9% / 1.30 | 1.96 / 6% / 1.61 ✓ | 1.72 / **5%** / 1.70 |

(균등가중 1/3 씩은 금에 위험을 과배분 → 1971~/현대서 낙폭 6.6%→9.5% 악화 = `NO_GOLD_BENEFIT`.
그래서 균등은 *안 쓴다*. 위험으로 사이징하는 두 방식만 의미 있다.)

## 금 상관 (분산 근거)

| 구간 | 금↔주식 | 금↔채권 |
|------|------:|------:|
| 전체 1871~ | +0.011 | +0.033 |
| 현대 1950~ | +0.000 | +0.032 |
| 자유변동 1971~ | −0.004 | +0.026 |
| 최근 1990~ | **−0.070** | **+0.165** |

금은 주식과 사실상 무상관~음(−0.07). 최근 금↔채권 +0.165 는 *둘 다 인플레/실질금리에 반응*
하는 regime 신호 — 바로 이 구간(채권 분산이 약해지는 인플레)에서 금이 주식 헤지로 빛난다.

## 결론 (정직)

1. **금은 진짜 분산을 더한다 — 단, 위험으로 사이징할 때만.** 금은 변동성 큰 자산(≈15%, 샤프
   0.92)이라 균등(1/3)으로 담으면 변동성을 들여와 일부 구간 낙폭을 악화시킨다. 위험으로
   사이징(역변동성)하면 금이 자동으로 작은 비중(≈10~15%)을 받아 *분산 이득만* 취한다.
2. **역변동성 3자산의 핵심 가치 = 자본 방어.** 모든 구간에서 **낙폭이 ~5% 로 떨어졌다**
   (2자산 6.6~18%). 칼마는 전체 0.45→1.10, 1971~ 1.49→1.77 로 크게 올랐다. 샤프는 2자산과
   비등(때때로 소폭↓ — 변동성 더 깎느라). = **같은 위험 예산에서 훨씬 안전하게 복리**.
3. **고정 위험가중(금 ≈14%)은 4/4 구간 엄격 엣지**(샤프·칼마·낙폭 모두 개선) — "돈"(복리
   천장=샤프) 관점의 가장 깨끗한 답.
4. **스펙 044 교훈의 직접 적용**: 변동성 차이 큰 자산은 *균등이 아니라 위험으로* 사이징.
   이것이 세계 최고 수준 managed futures 가 실제로 하는 방식(리스크 패리티 + 추세).

## 배선 (forward 페이퍼 ARM E)

`deploy/global-trend-portfolio.toml`: SPY+IEF+GLD, top_n=3, **weight_scheme=inverse_vol**(원칙적
사이징, "마법의 상수" 없음), 각자 sma 200 추세 게이트(역변동성 가중 *뒤에* 적용 = 자본 방어
오버레이), on_insufficient=cash. `rebalance-paper-forward.yml` ARM E(전용 DB `forward_global.db`
격리, set +e + if:always, GLD/IEF 백필 실패해도 graceful degrade). **측정한 것만 배선.**

   자본·라이브는 운영자 게이트(헌법 X.4).
