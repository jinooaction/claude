# 기능 명세: 모의 장부의 관측·게시 시각 연결

**Feature Branch**: `codex/210-intraday-timing`

**Created**: 2026-10-08

**Status**: 명세 확정·구현 완료·원격 검증 대기
**Input**: 기존 한국투자 단타 프로그램 완성 작업 중, 상태 신선도와 봉의 처리 시점을 구분하고 원래 기록의 시각을 가격·계좌·키 없이 연결한다.

## User Scenarios & Testing

### User Story 1 - 원래 관측 시각 구분 (Priority: P1)

운영자는 같은 봉의 모의 장부 기록과 진단 게시 기록을 연결해 각각 무엇을 뜻하는지 본다.
독립 검증: 합성 장부에서 서로 다른 관측·게시 시각을 정확히 보존하고 늦은 관측을 최신 게시로 숨기지 않는다.

1. **Given** 같은 봉과 운용 지문의 장부·진단, **When** 읽기 전용 조회, **Then** 봉 시작, 모형 종료, 장부에 저장된 관측, 진단 게시 시각과 두 차이를 구분한다.
2. **Given** 수신/처리 완료/자료원 게시 시각이 없음, **When** 조회, **Then** 미확인으로 남으며 관측 시각을 그 시각으로 바꾸지 않는다.

### User Story 2 - 불확실한 연결 차단 (Priority: P1)

운영자는 동시 쓰기, 다른 장부, 변조, 누락, 미래 시각을 성공한 시각 연결로 오인하지 않는다.
독립 검증: 공유 읽기 잠금, 원래 장부 식별, 마지막 기록의 국소 지문·이전 연결 및 진단의 봉/개수 일치 반례.

1. **Given** 장부와 진단 불일치, **When** 조회, **Then** 시각 확인 불가 이유만 남고 추정 시각은 없다.
2. **Given** 원래 진단만 있음, **When** 조회, **Then** 기존 진단은 유지되며 추가 시각은 미확인이다.

### Edge Cases

잠금 사용 중, 심볼릭 링크, 비정상 파일/크기, 잘못된 장부 버전/운용 모드, 중복 키/비유한 수, 미래/역순 시각, 다른 마지막 봉, 모형 종료 전 관측, 장부 개수 불일치, 시각 없는 대기 상태, 기존 추가 전용 영수증 보존.

## Requirements

- **FR-001** 기존 고정 읽기 명령의 진단 JSON에 가격 없는 선택적 시각 보고서만 추가한다. 기존 필드·명령 인자 거절·예약·오류 검사는 유지한다.
- **FR-002** 원래 진단의 운용 지문으로 고정된 모의 장부만 읽는다. 기존 쓰기 잠금을 생성하지 않고 공유 읽기로 잡으며, 진단과 마지막 장부의 봉·개수가 같아야 연결한다.
- **FR-003** 장부의 원래 관측 시각을 그대로 보존한다. 봉 종료는 기존 5분 시작 모형이며 실제 제공자 의미를 인증하지 않는다.
- **FR-004** 마지막 기록의 국소 지문·이전 기록 연결을 확인하되 전체 감사 사슬/증권사 서명 검증이라고 주장하지 않는다.
- **FR-005** 수집 시작·수신 완료·처리 완료·제공자 게시 시각은 이번 보고서에서 미평가다. 90초 여부는 저장된 관측 시각의 산술 비교일 뿐 정식 전진 판정이 아니다.
- **FR-006** 입력·조회 시간·출력 크기를 제한하고 불확실하면 시각을 내보내지 않는다. 원래 파일/DB/계좌/키/감사 로그에 쓰지 않는다.
- **FR-007** 기존209 원본 영수증은 선택적 보고서를 검증·보관한다. 예전 영수증에 새 필드가 없는 것은 누락으로 보존한다.
- **FR-008** 기존1645세션·최소36시도·미개봉495세션·60세션·비용·체결·현금·한도·승격 경계는 불변이다. 실제 주문/자본/권한 변화는 없다.

## Key Entities

- 진단: 운용 지문, 마지막 봉, 기록 수, 게시 시각, 기존 모의 범위.
- 마지막 장부 기록: 저장된 봉·관측 시각, 국소 지문과 이전 연결. 내부 가격/계좌 정보는 출력하지 않는다.
- 시각 보고서: 확인 또는 미확인 이유, 원래 시각과 산술 차이, 평가 범위.

## Success Criteria

- **SC-001** 합성 정상·반례에서 시각·범위를 혼동하거나 누락을 추정한 성공 0건.
- **SC-002** 동일 자료로 반복 조회 결과 동일하며 원래 파일 변경 0건.
- **SC-003** 추가 보고서 4KiB 이하, 장부 조회 최대 2초, 가격·계좌·비밀값 출력 0건.
- **SC-004** 전체 원격 회귀·린트·필수 기존 반례 무생략 확인 뒤 병합한다. 실제 서버 관측은 정상 장외 예약 반영 이후 별도 근거로 확인하며 그 전에는 미관측이라고 기록한다.

## Assumptions / non-goals

신뢰하는 서버 파일·시계의 자기 기록이다. 처리에 전달된 관측 시각은 처리 완료 시각이 아니다.
자료원 시각/조정/정정/출처·체결 동등성, 새 전략·가격 성과, 실제 주문/승격은 이번 기능에서 확정하지 않는다.
