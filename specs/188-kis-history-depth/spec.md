# 기존 KIS 인증으로 과거 분봉 조회 범위 확인

요청: 무료 과거 자료 확보를 이어간다. 위험 등급3: 인증된 읽기 진단 추가.
기존187 유료 공급자 초안과 분리해 이 진단만 출시한다. 실제 장기 연구 완료는 별도다.

- 고정 SPY/AMS/5분/120행 요청과 공식 NEXT/KEYB 연속 조회만 사용한다.
- 최대80페이지, 기존2회/초·재시도·차단기·토큰 캐시를 재사용한다.
- 과거30일 로컬 필터를 진단에 적용하지 않으며 운영 수집기의 제한은 유지한다.
- 빈 페이지, 과거 시각 진행 중단, 설정 한도 도달을 구분한다. 한도 도달은 실제 보관 끝이 아니다.
- 원본과 요청·시각·해시를 서버 비공개 새 폴더에 추가 저장한다. 인증값은 저장/출력하지 않는다.
- 잘못된 시각·가격·거래량·중복 충돌은 실패한다. 기간 공백은 채우지 않는다.
- 원본 조회 수와 정규장5분봉 수·최초/최종 시각을 구분해 보고한다.
- 결과는 연구 적격/실거래 적격으로 승격하지 않는다. 실제 주문·자본 변경 없음.
