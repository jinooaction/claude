# 186 계좌 원본 수집 분리

## 문제와 목표
미완료 단타 PR793에 원본 기록기가 있어 main 전용 서버 실행 경로에서 사용할 수 없다. 이미 검증한 기록기를 독립 출시해 실제 원본 확보를 가능하게 한다. 전체 단타 프로그램 완성은 별도 목표로 유지한다.

## 요구
- FR001 기존 잔고 진단 명령에 선택적 비공개 원본 장부와 기존 실행 장부 읽기를 연결한다.
- FR002 인증 비밀·계좌번호·자유 메시지는 공개하지 않는다. 원본 파일0600, 계좌 묶음·해시 연결·추가 기록을 검증한다.
- FR003 실패한 부분 수집도 기록하며 기존 실행 DB를 수정하지 않는다. 과거 거래 기간을 요구하지 않는다.
- FR004 main 전용 고정 서버 경로로 수집할 수 있어야 한다. 운영 워커 checkout·재시작·실주문 없이 별도 원본 장부에 남긴다.
- FR005 모의 HTTP, 실제 SQLite 재열기, 파일 권한·변조·계좌 혼입·실패와 서버 호출 경로를 검증한다.
- FR006 저장에 성공한 동일 원본 묶음에서 USD/다른 통화/통화 미분류 행의 숫자 유효성,
  0값·음수·중복 분포를 공개 가능한 건수로 분석한다. 필드는 공식 해외증거금 예제의
  고정 목록만 사용하고 금액·국가명·임의 필드·계좌번호를 출력하지 않는다. 같은 금액이나
  0값 분포는 합산/제외 규칙 또는 계좌 인증을 증명하지 않는다.

## 위험과 비목표
등급3: 비밀값·추가 기록과 서버 경로. 현금·전체 계좌 검증 판정, 주문·자본·운용 승인·헌법은 변경하지 않는다. 원본 보관 성공은 정규화 또는 계좌 인증의 완료가 아니다.

## 완료 기준
FR001~005, 전체 테스트·린트·하네스·인계·PR 검사, 독립 main 반영과 서버 읽기 결과 확인. 되돌림은 호출 중단과 코드 되돌림 커밋이며 이미 남긴 원본은 삭제하지 않는다.
