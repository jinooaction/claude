# 186 계좌 원본 수집 분리

## 문제와 목표
미완료 단타 PR793에 원본 기록기가 있어 main 전용 서버 실행 경로에서 사용할 수 없다. 이미 검증한 기록기를 독립 출시해 실제 원본 확보를 가능하게 한다. 전체 단타 프로그램 완성은 별도 목표로 유지한다.

## 요구
- FR014 거래내역 공통 읽기와 공백 거래소 필터를 독립 출시한다. 장부 사용 명령은
  UTC 오늘과 앞선2일의 등록일 범위를 한 번 고정해 전 페이지를 수집하며 원본 장부가
  필요하다. 거래내역은 계좌 관측 구간 전에 읽어 기존 전후 대조의30초를 소모하지
  않는다. 기존 서버의 --history-db 명령이 승인된 체크아웃의 새 읽기를 실행한다.
  원본·중복·통화·수수료를 보존하고 공개는 건수/산술 판정뿐이다. 빈 결과·부분 실패를
  전체 현금/기간 완전성/수수료0 인증으로 바꾸지 않는다. 장부 명령은 보통11GET,
  장부 없는 기존 조회와 내부 run의 기본 동작은 보존한다.
- FR013 같은 원본의 자산표19분류·5열 합계·채무와 현재 현금/보유 대조를 적용한다.
 184 FR065와 동일 계산기를 사용하고 상품코드는 인증된 수집 계좌에서만 가져온다.
 공개 결과는 판정·닫힌 이유·건수이며 추가 GET/주문/전체 계좌 인증 승격은 없다.
- FR012 같은 전후 원본 묶음에184의 조건부 USD 예수금/미결제, 원화·달러 평가와
  국가 전체 보유 대조 계산기를 적용한다. 추가 GET 없이 직접 수집한 국내/미국
  파서 결과와 원본 응답/실제 시각을 사용한다. 공개 출력은 판정·닫힌 이유·건수만
  포함하고 금액·종목·원문은 내보내지 않는다. 실제 조건별 성공/실패를 확인하되
  전체 계좌/현금/실주문 인증값을 승격하지 않는다.
- FR011 실제 원본 수집에서 국내·미국 잔고와 자산표를 현재 보고의 전후 조회 안으로
  옮긴다. 기존 결제 보고와 조회 횟수/개인 장부는 보존한다. 중간 수집 실패·취소·
  전체 구간30초 초과를 성공으로 기록하지 않는다. 조회 시각과 자산 발생 시각은 구분한다.
- FR010 같은 비공개 원본 묶음의 국내 예수금/정산액/순자산과 해외 현재·결제 보고의
  예수금/총예수금/외화 총액, 결제 자산표의 예수금 분류를 금액 없이 대조한다. 국내
  반복 요약은 합산하지 않고 모든 필드가 동일해야 한다. 누락/오류/변화는 비교 불가로
  보존한다. 단순 일치는 통화 포함 관계·동시 시점·순현금 집계 인증으로 승격하지 않는다.
- FR009 결제 기준 전체 자산표와 구분되는 국내 현재잔고를 같은 계좌 GET으로 전 페이지
  수집한다. 전일 매매·펀드 결제분을 포함하고 수량0 행/보유/평가/대출과 현금 요약을
  보존한다. 페이지 간 요약 변경·잘못된 숫자·연속 조회 실패는 부분 성공으로 처리하지
  않는다. 비공개 원본 장부에 남기고 공개 출력은 건수/숫자 상태만 허용한다.
- FR001 기존 잔고 진단 명령에 선택적 비공개 원본 장부와 기존 실행 장부 읽기를 연결한다.
- FR002 인증 비밀·계좌번호·자유 메시지는 공개하지 않는다. 원본 파일0600, 계좌 묶음·해시 연결·추가 기록을 검증한다.
- FR003 실패한 부분 수집도 기록하며 기존 실행 DB를 수정하지 않는다. 과거 거래 기간을 요구하지 않는다.
- FR004 main 전용 고정 서버 경로로 수집할 수 있어야 한다. 운영 워커 checkout·재시작·실주문 없이 별도 원본 장부에 남긴다.
- FR005 모의 HTTP, 실제 SQLite 재열기, 파일 권한·변조·계좌 혼입·실패와 서버 호출 경로를 검증한다.
- FR006 저장에 성공한 동일 원본 묶음에서 USD/다른 통화/통화 미분류 행의 숫자 유효성,
  0값·음수·중복 분포를 공개 가능한 건수로 분석한다. 필드는 공식 해외증거금 예제의
  고정 목록만 사용하고 금액·국가명·임의 필드·계좌번호를 출력하지 않는다. 같은 금액이나
  0값 분포는 합산/제외 규칙 또는 계좌 인증을 증명하지 않는다.

## 위험과 비목표
- FR008 같은 원본의 전체 자산 분류별 숫자 상태, 일반 잔고의 OTCB 수량/평가 상태,
  현재·결제 요약의 현금/채무 상태를 금액 없이 구분한다. 수량0인 표시 행과 양수 보유를
  구분할 근거를 제공하며, 지원되지 않는 자산을 실제0원 또는 검증된 자산으로 바꾸지 않는다.
  보고서별 고정 필드의 누락/0/양수/음수만 반환하고 원문·종목·금액은 공개하지 않는다.
- FR007 같은 수집 묶음의 공통 USD 구성과 현재/결제 잔고의 단일 USD 행을 대조한다.
  다른 통화 금액이 모두0인 경우에만 단일 USD 금액×보고 환율을 외화 총액과 비교한다.
  공식 HTS 총자산식 후보도 같은 요약 행 내부에서 계산한다. 정확한 산술 일치/차이/자료
  부족만 공개하며, 값 일치를 필드 의미·전체 계좌 범위·평가 시각 인증으로 바꾸지 않는다.

등급3: 비밀값·추가 기록과 서버 경로. 현금·전체 계좌 검증 판정, 주문·자본·운용 승인·헌법은 변경하지 않는다. 원본 보관 성공은 정규화 또는 계좌 인증의 완료가 아니다.

## 완료 기준
FR001~005, 전체 테스트·린트·하네스·인계·PR 검사, 독립 main 반영과 서버 읽기 결과 확인. 되돌림은 호출 중단과 코드 되돌림 커밋이며 이미 남긴 원본은 삭제하지 않는다.
