# Data model

- `Event`: accession, CIK, symbol, 접수 주장 시각, 시장 세션, 정정/추정/계보 표식.
  원본은 201 감사 결과이며 감사 지문이 맞지 않으면 거절한다.
- `Observation`: symbol, XNYS 진입 세션, 직전 거래일 마지막 종가,
  09:45 종가, 09:47 시가/거래량, 15:56 시가/거래량.
- `Diagnostic`: 원본·계약 지문, 사건 선별/중복/누락 사유,
  비용별 가격 참조 수익률, 승격 불가 표식. 상태 전이는 없다.

입력 원본과 출력은 분리한다. 출력 경로가 이미 있으면 거절한다.
