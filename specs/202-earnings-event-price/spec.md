# Feature Specification: 실적 공시 뒤 가격 반응의 개발 구간 진단

**Feature Branch**: `codex/202-earnings-event-price`  
**Created**: 2026-10-02  
**Status**: Development rejected — research only
**Input**: 기존 한국투자 단타 프로그램의 실제 자료 전략 검증을 계속한다.

## User Scenarios & Testing

### User Story 1 — 가격을 보기 전에 한 가설을 고정한다 (P1)

운영자는 실적 관련 공시 뒤 상승한 종목의 장중 움직임이 큰 거래 비용을 감당할
가능성이 있는지, 미래 기간을 보지 않고 확인한다.

1. 정확히 고정한 공시·가격 원본과 단일 규칙만 사용한다.
2. 2014-03-03~2017-12-29 진입 세션만 개발 결과로 연다. 2018년 이후는 봉인한다.
3. 종목 변경 계보가 미확인된 `DD`, `UTX`와 정정 공시, 추정 시각을 제외한다.

### User Story 2 — 시각과 관측 누락을 숨기지 않는다 (P1)

공시 접수 주장 시각이 09:30 미국 동부 시간보다 빠르면 그 거래일, 그 외에는
다음 거래일을 관측한다. 직전 거래일 종가와 09:45 분봉 종가로 상승 여부를
판정한다. 상승이면 09:47 분봉 시가와 15:56 분봉 시가를 가격 참조로 대조한다.
어느 하나가 없거나 거래량이 0이면 누락으로 기록한다. 같은 종목·세션에
여러 공시가 있어도 관측은 한 번만 계산한다.

### User Story 3 — 제한된 결론을 재현한다 (P2)

운영자는 기준 편도 31bp와 가혹 편도 40bp의 비용 후 방향성, 누락 수, 원본
지문을 재현한다. 이는 한 주의 참조 가격 진단이며 현금·부분 체결·계좌 성과나
전략 합격 판정이 아니다. 결과에는 주문 0, 실제 자본 0, 실거래 불가를 표시한다.

### Edge Cases

- 비거래일·조기 폐장·일광절약시간·첫 가격 거래일·공시 후 마지막 가격 거래일.
- 같은 종목의 한 세션 중복, 전일 종가 누락, 09:45/09:47/15:56 누락·거래량 0.
- 원본 지문 변조, 기존 출력 덮어쓰기, 공시 목록의 미인증 과거 공개 시각.

## Requirements

### Functional Requirements

- **FR-001**: 정확한 공시 감사 출력과 30개 가격 파일 목록의 지문을 성과 조회 전에 고정한다.
- **FR-002**: 실제 공시의 접수 주장 시각으로만 다음 관측 세션을 정한다. 공시 본문이 당시 공개됐다고 주장하지 않는다.
- **FR-003**: 개발 세션 이후 가격 행은 읽더라도 성과 계산에 사용하지 않는다.
- **FR-004**: 완성 분봉 신호 이후 한 분 더 기다린 09:47 시가를 진입 참조로 사용한다. 미래 가격으로 신호를 바꾸지 않는다.
- **FR-005**: 누락과 중복은 공개하고, 가격이나 거래량을 보간하지 않는다.
- **FR-006**: 기준/가혹 비용 후 수익률을 관측쌍별로 계산하고 원본/규칙/결과 지문을 남긴다.
- **FR-007**: 실제 체결, 계좌 현금, 용량, 기업 계보, 역사적 공시 관측이 확인되지 않았으므로 합격·전진 관찰·실거래 승격을 금지한다.

### Key Entities

- 봉인 계약: 원본 지문·기간·한 가지 신호·참조 시각·비용.
- 관측쌍: 공시·종목·진입 세션·전일 종가·신호/진입/청산 관측.
- 진단 결과: 누락 이유·비용별 수익·원본 지문·승격 불가 표식.

## Success Criteria

- **SC-001**: 원본이 같으면 결과와 누락 사유가 바이트 단위로 재현된다.
- **SC-002**: 일광절약시간·휴장·중복·미래 가격·변조 반례를 통과한다.
- **SC-003**: 실제 개발 자료 전체에서 가격 반응과 비용 부담을 수치로 확인한다.
- **SC-004**: 모든 결과가 주문 0·자본 0·승격 불가를 명시한다.

## Assumptions

새 연구 도구와 활성 명세 포인터를 추가하는 등급 2 변경이다. 기존 연구/주문
경로는 제거하지 않는다. 실패 시 새 연구 경로와 포인터만 되돌리며 원본은 보존한다.
이 진단이 양수여도 `specs/181-intraday-runtime/tasks.md` T013~T016은 미완료다.
