# Feature Specification: 고정 공시 시각 자료의 연구용 검증

**Branch**: `codex/201-earnings-clock-input`
**Created**: 2026-10-02
**Status**: Released (research input only; whole intraday goal incomplete)

## Goal and scope

기존 한국투자 계좌용 단타 프로그램의 전략 검증에 앞서, 공개 8-K 사건 메타데이터의
기업 식별자와 접수 시각 주장을 실제 확보한 공시 원문과 재현 가능하게 대조한다.
직접 SEC 접근이 403으로 거절되는 환경에서도 고정된 공개 사본을 검증할 수 있어야 한다.
이 도구는 가격 성과나 과거 공개 가능성을 증명하지 않는다.

## User stories and acceptance

### US1 — 고정 출처와 기업 연결 검증 (P1)

- 고정 출처 개정·두 원본 파일 지문·30개 역사 기업의 CIK와 목록의 공개 근거 날짜를 선언한다.
- 원본 지문이 바뀌면 거절한다. 137개 로컬 본문의 accession/CIK가 접수 기록에 없거나
  다르면 성공 보고서를 만들지 않는다.
- 공시 날짜와 미국 동부 접수 날짜가 다르면 그 식별자를 따로 보여준다.

### US2 — 사건 시각의 의미를 보존 (P1)

- `Item 2.02` 행을 accession+CIK로 접수 기록과 연결하고, 중복·누락을 거절한다.
- 공급자가 주장한 접수·지식 시각, XNYS 거래소 달력에 따른 장전/장중/장후/휴장일, 추정 시각,
  정정본, 기업 계보 미확인, 본문 유무를 각각 따로 남긴다.
- 2014-02-24에 공개된 고정 기업 목록을 그 이전 사건의 당시 선택 가능 목록으로
  간주하지 않는다. 이전 사건은 원자료에 남기되 적격 후보 수에서 제외한다.
- 모든 결과는 `historical_asof_proven=false`, `strategy_admitted=false`,
  `live_eligible=false`다. 접수 시각을 실제 공개·관측 시각으로 승격하지 않는다.

### US3 — 재현 가능한 오프라인 진단 (P2)

- 원본 두 파일과 로컬 공시 폴더를 인수로 받아 새 출력 파일만 생성한다.
- 출력은 원본 개정과 지문, 사건 목록, 집계, 날짜 불일치 식별자를 포함한다.
- 수정된 원본, 잘못된 기업 연결, 기존 출력 파일은 거절한다.

## Constraints and success criteria

- 2013-08-23~2020-03-06 미국 동부 날짜의 2013-10-31 DIA 보유 30개 회사를
  원자료 범위로 검사한다. 고정 연구 목록은 공개 다음 날인 2014-02-25부터만 사용한다.
  `DD`와 `UTX`의 종목 계보는 가격 연결 전 제외한다.
- SEC 개인 이메일은 코드·명세·보고서에 저장하지 않는다. 조회 요청 헤더에만 사용했다.
- 외부 API·브로커·주문·계좌 환경값 접근은 없다. 연구 입력은 기존 실거래 관문을
  대체하지 않는다. 실제 자본 0, 주문 0.
- 실제 두 고정 Parquet과 137 본문으로 성공, 변조·잘못된 연결 반례로 거절을 확인한다.
- 위험 등급 2: 연구 도구·개발 의존성·CI 검사 경로·활성 명세 포인터를 추가한다.
  기존 기능 제거 없음. 되돌림은 새 도구/포인터/CI 경로 사용 중단이며 기존 원본은 보존한다.

## Explicit non-goals and next evidence

과거 시점에 시장 참여자가 본문을 읽을 수 있었는지, 독립 가격 원본과 체결 가능성,
수익성·전진 관찰·실거래 안전성은 별도 검증 대상이다. 전체 목표인
`specs/181-intraday-runtime/tasks.md`의 T013~T016을 완료로 표시하지 않는다.
