# Feature Specification: 보관 분봉의 운영 관측 연결 검증

**Branch**: `codex/208-public-minute-bridge` | **Created**: 2026-10-06
**Status**: 실제전체원본재인증/관측계산/원격보관·최초5358검사 완료, 최종기록회귀/병합 확인 중
**Input**: 확보한 공개1분 자료를 현재 운영5ETF/5분의 관측 방식과 연결해 검증한다.

## User Scenarios & Testing

### User Story 1 — 다시 수집하지 않고 보관 원본을 검증한다 (P1)

운영자는 기존207 암호문을 재인증하고 정확히 같은 원본으로 다음 검증을 수행한다.
독립 검사: 보관 자산 하나라도 크기·지문·인증이 다르면 분석을 시작하지 않는다.

1. 고정 여섯 자산과 실제 원격 지문이 맞으면 전체 원본 인증 뒤 분석한다.
2. 다른 자산·중복 이름·부분 파일·잘못된 키·인증 문맥은 실패 기록을 남긴다.
3. 원본 공급자 재요청, 기존 보관물 덮어쓰기, 맥북의 큰 원본 처리가 없다.

### User Story 2 — 누락을 보존하며 5분 관측을 검증한다 (P1)

운영자는 SPY/QQQ/IWM/TLT/GLD의 실제 공통 날짜와 완전한5분 구간을 확인한다.
독립 검사: 한 분 누락·중복·장외·휴장·조기 폐장·0거래량이 완전 관측으로 통과하지 않는다.

1. 각5분 구간은 서로 다른 정확한5개 정규장 분봉이 있어야 한다.
2. 5분 가격/거래량은 시간 순서의 시가·최고·최저·종가·거래량 합계로 내부에서만 만든다.
3. 봉 시작+5분+60초 이전에는 그 봉 전체를 관측하거나 사용할 수 없다.
4. 하루 한 구간이라도 빠지면 그 종목의 완전세션이 아니며 공통세션은 실제 날짜 교집합이다.
5. 하루 전체가 없어도 그 날짜를 누락으로 보고한다. 종목 부재를 다른 종목으로 대체하지 않는다.

### User Story 3 — 모형 검사와 실거래 자격을 구분한다 (P2)

운영자는 시간·정규화 검사가 통과해도 제공자/체결 동등성이나 수익 전략이 검증되지 않았음을 안다.
독립 검사: 모든 정상·실패 결과의 제공자/전략/승격 자격은 거짓이며 주문·성과 조회는0이다.

## Requirements

- FR-001: 입력은207 고정release402595786의 정확6자산과2014-01/2019-12 전체 원본만 허용한다.
- FR-002: 인증·시간·구조 검증 실패는 안전한 사유 코드로 기록하며 비밀/가격/서명주소를 공개하지 않는다.
- FR-003: 실제 거래소 달력·뉴욕 월·정규장·5분 구간으로 날짜별 누락과 공통 완전세션을 산출한다.
- FR-004: 누락 분을 가격 복사·0거래량·다른 종목·다른 날짜로 채우지 않는다. 중복 분은 거절한다.
- FR-005: 현재 운영 정규화 함수로 각 완전봉의 가격/거래량·시각을 검사한다. 0합계 거래량은 거절한다.
- FR-006: 공개 원본의 시각을 봉 시작으로 해석하는 가정과60초 게시 지연은 검증 모형이며 실제 당시 측정이 아니다.
- FR-007: 전체 계산은GitHub에서만 실행한다. 내부 검토 코드·소유자 확인 후 키를 제공한다.
- FR-008: 같은 검토 코드의 실제 분석은 영구 첫 시도 선점 뒤 한 번이며 실패/성공을 이유로 자동 재개하지 않는다.
- FR-009: 결과는 가격 없는 개수/날짜/누락/모형 시각만 공개하며 기존 모든 자산은 보존한다.
- FR-010: 전체181 T013~T016, 출처/조정/정정/당시 구성/라이선스/체결 동등성은 이번 검사로 완료되지 않는다.

## Key Entities

- 고정 입력: release ID·자산 이름·크기·전체 지문·원본 인증 문맥.
- 관측 구간: 종목·거래일·정규장 시작/끝·완전5분 구간·누락/0거래량 구간.
- 결과 영수증: 검토 코드·입력 인증·분석 완료·실제 날짜 교집합·모형과 미확인 사실·자격 거짓.

## Success Criteria

- SC-001: 고정 원본 두 파일 모두 전체 인증하고 실제 자료 결과와 원격 보관 결과를 대조한다.
- SC-002: 모든 거래일×5종목 상태를 빠짐없이 보고하고, 독립 합계로 원래207 종목별 분누락과 맞춘다.
- SC-003: 합성 반례에서 누락·중복·0거래량·미래 관측·조기 폐장·인증 오류가 잘못 통과하지 않는다.
- SC-004: 전체 검사와 린트가 통과하고 새 필수 반례가 건너뛰어지지 않는다.
- SC-005: 실제 결과·검증·인계를 보존하고 병합한다. 원본 인증과 실거래 자격을 혼동하지 않는다.

## Assumptions / boundaries

추가 가입/비용은 없다. 기존 의존성과 연구용 암호화 키를 재사용한다. 위험 등급3(키/분석 실행 경로),
돈 경로 변경 없음. 미개봉495세션·최소36선행시도·31/40bp·200거래·현금/정산/부분체결·한도/감사는 유지한다.
새 전략 가설/수익률 계산/실주문/자본 배정/승격/헌법·커널 변경은 비목표다.
시각 모형을 확인할 수 있어도 원본의 봉 시작 의미·실제 게시 지연·KIS 체결 동등성은 미확인으로 남긴다.
