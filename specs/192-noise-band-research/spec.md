# Feature Specification: 과거 같은 시각 변동 폭을 이용한 단타 연구

**Feature Branch**: `codex/192-noise-band-research`
**Created**: 2026-09-21
**Status**: Draft
**Input**: 기존 KIS 계좌로 사용할 검증된 단타 프로그램을 완성한다. 기존28후보 실패 이후 새 신호 가설을 비용·자료·판정 변경 없이 검증한다.

## User Scenarios & Testing

### User Story 1 — 과거 정보만 사용한 신호 (Priority: P1)
운영자는 오늘 가격에 맞춰 기준을 바꾸지 않고 과거 같은 시각의 변동으로 판단한다.
독립 시험: 이후 날짜/이후 봉을 변경해도 이전 신호가 같아야 한다.
과거14개 완결 세션이 없거나 같은 시각 봉이 빠지면 신규 매수하지 않는다.

### User Story 2 — 비용을 포함한 단일 후보 판정 (Priority: P1)
운영자는 한 후보를 고정한 뒤 기준/가혹 비용의 성과와 잔량을 확인한다.
독립 시험: 손실·거래 부족·미청산은 탈락이며 개발 통과도 실거래 승인이 아니다.

### User Story 3 — 원본 재현 (Priority: P2)
운영자는 입력·계약·코드·장부 지문과 원본 재계산으로 결과를 재현한다.
독립 시험: 입력 변경, 장부 변조, 기존 결과 덮어쓰기를 거부한다.

### Edge Cases
14일 준비 기간, 조기 폐장으로 해당 시각이 없는 날, 빈 거래량, 야간 갭,
신호 경계의 같은 가격, 미래 봉 변경, 미체결/부분청산 후 신호 반전,
마지막 봉 청산 잔량, 잘못된 계약/자료, 신규 확인 자료 접근을 시험한다.

## Requirements
### Functional Requirements
- FR001: 후보는30분·14일·매수 전용1개로 고정한다. 같은 날짜 자료를 과거 평균에 넣지 않는다.
- FR002: 과거14개 세션의 같은 시작 후 경과시각 봉 종가/당일 시가 변동 절댓값 평균을 사용한다. 시각 누락이면 더 오래된 날로 채우지 않는다.
- FR003: 상단=max(오늘 시가, 직전 세션 종가)×(1+평균). 완결봉 종가가 max(상단, 누적 대표가격 거래량가중평균)보다 클 때 매수, 이하일 때 청산한다.
- FR004: 종목/날짜별 매수 시도1회, 다음 봉 시가 체결, 청산 시작 후 잔량 재시도, 마지막30분봉 시가 청산을 고정한다.
- FR005: 기존177의5종목·자본·노출·두 비용·참여율을 유지한다. 공매도/레버리지/실계좌 접근을 추가하지 않는다.
- FR006: 이미 관찰한1645일만 개발에 사용한다. 첫14일은 준비 기간이며 성과 지표는 이후1631일로 계산한다. 미개봉495일은 읽지 않는다. 실제 직전 XNYS14거래일 중 자료/슬롯 누락은 무신호다.
- FR007: 기준200청산 이상, 양비용 순수익 양수, 양비용 미청산0일 때만 확인검증 필요 판정이다. 누적 시도 수는 최소29개다.
- FR008: 기존177/190/191 결과와 신호를 보존하고 새 가설은 별도 지문으로 식별한다. 계약은 실제 성과를 열기 전에 커밋한다.
- FR009: 보고서는 논문 재현이 아니라 매수 전용 변형임을 표시한다. 전 봉 거래량으로 시가 유동성을 가정하는 체결 모형, 조정가격, 조기청산 한계를 숨기지 않는다.
- FR010: 코드·원본·계약 지문, 전체 장부, 원본 재계산 일치와 실패 결과를 보존한다.

### Key Entities
고정 계약, 날짜/종목/봉의 상단·평균가격·진입/청산 신호, 개발 결과와 장부.

## Success Criteria
- SC001: 미래 가격 변경이 기존 신호에 영향을 주지 않고 준비/누락 경계를 모두 거부한다.
- SC002: 실제 고정 자료에서 단일 후보의 두 비용 결과와 원본 재계산이 정확히 일치한다.
- SC003: 기존 후보 회귀와 전체 검사·린트·인계 검증이 통과한다.
- SC004: 실제 주문0/자금0을 유지한다. 전체 실사용 완료는 통과 전략·독립 확인·전진관찰·실행/운영 증거가 있어야 한다.

## Assumptions
새 가설의 성공은 미확인이다. 원문 표본이 확인 기간과 겹치므로 미개봉 자료도 완전히 새로운 독립 연구 증거라고 부르지 않는다. 전략 합격·실행 동등성은 연구 도구 완성과 구별한다.
