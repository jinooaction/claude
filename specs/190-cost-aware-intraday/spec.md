# Feature Specification: 거래비용을 고려한 단타 후보 연구

**Feature Branch**: `codex/190-cost-aware-intraday`  
**Created**: 2026-09-21  
**Status**: Draft  
**Input**: 기존 한국투자 계좌용 단타 실사용 프로그램을 완성하고, 기존 후보 실패 시 대안을 검증한다.

## User Scenarios & Testing

### User Story 1 - 기존 실패를 보존한 대안 검증 (Priority: P1)

운영자는 거래비용보다 작은 움직임을 반복 매매한 기존 후보의 실패를 보존한 채,
더 큰 가격 움직임에서만 진입하는 한정된 후보군의 결과를 확인한다.

**Independent Test**: 이미 확인한 기간만 제공했을 때 정확히 6후보의 기준/가혹 비용
결과와 선택 또는 탈락 이유를 재현하고 실제 주문은 0건이다.

**Acceptance Scenarios**:
1. **Given** 같은 원본과 사전등록, **When** 재실행, **Then** 같은 후보·선택·장부 지문이다.
2. **Given** 개발 단계 최소 조건 미달, **When** 검증, **Then** 후보를 탈락시키고 독립 확인 자료를 읽지 않는다.

### User Story 2 - 독립 확인 기간 보존 (Priority: P1)

운영자는 개발 결과로 선택한 후보가 이후 자료에서도 비용 후 성과와 기존 통계 관문을
통과하는지 확인한다. 확인 결과로 후보를 다시 선택할 수 없어야 한다.

**Independent Test**: 선택 지문 변조·기간 중복·잘못된 원본·불완전 봉을 각각 거부한다.

**Acceptance Scenarios**:
1. **Given** 고정된 개발 선택, **When** 독립 검증, **Then** 495거래일 전체를 사전등록한 두 구간으로 평가한다.
2. **Given** 실패 결과, **When** 보고, **Then** 실패를 유지하고 자동 재선택·실거래 승격을 하지 않는다.

### Edge Cases

- 조기 폐장·마지막 봉 신호·저거래량 부분 체결·미청산은 기존 연구기의 처리와 일치해야 한다.
- 무거래·자산 고갈·비유한 지표·누락 비용·잘못된 지문은 통과할 수 없다.
- 이미 공개한 기존 1,645세션을 새로운 독립 확인 자료로 부르지 않는다.
- 중단 후 재실행은 같은 사전등록·선택·입력 지문에만 연결한다. 기존 산출물 덮어쓰기는 거부한다.

## Requirements

### Functional Requirements

- **FR-001**: 기존 SPY/QQQ/IWM/TLT/GLD의 실제 원본만 사용하고 원천·조정 방식·해시를 보존한다.
- **FR-002**: 30분 또는 60분 장 초반 가격대의 최고가를 왕복 기준비용의 1·2·3배만큼
  넘어선 완결 봉에서 신호를 만든다. 정확히 6후보이며 당일 종목당 최대 1회 진입한다.
- **FR-003**: 신호 다음 봉에서 모의 체결하고 당일 청산한다. 기존 수량·노출·거래량 제한,
  기준/가혹 비용과 미청산 거부를 유지한다. 합성 가격·미래 봉 사용은 금지한다.
- **FR-004**: 개발은 이미 성과를 확인한 2013-08-23~2020-03-06의 1,645세션만 사용한다.
  개발 기준/가혹 비용 후 손익 양수와 최소 200회 청산을 모두 충족한 후보만 선택할 수 있다.
  순위는 기존 개발 샤프·낙폭·회전율·후보 식별자 순서를 따른다.
- **FR-005**: 개발 선택과 원본·코드·사전등록 지문을 고정하기 전 확인 자료의 성과를 계산하지 않는다.
  2020-03-19~2022-03-04의 495세션을 앞 247일 차단 구간, 뒤 248일 최종 확인으로 나눈다.
  두 기간 사이로 후보 선택 결과를 전달하며 재선택하지 않는다.
- **FR-006**: 기존 177의 비용 후 수익률·샤프·PSR·DSR·PBO·낙폭·수익 집중·분기 안정성·
  가혹 비용 기준을 낮추지 않는다. 과거 18후보와 새 6후보를 모두 다중 비교 기록에 남긴다.
- **FR-007**: 독립 검사에서 원본·장부·선택·결과의 일치를 검사한다. 연구 통과도 실주문,
  자본 배정, 기존 전략 변경 또는 60세션 전진 관찰의 대체 근거가 아니다.
- **FR-008**: 사용자는 개발 탈락, 확인 탈락, 연구 통과, 자료/검사 오류를 구분하고 다음
  조치를 알 수 있어야 한다. 충분한 자료가 있는데 단순히 자료 추가만 요구하지 않는다.

### Key Entities

- 사전등록: 변경할 수 없는 6후보·비용·선택·기간·판정 규칙.
- 개발 선택: 입력·코드·사전등록 지문, 모든 후보 결과, 선택한 0개 또는 1개 후보.
- 확인 기록: 개발 선택 지문에 묶인 두 구간 결과, 24후보 통계 비교 기록, 장부 지문.

## Success Criteria

- **SC-001**: 같은 원본에서 6후보의 비용 후 결과와 선택을 재현한다.
- **SC-002**: 개발 실패 시 확인 자료 접근 0회, 실제 주문·자금 이동 0건이다.
- **SC-003**: 변조·시간 중복·불완전 입력·미청산을 모두 거부하는 검사가 통과한다.
- **SC-004**: 실제 자료의 결과와 실패 사유를 완전히 보고한다. 전략이 합격해야만 연구 완료인 것은
  아니지만, 전략 미통과 상태에서 전체 단타 실사용 목표가 완료됐다고 선언하지 않는다.

## Assumptions

- 이 조건은 기존 실패의 비용 분해에서 도출한 미검증 가설이며 수익을 보장하지 않는다.
- 계좌별 실제 수수료는 미확인이다. 기존 편도 25bp 가정을 낮추지 않는다.
- 과거 조정 가격과 한국투자 실제 체결의 동등성·60세션 전진 관찰·실거래 완료 증거는 별도다.
- 위험 등급 2: 연구와 운영 인계 추가. 기존 커널·주문·승격 관문 변경 없음.
