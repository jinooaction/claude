# Research: Lot-Aware Execution Proxy

## Decision: 신호와 체결 종목을 분리한다

`SPY/IEF/GLD`는 장기 홀드아웃과 forward 검증 신호로 유지한다. 체결만 `SPYM/IEF/GLDM`으로
바꿔 전략 지문과 작은 계좌의 주문 가능성을 동시에 보존한다. 대안인 라이브 유니버스 직접 교체는
검증한 신호 자체를 바꾸므로 제외했다.

## Decision: SPYM과 GLDM을 저가 체결 ETF로 사용한다

State Street 공식 상품 자료상 SPYM은 S&P 500을, GLDM은 금 가격을 추종한다. 2026년 공식
표시 가격은 각각 약 86.89달러와 80.46달러로, SPY와 GLD보다 293달러 계좌에서 정수 주 표현이
쉽다. IEF는 검증 상품을 그대로 쓴다. SCHR은 더 저가지만 채권 지수와 만기가 IEF와 완전히
같지 않아 이번 변경에서 제외했다.

## Decision: 가장 가까운 정수 주를 선택한다

항상 내림하면 목표가 48달러, 한 주가 80달러인 금 다리는 영원히 0주다. 0주의 목표 오차
48달러보다 1주의 오차 32달러가 작으므로 1주가 더 정확하다. 기본 경로는 기존 내림을 유지하고,
명시적 설정에서만 nearest를 사용하며 모든 캡과 현금 게이트를 다시 적용한다.

## Decision: 실제 KIS 스냅샷을 필수화한다

현재 미리보기의 `AAPL/AMZN/GOOGL/MSFT/NVDA`는 내부 모의 원장에서 왔다. 라이브와 미리보기
모두 `--account-wide`로 KIS 보유와 매수가능현금을 읽고, 비관리 보유는 보류한다. 최신 KIS
읽기 전용 점검은 현금 934.27달러, 총자산 1466.83달러, ORANY 28주를 기록했다.

## Alternatives Considered

- 자본을 늘려 SPY/GLD를 매수: 단 1의 20% 상한을 깨므로 제외.
- 소수점 주문: 현재 KIS 해외주식 주문 경로가 정수 수량을 사용하므로 제외.
- 옛 micro GTAA 재무장: 최신 검증 전략과 별도이고 과거 의도 손실 게이트가 있어 제외.
- 비관리 ORANY 자동 매도: 293달러 자본 범위를 넘어 계좌 배분을 바꾸므로 제외.
